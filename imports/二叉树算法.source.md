## 1. 理论基础

### 1.1 数据结构特点与核心性质

二叉树的每个节点最多有两个孩子，且左右有区别。子树仍然是二叉树，因此天然适合把大问题拆成同样定义的小问题。

| 类型 | 定义与性质 | 算法影响 |
|-|-|-|
| 普通二叉树 | 只约束每个节点最多两个孩子 | 不能根据值的大小决定搜索方向 |
| 满二叉树（本章采用代码随想录口径） | 每一层都填满，即 perfect binary tree | 高度为 h 时，节点数为 2^h − 1 |
| 完全二叉树 | 除最后一层外全满，最后一层从左到右连续 | 可利用满子树加速计数；常用于堆 |
| 二叉搜索树 BST | 左子树所有值小于根，右子树所有值大于根 | 中序严格递增；查询可舍弃一侧 |
| 平衡二叉树 | 每个节点左右子树高度差不超过 1 | 高度 O(log n)，避免搜索退化 |

注意：“full binary tree”在部分英文资料指每个节点有 0 或 2 个孩子，不等同于上表的 perfect。501 允许重复值，按它的题意使用“左侧不大于、右侧不小于”，中序为非递减。

- 深度：从根向下到当前节点的距离；高度：从当前节点向下到最远叶子的距离。
- 本文统一按**节点数**计：空树高度 0，根深度 1，叶子高度 1。按边数计时相应减 1。
- 树的最大深度等于根的高度，但一个中间节点的深度通常不等于它的高度。
- n 个节点的非空树有 n − 1 条边；第 k 层最多 2^(k−1) 个节点。
- 叶子必须同时满足 `left == null` 和 `right == null`。缺少一个孩子不代表叶子。
- BST 不保证平衡：单次搜索、插入、删除是 O(h)，最坏 h = n。

### 1.2 Java 节点与常用 API

节点类由力扣提供，解答中不重复定义。普通二叉树用 `TreeNode`；429、559 用带 `children` 的 `Node`；116、117 用带 `left/right/next` 的 `Node`。后两者同名但属于不同题目，不能混用。

| 题目中的节点类型 | 关键字段 | 用法 |
|-|-|-|
| `TreeNode` | `int val; TreeNode left; TreeNode right;` | 普通二叉树和 BST |
| N 叉树的 `Node` | `int val; List<Node> children;` | 429、559 |
| next 树的 `Node` | `int val; Node left; Node right; Node next;` | 116、117 |



同类题复用**写法**：中序固定“压左链 → 弹出处理 → 转右”，层序固定“锁定层大小 → 出队 → 左右入队”，路径固定“加入 → 递归 → 撤销”。每题仍完整展开代码，不要求复制其他章节的 helper。

| 需求 | 推荐类型与 API | 注意 |
|-|-|-|
| 栈 | `Deque<TreeNode>` + `ArrayDeque<>`；`push/pop/peek` | 后进先出；先压右再压左，左先处理 |
| 队列 | `Queue<TreeNode>` + `ArrayDeque<>`；`offer/poll/peek` | 先进先出；孩子进入下一层 |
| 结果列表 | `List<Integer>` + `ArrayList<>`；`add/get/size` | 路径结果要复制，不能共享正在修改的列表 |
| 反转结果 | `Collections.reverse(list)` | 原地反转列表顺序 |
| 记录父节点/高度 | `Map<TreeNode, TreeNode>` / `Map<TreeNode, Integer>` | 按节点身份区分，不能仅用节点值 |

`ArrayDeque` **不允许存 null**。需要同时保存可空节点时，将它们包装为非空数组或状态对象；统一迭代使用布尔标记，避免压入空指针。

### 1.3 使用场景与复杂度口径

树用于表达层级关系、表达式结构、搜索索引等。算法题中，遇到“子结构与整体同构”“祖先”“根到叶路径”，优先考虑树递归；遇到“第几层”“最近叶子”，考虑层序。

全文 n 为节点数，h 为树高，w 为最大层宽；空间默认指**辅助空间，不含必须返回的结果**。递归栈 O(h)，DFS 显式栈通常 O(h)，BFS 队列 O(w)。退化树的递归深度可达 n，可能触发 `StackOverflowError`；迭代消除调用栈风险，但不会自动降低时间复杂度。

**一句话总结：树题的核心是给“当前子树”定义任务，再决定从父亲接收什么、向父亲返回什么。**

## 2. 核心思想总结

### 2.1 递归三部曲：先写契约，再写代码

参考：[代码随想录·递归遍历](https://programmercarl.com/%E4%BA%8C%E5%8F%89%E6%A0%91%E7%9A%84%E9%80%92%E5%BD%92%E9%81%8D%E5%8E%86.html)。后文每题的三部曲统一为：

1. **参数与返回值**：参数表示哪棵子树、携带什么上下文；返回值必须有明确含义。不要只写“返回 int”，而要写“返回这棵子树的高度”。
2. **终止条件**：空节点、叶子、空区间分别如何处理；返回值要能直接参与上一层计算。
3. **单层逻辑**：假设左右递归已经正确，只写当前节点如何使用它们。不要在脑中把所有层同时展开。

例如求高度：函数接收节点并返回该子树高度；空树返回 0；当前返回 `1 + max(左高度, 右高度)`。因为父节点依赖子树结果，计算放在后序位置。

### 2.2 为什么选择前序、中序、后序

“序”指**当前节点的关键处理放在何时**，不是函数从哪里开始调用。三种递归都先进入根的函数。

| 信息关系 | 推荐顺序 | 为什么 | 代表题 |
|-|-|-|-|
| 当前状态传给孩子 | 前序：中左右 | 孩子需要带上父节点处理后的状态 | 路径、深度、构造 |
| 利用 BST 值的顺序 | 中序：左中右 | 左侧值整体较小，右侧整体较大 | 验证、最小差、众数 |
| 先有孩子结果才能算父亲 | 后序：左右中 | 子问题必须先解决 | 高度、平衡、普通树 LCA |
| 累积比当前更大的 BST 值 | 反中序：右中左 | 先处理较大值 | 累加树 |
| 按距离根的远近处理 | 层序：BFS（广度优先） | 队列先处理较浅节点 | 层统计、最小深度 |

这些是依赖关系，不是硬性口诀。翻转树可以前序也可以后序；BST 搜索只走一条分支，不需要强行称为中序；用中序序列重建树不代表构造过程是中序。

用同一棵树检查自己是否真正理解“序”：

```Plaintext
        4
       / \
      2   6
     / \ / \
    1  3 5  7

前序：4 2 1 3 6 5 7    父节点先处理
中序：1 2 3 4 5 6 7    BST 中呈递增
后序：1 3 2 5 7 6 4    孩子先完成
层序：4 | 2 6 | 1 3 5 7
```

以高度为例：叶子 1、3 分别返回 1，节点 2 才能返回 2；节点 6 也返回 2，根 4 最后返回 3。后序的位置由“先知道孩子高度”的依赖决定，而非背诵顺序。

### 2.3 遍历型与分解型递归

| 写法 | 状态来源 | 典型函数含义 | 主要风险 |
|-|-|-|-|
| 遍历型 | 从根向下传递深度、路径、剩余目标 | “访问这个节点，并更新答案” | 共享字段忘记重置；路径忘记撤销 |
| 分解型 | 子树向上返回高度、是否成立、子树根 | “解决以这个节点为根的子问题” | 返回含义含糊；修改后忘接回子树 |

返回值选型：只收集信息可用 `void`；判断存在性用 `boolean` 并短路；聚合用数值；修改结构用 `TreeNode` 返回修改后的根。

### 2.4 递归如何改成迭代

递归调用栈保存的不只是节点，还保存“执行到哪里”和局部状态。

- 前序：取节点立即处理，栈保存尚未访问的子树。
- 中序：先沿左链压栈，弹出时才处理，随后进入右子树。
- 后序：需要知道孩子是否完成，可用 `lastVisited` 或“节点＋完成标记”。
- 路径：状态中还要保存路径或剩余目标，不能只压节点。
- 构造：状态中保存数组区间与待挂接的位置。
- 层序：每轮先固定 `levelSize = queue.size()`，新入队孩子属于下一轮。

### 2.5 统一迭代模板：显式区分“展开”和“处理”

参考：[代码随想录·统一迭代法](https://programmercarl.com/%E4%BA%8C%E5%8F%89%E6%A0%91%E7%9A%84%E7%BB%9F%E4%B8%80%E8%BF%AD%E4%BB%A3%E6%B3%95.html)。下面以中序展示，三种顺序只调整压栈次序。

```Java
import java.util.*;

class Solution {
    private static class Frame {
        TreeNode node;
        boolean ready;

        Frame(TreeNode node, boolean ready) {
            this.node = node;
            this.ready = ready;
        }
    }

    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Deque<Frame> stack = new ArrayDeque<>();
        stack.push(new Frame(root, false));
        while (!stack.isEmpty()) {
            Frame frame = stack.pop();
            TreeNode node = frame.node;
            if (frame.ready) {
                result.add(node.val);
                continue;
            }
            // 想要执行左、中、右，就逆序压入右、中、左。
            if (node.right != null) {
                stack.push(new Frame(node.right, false));
            }
            stack.push(new Frame(node, true));
            if (node.left != null) {
                stack.push(new Frame(node.left, false));
            }
        }
        return result;
    }
}
```

| 遍历 | 实际处理顺序 | 压栈顺序（从先到后） |
|-|-|-|
| 前序 | 中、左、右 | 右展开、左展开、中处理 |
| 中序 | 左、中、右 | 右展开、中处理、左展开 |
| 后序 | 左、右、中 | 中处理、右展开、左展开 |

### 2.6 回溯、修改与剪枝的三个关键点

共享 `List` / `StringBuilder`：进入时加入当前节点，退出时恢复进入前状态。整数参数是值传递，不需要手动撤销；为每个分支创建独立字符串也无需撤销，但会增加复制成本。

修改树时牢记：`node.left = change(node.left)`。递归可能删除或替换子树根，只调用而不接返回值，会丢失修改。

普通树不能因为“值太大”就剪掉一侧。BST 可以根据整个子树的值域剪枝；路径和允许负数时，不能因“剩余目标小于 0”就停止。

### 3.1 [144. 二叉树的前序遍历](https://leetcode.cn/problems/binary-tree-preorder-traversal/)

#### 一句话总结

> 这道题本质是：第一次到达节点时立即处理它，再进入左右子树。

#### 思路分析

先看输出顺序：要求“根→左→右”，所以到一个节点先记下它，再处理左右子树。  
把 traversal(node, result) 理解为“把这棵子树按前序放进 result”。空节点没东西可放，直接返回；非空只做“记自己→交给左边→交给右边”。  
迭代也照这个顺序：栈后进先出，想先处理左边，就先压右、再压左。

#### 方法选择

递归选择前序，直接对应输出要求；迭代选择栈，模拟深度优先的待办顺序。

递归三部曲：① `traversal(node, result)` 将当前子树的前序追加到结果，无返回值；② 空节点直接返回；③ 记录当前值，再递归左、右。

#### 解题模板

看到“先记录父节点，再处理子结构” → 前序。递归和迭代均 O(n) 时间、O(h) 辅助空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        traversal(root, result);
        return result;
    }

    // ① node 是当前子树；result 收集答案，不需要返回子树结果。
    private void traversal(TreeNode node, List<Integer> result) {
        // ② 空节点没有值可记录，结束这一支。
        if (node == null) {
            return;
        }
        // ③ 前序先记自己，再让左右子树做同样的事。
        result.add(node.val);
        traversal(node.left, result);
        traversal(node.right, result);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            // 栈后进先出：先压右、再压左，弹出时才是左→右。
            if (node.right != null) {
                stack.push(node.right);
            }
            if (node.left != null) {
                stack.push(node.left);
            }
        }
        return result;
    }
}
```

### 3.2 [94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

#### 一句话总结

> 这道题本质是：当前节点要等左子树全部处理完，才轮到自己。

#### 思路分析

要求“左→根→右”，所以当前节点先等左子树处理完，再记录自己，最后处理右子树。  
递归函数负责把当前子树的中序结果加入列表；空节点直接返回。和前序相比，只把“记录当前值”移到两次递归之间。  
迭代时先沿左边走到底，并用栈记住父节点；走不动了就弹出、记录，再转向右子树。

#### 方法选择

递归中序；迭代用栈保存回到父节点的位置，`cur` 表示接下来要探索的子树。

递归三部曲：① 追加当前子树中序；② 空节点返回；③ 左递归、记录当前值、右递归。

#### 解题模板

看到“BST 有序性、与前驱比较” → 中序。循环条件是 `cur != null || !stack.isEmpty()`；均 O(n) 时间、O(h) 空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        traversal(root, result);
        return result;
    }

    // ① 把当前子树的中序结果追加到 result，无需返回值。
    private void traversal(TreeNode node, List<Integer> result) {
        // ② 空节点没有内容，直接返回。
        if (node == null) {
            return;
        }
        // ③ 中序要等左边完成，才记录自己，再处理右边。
        traversal(node.left, result);
        result.add(node.val);
        traversal(node.right, result);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            // 沿左边走到底，栈记住稍后要回来的父节点。
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            // 左子树完成了，现在记录当前节点，再转右边。
            cur = stack.pop();
            result.add(cur.val);
            cur = cur.right;
        }
        return result;
    }
}
```

### 3.3 [145. 二叉树的后序遍历](https://leetcode.cn/problems/binary-tree-postorder-traversal/)

#### 一句话总结

> 这道题本质是：左右子树都完成后，当前节点才能完成。

#### 思路分析

要求“左→右→根”，所以先让左右子树完成，再记录当前节点。求高度、判断平衡也常用这个顺序：父节点要等孩子给出结果。  
递归函数负责输出当前子树的后序；空节点返回，非空按“左递归→右递归→记录自己”写。  
迭代要区分“第一次看到节点”和“孩子已经处理完”。lastVisited 记住刚完成的节点，防止反复进入右子树。

#### 方法选择

递归后序最直观。迭代查看栈顶：若右子树存在且尚未完成，先去右侧；否则处理并弹出当前节点。`lastVisited` 是最近完成的子树根。

递归三部曲：① 追加当前子树后序；② 空节点返回；③ 左递归、右递归、记录当前值。

#### 解题模板

看到“父亲依赖两个孩子的结果” → 后序。迭代需保存完成状态；均 O(n) 时间、O(h) 空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        traversal(root, result);
        return result;
    }

    // ① 把当前子树的后序结果追加到 result，无需返回值。
    private void traversal(TreeNode node, List<Integer> result) {
        // ② 空节点没有内容，直接返回。
        if (node == null) {
            return;
        }
        // ③ 后序先完成两个孩子，最后记录自己。
        traversal(node.left, result);
        traversal(node.right, result);
        result.add(node.val);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        // 记住刚完成的节点，判断右子树是否已经处理过。
        TreeNode lastVisited = null;
        while (cur != null || !stack.isEmpty()) {
            if (cur != null) {
                stack.push(cur);
                cur = cur.left;
            } else {
                // 先看栈顶，不能马上弹出：它还可能要等右子树。
                TreeNode node = stack.peek();
                // 右子树尚未完成就先走右边；否则才处理根。
                if (node.right != null && node.right != lastVisited) {
                    cur = node.right;
                } else {
                    result.add(node.val);
                    lastVisited = stack.pop();
                }
            }
        }
        return result;
    }
}
```

### 3.4 [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

#### 一句话总结

> 这道题本质是：把节点按到根的距离分组。

#### 思路分析

看到“按层输出”，先想队列：处理完这一层，再处理下一层。每轮先记住队列长度，孩子入队后不会混进当前层。  
如果用递归，访问顺序仍是深度优先，但带上 depth，就知道节点该放进哪一层。第一次到达新深度，先建列表，再加入当前值。  
空节点直接返回；孩子的 depth 加 1。先左后右，能让同层结果保持从左到右。

#### 方法选择

推荐 BFS，因为输出单位就是层。递归用前序携带 `depth`，同层的节点因先左后右而保持正确顺序。

递归三部曲：① `traversal(node, depth, result)` 收集节点，根深度下标为 0；② 空节点返回；③ 必要时创建该层，加入当前值，再访问左右孩子。

#### 解题模板

看到“每层” → BFS 固定本轮队列长度。时间 O(n)；BFS 空间 O(w)，递归 O(h)，不含结果。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        traversal(root, 0, result);
        return result;
    }

    // ① depth 是层下标，根为 0；节点写入 result[depth]。
    private void traversal(TreeNode node, int depth, List<List<Integer>> result) {
        // ② 空节点不属于任何层，直接返回。
        if (node == null) {
            return;
        }
        // ③ 首次到达这一层先建列表，再记当前值并继续下一层。
        if (depth == result.size()) {
            result.add(new ArrayList<>());
        }
        result.get(depth).add(node.val);
        // 孩子属于下一层；先左后右保证同层从左到右。
        traversal(node.left, depth + 1, result);
        traversal(node.right, depth + 1, result);
    }
}
```

### 3.5 [107. 二叉树的层序遍历 II](https://leetcode.cn/problems/binary-tree-level-order-traversal-ii/)

#### 一句话总结

> 这道题本质是：改变层的输出顺序，不改变层内节点顺序。

#### 思路分析

先把它当作普通层序：每层仍然从左到右，只是最后要先输出底层。  
因此先收集从上到下的各层，再反转外层列表；每一层内部不要反转。  
递归仍用 depth 分组、空节点返回、先左后右；反转放在入口里做一次，别放进每层递归。

#### 方法选择

BFS 或前序按深度收集，最后反转。递归三部曲：① 收集某子树各深度节点；② 空节点返回；③ 当前值入对应层，再左、右递归；反转只在入口完成。

#### 解题模板

看到“自底向上层序” → 102 ＋ 反转外层。时间 O(n)，辅助空间 BFS O(w)、递归 O(h)。两种解法都在本题内完整实现收集过程，最后只反转外层列表。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        traversal(root, 0, result);
        // 只反转层的先后，不改变每层内部的左右顺序。
        Collections.reverse(result);
        return result;
    }

    // ① 先按 depth 收集正常层序，反转交给入口统一做。
    private void traversal(TreeNode node, int depth, List<List<Integer>> result) {
        // ② 空节点没有值，结束这一支。
        if (node == null) {
            return;
        }
        // ③ 先建当前层、加当前值，再按左到右收集孩子。
        if (depth == result.size()) {
            result.add(new ArrayList<>());
        }
        result.get(depth).add(node.val);
        traversal(node.left, depth + 1, result);
        traversal(node.right, depth + 1, result);
    }
}
```

### 3.6 [199. 二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)

#### 一句话总结

> 这道题本质是：保留每个深度最靠右的实际存在节点。

#### 思路分析

从右侧看，一层只能看到最靠右的那个节点。它未必在一直向右的链上：右子树不够深时，左子树也会露出来。  
递归先右后左。这样每个深度第一次遇到的节点就是最右节点，只在 depth == result.size() 时记录一次。  
空节点返回，孩子深度加 1；迭代则正常从左到右做层序，只取每层最后一个。

#### 方法选择

迭代 BFS 便于理解“每层最右”；递归用中右左的前序变体优先占位。

递归三部曲：① 节点、深度、结果列表，无返回值；② 空返回；③ 深度第一次出现时记录，然后右、左递归。

#### 解题模板

看到“每层一项且偏向一侧” → BFS 边界项，或优先侧 DFS 首次到达。时间 O(n)，空间 BFS O(w)、DFS O(h)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        traversal(root, 0, result);
        return result;
    }

    // ① depth 标记层；result 每层只保留最右边一个值。
    private void traversal(TreeNode node, int depth, List<Integer> result) {
        // ② 空节点看不到，直接返回。
        if (node == null) {
            return;
        }
        // ③ 先右后左，所以新深度的第一个节点就是最右节点。
        if (depth == result.size()) {
            result.add(node.val);
        }
        // 右侧优先占位；右侧缺失时，左子树仍能补上更深层。
        traversal(node.right, depth + 1, result);
        traversal(node.left, depth + 1, result);
    }
}
```

##### 方法2：迭代

```Java
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }
        return result;
    }
}
```

### 3.7 [637. 二叉树的层平均值](https://leetcode.cn/problems/average-of-levels-in-binary-tree/)

#### 一句话总结

> 这道题本质是：按层维护**总和**与**数量**两个统计量。

#### 思路分析

一层的平均值就是“这一层的总和÷节点数”，所以不必保存每个节点，只记这两个量。  
队列法每轮固定一层的节点数，边出队边加；递归法带 depth，把值加到对应层，并把计数加 1，遍历结束后再统一除。  
空节点返回，新深度先建统计位置。总和用 double，避免用 int 累加整层时溢出。

#### 方法选择

BFS 天然给出层大小；递归前序把当前值计入所属深度。

递归三部曲：① 节点、深度、各层总和与计数；② 空返回；③ 创建统计槽，更新当前层，再遍历孩子。

#### 解题模板

看到“每层聚合” → 把 102 的列表替换成统计量。时间 O(n)；BFS 空间 O(w)，DFS 的栈与统计数组 O(h)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<Double> averageOfLevels(TreeNode root) {
        List<Double> sums = new ArrayList<>();
        List<Integer> counts = new ArrayList<>();
        traversal(root, 0, sums, counts);
        for (int i = 0; i < sums.size(); i++) {
            sums.set(i, sums.get(i) / counts.get(i));
        }
        return sums;
    }

    // ① depth 标记层；sums 和 counts 分别记录各层总和、数量。
    private void traversal(TreeNode node, int depth,
            List<Double> sums, List<Integer> counts) {
        // ② 空节点不参与统计。
        if (node == null) {
            return;
        }
        // ③ 新层先建统计位置；当前值和数量更新后，再处理孩子。
        if (depth == sums.size()) {
            // 总和用 double，避免一整层用 int 相加溢出。
            sums.add(0.0);
            counts.add(0);
        }
        sums.set(depth, sums.get(depth) + node.val);
        counts.set(depth, counts.get(depth) + 1);
        traversal(node.left, depth + 1, sums, counts);
        traversal(node.right, depth + 1, sums, counts);
    }
}
```

##### 方法2：迭代

```Java
            return result;
        }

                sum += node.val;
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            result.add(sum / levelSize);
        }
        return result;
    }
```

### 3.8 [429. N 叉树的层序遍历](https://leetcode.cn/problems/n-ary-tree-level-order-traversal/)

#### 一句话总结

> 这道题本质是：把二叉树的两个孩子扩展为一个有序孩子列表。

#### 思路分析

它和二叉树层序是同一件事，只是孩子不再固定为左、右两个，而是一整个列表。  
队列仍按层处理；递归仍带 depth 分组，记下当前节点后，按 children 的顺序递归所有孩子。  
空节点返回；没有孩子就结束这一支。迁移模板时，把两次左右递归换成孩子循环即可。

#### 方法选择

队列 BFS 为主；递归是多叉前序，不存在天然唯一的“中序”位置。

递归三部曲：① 节点、深度、层结果；② 空返回；③ 当前值入对应层，再遍历全部孩子。

#### 解题模板

看到“任意多个孩子” → 二叉树模板中的左、右递归替换为循环。时间 O(n)；BFS 空间 O(w)，递归 O(h)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<List<Integer>> levelOrder(Node root) {
        List<List<Integer>> result = new ArrayList<>();
        traversal(root, 0, result);
        return result;
    }

    // ① depth 决定放在哪一层；result 保存各层节点。
    private void traversal(Node node, int depth, List<List<Integer>> result) {
        // ② 空节点没有内容，直接返回。
        if (node == null) {
            return;
        }
        // ③ 记录当前节点，再按 children 的顺序处理下一层。
        if (depth == result.size()) {
            result.add(new ArrayList<>());
        }
        result.get(depth).add(node.val);
        if (node.children != null) {
            // 二叉树的两次递归，在这里换成遍历所有孩子。
            for (Node child : node.children) {
                traversal(child, depth + 1, result);
            }
        }
    }
}
```

```Java
                    }
                }
            }

        }
        return result;
    }
```

### 3.9 [515. 在每个树行中找最大值](https://leetcode.cn/problems/find-largest-value-in-each-tree-row/)

#### 一句话总结

> 这道题本质是：每个深度只保留一个最大值。

#### 思路分析

看到“每层最大值”，就把层序里的“保存全部值”改成“只保留当前最大值”。  
递归带 depth；第一次到达这一层，用当前节点值初始化，后面遇到同层节点就取较大值。空节点返回，再继续访问孩子。  
迭代每层重新统计一次；最大值不能初始化为 0，因为这一层可能全是负数。

#### 方法选择

BFS 在一层内聚合；递归前序按深度更新。

递归三部曲：① 节点、深度、各层最大值；② 空返回；③ 新深度用当前值初始化，否则取较大值，再递归孩子。

#### 解题模板

看到“每层最大/最小/总和” → 相同层序骨架，替换聚合运算。时间 O(n)，空间 BFS O(w)、递归 O(h)。

```Java
        traversal(root, 0, result);
        return result;
    }
```

### 3.10 [116. 填充每个节点的下一个右侧节点指针](https://leetcode.cn/problems/populating-next-right-pointers-in-each-node/)

#### 一句话总结

> 这道题本质是：利用已连接的上一层，连接下一层的兄弟与跨父节点邻居。

#### 思路分析

要连的是同一层的相邻节点。先看满树结构：同一个父亲的左孩子连右孩子；右孩子连隔壁父亲的左孩子。  
先把孩子的 next 连好，再递归孩子，因为下一层要用这些 next 找隔壁节点。空节点或叶子没有孩子可连，直接返回。  
迭代沿本层的 next 一路向右，同时连接下一层；一层结束后，从最左孩子进入下一层。

#### 方法选择

递归在下降前连好孩子，属于前序式处理；迭代通过本层的 `next` 链横向行走，用 O(1) 辅助空间。

递归三部曲：① `link(node)` 连接该子树下面的层，进入时当前层的 next 已可用；② 空或叶子返回；③ 连兄弟、连跨父节点邻居，再递归左右。

#### 解题模板

看到“满树＋额外 next 指针” → 用上一层链表代替 BFS 队列。两法 O(n) 时间；递归 O(h)，迭代 O(1)。普通稀疏树不能直接套此公式。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public Node connect(Node root) {
        if (root != null) {
            root.next = null;
        }
        link(root);
        return root;
    }

    // ① 进入 link 时，本层 next 已可用；现在负责连接孩子。
    private void link(Node node) {
        // ② 空节点或叶子没有孩子可连接。
        if (node == null || node.left == null) {
            return;
        }
        // ③ 先连同父兄弟，再连跨父邻居；连好后孩子才能继续使用 next。
        node.left.next = node.right;
        node.right.next = null;
        if (node.next != null) {
            // 跨父连接：自己的右孩子，连隔壁父亲的左孩子。
            node.right.next = node.next.left;
        }
        link(node.left);
        link(node.right);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public Node connect(Node root) {
        if (root == null) {
            return null;
        }
        root.next = null;
        Node levelStart = root;
        // 叶子层已由上一层连好；没有下一层时停止。
        while (levelStart.left != null) {
            Node cur = levelStart;
            while (cur != null) {
                // 连同父兄弟，再连隔壁父亲的左孩子。
                cur.left.next = cur.right;
                cur.right.next = null;
                if (cur.next != null) {
                    cur.right.next = cur.next.left;
                }
                // 本层 next 已经连好，可代替队列横向遍历。
                cur = cur.next;
            }
            // 本层完成后，转到下一层的最左节点。
            levelStart = levelStart.left;
        }
        return root;
    }
}
```

### 3.11 [117. 填充每个节点的下一个右侧节点指针 II](https://leetcode.cn/problems/populating-next-right-pointers-in-each-node-ii/)

#### 一句话总结

> 这道题本质是：把当前层所有实际存在的孩子串成下一层链表。

#### 思路分析

这次树有空缺，隔壁父亲不一定有左孩子，不能直接套 116 的连接公式。  
最直观的递归：带 depth，记住每层刚访问的节点；先左后右访问，把同层前一个节点连到当前节点。空节点返回，新深度只登记首节点。  
想做到常数额外空间，就沿本层 next 走，把非空孩子按左、右顺序追加成下一层链表。dummy 负责统一处理首节点，tail 负责追加。

#### 方法选择

推荐 next 链迭代，O(1) 辅助空间。递归前序先左后右，使同层节点依次到达，维护每层 `previous`；它是便于理解的 O(h) 空间备选，不满足常数额外空间的严格目标。

递归三部曲：① 节点、深度、每层最后访问节点；② 空返回；③ 把同层前驱连到当前，更新前驱，再访问左、右。

#### 解题模板

看到“遍历一层并构造下一层链” → dummy 统一处理下一层首节点。时间 O(n)，迭代 O(1) 空间，递归 O(h)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public Node connect(Node root) {
        link(root, 0, new ArrayList<>());
        return root;
    }

    // ① previous[depth] 记住本层刚访问的节点，便于连到当前。
    private void link(Node node, int depth, List<Node> previous) {
        // ② 空位置略过，不加入 next 链。
        if (node == null) {
            return;
        }
        // ③ 先清空旧 next；新层登记首节点，已有层把前一个节点连过来。
        node.next = null;
        if (depth == previous.size()) {
            previous.add(node);
        } else {
            previous.get(depth).next = node;
            previous.set(depth, node);
        }
        // 先左后右，使同一层节点按从左到右到达。
        link(node.left, depth + 1, previous);
        link(node.right, depth + 1, previous);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public Node connect(Node root) {
        if (root == null) {
            return null;
        }
        root.next = null;
        Node levelStart = root;
        while (levelStart != null) {
            // dummy 不进原树，只作为下一层链表的虚拟头。
            Node dummy = new Node(0);
            Node tail = dummy;
            for (Node node = levelStart; node != null; node = node.next) {
                if (node.left != null) {
                    // 把非空孩子依次接到链尾，空缺自然被跳过。
                    tail.next = node.left;
                    tail = tail.next;
                }
                if (node.right != null) {
                    tail.next = node.right;
                    tail = tail.next;
                }
            }
            // 最后节点收尾，避免保留旧 next。
            tail.next = null;
            // dummy.next 就是下一层首节点，没有孩子时为 null。
            levelStart = dummy.next;
        }
        return root;
    }
}
```

### 3.12 [226. 翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/)

#### 一句话总结

> 这道题本质是：对每个节点交换左右子树，而不是只交换最外层。

#### 思路分析

先想一个节点怎么翻转：交换它的左、右孩子。所有节点都交换一次，整棵树就镜像了。  
invertTree(root) 返回翻转后的子树根。空树返回 null；非空先交换孩子，再翻转交换后的左右子树，最后返回 root。  
这里改的是原节点的引用，所以根对象仍是原来的 root；迭代只是换成队列，逐个做同样的交换。

#### 方法选择

前序先交换再递归，后序先翻转孩子再交换也正确。朴素中序“递归左、交换、递归右”会再次进入原左子树，因此不能机械搬动交换语句。迭代用队列覆盖全部节点。

递归三部曲：① 返回当前子树翻转后的根；② 空返回 null；③ 交换孩子，再翻转交换后的两棵子树，返回当前节点。

#### 解题模板

看到“每个节点都执行相同局部变换” → 遍历＋局部操作。时间 O(n)，递归 O(h)、BFS O(w) 空间；原树被修改。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回当前子树翻转后的根；操作直接修改原节点。
    public TreeNode invertTree(TreeNode root) {
        // ② 空树翻转后仍为空。
        if (root == null) {
            return null;
        }
        // ③ 交换两侧，再递归翻转交换后的孩子；当前根仍是 root。
        TreeNode temporary = root.left;
        root.left = root.right;
        root.right = temporary;
        invertTree(root.left);
        invertTree(root.right);
        return root;
    }
}
```

##### 方法2：迭代

```Java

            return null;

            TreeNode temporary = node.left;
            node.left = node.right;
            node.right = temporary;
            if (node.left != null) {
                queue.offer(node.left);
            }
            if (node.right != null) {
                queue.offer(node.right);
            }
        }
        return root;
    }
}
```

### 3.13 [101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/)

#### 一句话总结

> 这道题本质是：同步比较两棵子树的镜像位置，而不是比较一层的数值是否回文。

#### 思路分析

判断对称时，要同时看左右两棵树：值相同还不够，空位置也要镜像。  
让 mirror(left, right) 回答“两棵子树是否镜像”。两边都空为真，只有一边空或值不同为假。  
当前值通过后，再比较“左树的左↔右树的右”和“左树的右↔右树的左”，两组都通过才对称。迭代也成对保存节点，不能丢掉 null。

#### 方法选择

递归是双树的后序式布尔汇总，当前值可提前判错，最终结果依赖外侧与内侧子问题；它不是对单棵树做普通后序输出。迭代保存节点对，并保留其中的 null。

递归三部曲：① `mirror(left, right)` 返回两树是否镜像；② 同为空 true，单空或值不同 false；③ 外侧镜像且内侧镜像。

#### 解题模板

看到“相同/镜像两棵树” → 双指针同步遍历，先处理空结构。时间 O(n)，递归 O(h)，队列 O(w)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) {
            return true;
        }
        return mirror(root.left, root.right);
    }

    // ① 两个参数是待比较的子树根；返回它们是否镜像。
    private boolean mirror(TreeNode left, TreeNode right) {
        // ② 两边都空才匹配；只有一边空说明结构不对称。
        if (left == null || right == null) {
            return left == right;
        }
        // ③ 值相同后，再同时检查外侧和内侧的镜像关系。
        if (left.val != right.val) {
            return false;
        }
        // 外侧对外侧、内侧对内侧；两组都匹配才是镜像。
        return mirror(left.left, right.right)
                && mirror(left.right, right.left);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) {
            return true;
        }
        // 队列里保存节点对；数组可以保留 null，空结构也要比较。
        Queue<TreeNode[]> queue = new ArrayDeque<>();
        queue.offer(new TreeNode[] {root.left, root.right});
        while (!queue.isEmpty()) {
            TreeNode[] pair = queue.poll();
            TreeNode left = pair[0];
            TreeNode right = pair[1];
            // 两空匹配；一空说明结构不对称，直接失败。
            if (left == null || right == null) {
                if (left != right) {
                    return false;
                }
                continue;
            }
            if (left.val != right.val) {
                return false;
            }
            // 按镜像配对：外侧对外侧，内侧对内侧。
            queue.offer(new TreeNode[] {left.left, right.right});
            queue.offer(new TreeNode[] {left.right, right.left});
        }
        return true;
    }
}
```

### 3.14 [104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

#### 一句话总结

> 这道题本质是：从左右子树中选更高的一棵，再算上当前节点。

#### 思路分析

最长根到叶路径一定走向更深的那一边，所以当前子树高度 = 左右高度的较大值 + 当前这一层。  
让 maxDepth(root) 只负责返回“这棵子树有几层”。空树为 0；先递归拿到左右高度，再取 max + 1，叶子自然算出 1。  
另一种递归是向下传“当前第几层”，沿途更新最大值；队列法则直接统计一共处理了几层。先分清返回的是高度，还是传入的是深度。

#### 方法选择

主解后序，因为高度依赖两个孩子。前序版本展示“向下传深度”与“向上返高度”的区别；BFS 直接按层计数。

递归三部曲：① `maxDepth(node)` 返回当前子树高度；② 空为 0；③ 取左右高度最大值＋1。前序版：参数增加 depth，空返回，更新全局最大值再下降。

#### 解题模板

看到“子树高度” → 后序；看到“当前层数” → 前序带参数。时间 O(n)，递归 O(h)、BFS O(w) 空间。

#### Java代码

##### 方法1：递归：后序返回高度

```Java
import java.util.*;

class Solution {
    // ① 返回当前子树的高度，不是当前节点距离根的深度。
    public int maxDepth(TreeNode root) {
        // ② 空树有 0 层；这样叶子才能由 max(0, 0) + 1 得到 1。
        if (root == null) {
            return 0;
        }
        // ③ 父高度依赖孩子：先拿左右高度，再取较大值加自己一层。
        int leftHeight = maxDepth(root.left);
        int rightHeight = maxDepth(root.right);
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

##### 方法2：递归：前序传递深度

```Java
import java.util.*;

class Solution {
    private int maximum;

    public int maxDepth(TreeNode root) {
        // 每次调用重新统计；根从第 1 层开始。
        maximum = 0;
        traversal(root, 1);
        return maximum;
    }

    // ① depth 是从根走到当前节点的层数，maximum 保存全树最大值。
    private void traversal(TreeNode node, int depth) {
        // ② 空位置不算一层，直接返回。
        if (node == null) {
            return;
        }
        // ③ 先用当前深度更新最大值，再给孩子传 depth + 1。
        maximum = Math.max(maximum, depth);
        traversal(node.left, depth + 1);
        traversal(node.right, depth + 1);
    }
}
```

##### 方法3：迭代

```Java

            return 0;
        }

        while (!queue.isEmpty()) {

            int levelSize = queue.size();
            // 每处理一轮就是一层；层数即最大深度。
            depth++;
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }
        return depth;
    }
}
```

### 3.15 [559. N 叉树的最大深度（关联补充）](https://leetcode.cn/problems/maximum-depth-of-n-ary-tree/)

#### 一句话总结

> 这道题本质是：取所有孩子高度的最大值，而不只比较两个孩子。

#### 思路分析

先套最大深度的想法：当前高度等于最深孩子的高度 + 1，只是这次孩子有多个。  
递归函数返回当前子树高度；空树返回 0。遍历所有孩子，保留最高的返回值，最后加上自己。  
孩子最大高度从 0 开始，所以没有孩子的叶子返回 1；迭代按层计数即可。

#### 方法选择

递归多叉后序，所有孩子完成后汇总；迭代 BFS 数层。

递归三部曲：① 返回当前子树高度；② 空为 0；③ 遍历孩子取最大高度＋1，无孩子时返回 1。

#### 解题模板

看到“多叉树属性汇总” → 把左右结果改成遍历孩子列表。时间 O(n)，空间递归 O(h)、BFS O(w)。

##### 方法1：递归

```Java

    // ① 返回当前 N 叉子树高度，供父节点选最高的孩子。
```

### 3.16 [111. 二叉树的最小深度](https://leetcode.cn/problems/minimum-depth-of-binary-tree/)

#### 一句话总结

> 这道题本质是：找最近的真实叶子，而不是最近的空指针。

#### 思路分析

先抓住“到叶子”三个字：只有左右孩子都为空才到终点，缺一边不能提前结束。  
空树返回 0；只有一个孩子，就沿存在的那一边继续并加 1；两边都有孩子，才取左右最小深度 + 1。  
例如根只有一个左叶子，答案是 2，不能把空右边的 0 拿来取 min。队列从浅到深走，遇到第一个叶子就能返回。

#### 方法选择

后序分别求到左右叶子的距离，再分类合并；BFS 首次遇到叶子即可返回，通常更适合“最近”。

递归三部曲：① 返回当前子树到最近叶子的节点数；② 空树 0；③ 单空取非空侧＋1，两侧都在才取 min＋1。

#### 解题模板

看到“最近叶子/最少层数” → BFS 首次命中；递归要排除不存在的路径。最坏 O(n) 时间，空间 DFS O(h)、BFS O(w)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回从当前根到最近叶子的节点数。
    public int minDepth(TreeNode root) {
        // ② 空树为 0，但空孩子不能当作可走的叶子路径。
        if (root == null) {
            return 0;
        }
        // ③ 单孩子只能走存在的一边；两边都在才取 min，最后加自己。
        if (root.left == null) {
            return minDepth(root.right) + 1;
        }
        if (root.right == null) {
            return minDepth(root.left) + 1;
        }
        int leftDepth = minDepth(root.left);
        int rightDepth = minDepth(root.right);
        return Math.min(leftDepth, rightDepth) + 1;
    }
}
```

##### 方法2：迭代

```Java
        }

        while (!queue.isEmpty()) {

            int levelSize = queue.size();
            for (int i = 0; i < levelSize; i++) {

                    return depth;
                }
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            depth++;
        }
        return depth;
    }
```

### 3.17 [222. 完全二叉树的节点个数](https://leetcode.cn/problems/count-complete-tree-nodes/)

#### 一句话总结

> 这道题本质是：识别可直接套公式的满子树，避免逐节点计数。

#### 思路分析

普通树先想“左边数量 + 右边数量 + 自己”。题目又给了完全树，便可进一步跳过整棵满子树。  
在完全树里，当前子树最左路径和最右路径一样高，说明每层都满，可直接算 2^h - 1；不一样高才继续递归左右并加 1。  
空树数量为 0。迭代比较左右子树的左链高度，数掉确定为满的一边，只往另一边走；这个判断依赖完全树条件。

#### 方法选择

递归先检测满树，否则后序汇总；迭代比较左右子树的左链高度，每轮数掉一棵确定满的子树，只进入另一棵。

递归三部曲：① 返回子树节点数；② 空为 0，满树直接公式返回；③ 非满时返回左计数＋右计数＋1。

#### 解题模板

看到“完全树计数” → 满树公式＋结构剪枝。递归 O(log² n) 时间、O(log n) 空间；迭代同时间、O(1) 空间。位移先用 long；最终 int 转换依据本题节点数范围。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回当前完全子树的节点总数。
    public int countNodes(TreeNode root) {
        // ② 空树没有节点，返回 0。
        if (root == null) {
            return 0;
        }
        // ③ 先看是否整棵满；能用公式就直接算，否则递归左右再加自己。
        int leftHeight = leftHeight(root);
        int rightHeight = 0;
        TreeNode cur = root;
        while (cur != null) {
            rightHeight++;
            cur = cur.right;
        }
        if (leftHeight == rightHeight) {
            // 完全树的两端同高，才能判定整棵满；h 层共 2^h - 1 个节点。
            return (int) ((1L << leftHeight) - 1);
        }
        return countNodes(root.left) + countNodes(root.right) + 1;
    }

    private int leftHeight(TreeNode node) {
        int height = 0;
        while (node != null) {
            height++;
            node = node.left;
        }
        return height;
    }
}
```

##### 方法2：迭代

```Java
        return height;
    }

    public int countNodes(TreeNode root) {
        long count = 0;
        TreeNode cur = root;
        while (cur != null) {
            // 比较的是左右子树的左链高度，用完全树性质确定哪侧满。
            int leftHeight = leftHeight(cur.left);
            int rightHeight = leftHeight(cur.right);
            if (leftHeight == rightHeight) {
                // 左子树满：左树节点数 + 当前根 = 2^leftHeight。
                count += 1L << leftHeight;
                cur = cur.right;
            } else {
                // 右子树满且矮一层，数掉它和当前根。
                count += 1L << rightHeight;
                cur = cur.left;
            }
        }
        return (int) count;
    }
}
```

### 3.18 [110. 平衡二叉树](https://leetcode.cn/problems/balanced-binary-tree/)

#### 一句话总结

> 这道题本质是：一次后序同时返回高度和是否失衡的信息。

#### 思路分析

平衡要求每个节点的左右高度差都不超过 1，所以父节点需要先知道孩子的高度和是否平衡。  
让 height(node) 一次给出两类结果：平衡时返回高度，不平衡时返回 -1。空树高度为 0。  
先求左右结果；任何一边为 -1，或两边高度差超过 1，就返回 -1；否则返回 max + 1。这样高度不用反复重算。

#### 方法选择

推荐后序递归，孩子先报告高度。迭代用单栈后序＋高度表模拟返回值，展示“栈只控制顺序，Map 保存子问题答案”。

递归三部曲：① 返回高度或失衡标记 −1；② 空高度 0；③ 孩子为 −1 或高度差超过 1，返回 −1，否则返回较大高度＋1。

#### 解题模板

看到“每个节点都满足子树属性” → 后序合并，并用特殊返回值携带失败。时间 O(n)，递归 O(h)，下述迭代因高度表为 O(n) 空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public boolean isBalanced(TreeNode root) {
        return height(root) != -1;
    }

    // ① 平衡时返回高度，不平衡时返回 -1；一次递归同时回答两件事。
    private int height(TreeNode node) {
        // ② 空树高度为 0，并且平衡。
        if (node == null) {
            return 0;
        }
        // ③ 先拿孩子结果；发现失衡就向上传 -1，否则合成当前高度。
        int leftHeight = height(node.left);
        // 孩子已失衡，父节点也必然失衡，无需再算另一边。
        if (leftHeight == -1) {
            return -1;
        }
        int rightHeight = height(node.right);
        if (rightHeight == -1 || Math.abs(leftHeight - rightHeight) > 1) {
            return -1;
        }
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public boolean isBalanced(TreeNode root) {
        // 递归用返回值传高度；这里用 Map 存已完成子树的高度。
        Map<TreeNode, Integer> heights = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        TreeNode lastVisited = null;
        while (cur != null || !stack.isEmpty()) {
            if (cur != null) {
                stack.push(cur);
                cur = cur.left;
            } else {
                TreeNode node = stack.peek();
                // 右树未完成先处理右树；两边完成后才合成当前高度。
                if (node.right != null && node.right != lastVisited) {
                    cur = node.right;
                } else {
                    // 此时两个孩子已处理完，空孩子默认高度 0。
                    int leftHeight = heights.getOrDefault(node.left, 0);
                    int rightHeight = heights.getOrDefault(node.right, 0);
                    if (Math.abs(leftHeight - rightHeight) > 1) {
                        return false;
                    }
                    heights.put(node, Math.max(leftHeight, rightHeight) + 1);
                    lastVisited = stack.pop();
                }
            }
        }
        return true;
    }
}
```

### 3.19 [257. 二叉树的所有路径](https://leetcode.cn/problems/binary-tree-paths/)

#### 一句话总结

> 这道题本质是：维护从根到当前节点的路径，在叶子处保存快照。

#### 思路分析

要输出所有根到叶路径，就从根往下走，边走边把节点追加到当前路径；到叶子才保存。  
递归参数带当前节点、正在拼接的 path 和结果列表；空节点返回。进入时记住旧长度，再加当前值，处理孩子，最后恢复旧长度。  
恢复是为了让兄弟分支从同一条父路径出发，不能带上上一支的节点。保存时用 toString() 生成独立字符串。

#### 方法选择

递归前序：孩子的路径必须先包含当前节点。迭代用“节点＋路径”状态模拟，不依赖隐式调用栈。

递归三部曲：① 当前节点、共享路径、结果；② 空返回，叶子保存完整路径；③ 记录旧长度、追加当前值、递归孩子、恢复旧长度。

#### 解题模板

看到“所有根到叶路径” → 前序＋回溯＋叶子快照。令 L 为输出总字符数，递归时间 O(n + L)、辅助空间 O(h)（整数字符长度视为常数）；下述迭代因复制前缀，最坏 O(nh) 时间、O(h²) 辅助空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        traversal(root, new StringBuilder(), result);
        return result;
    }

    // ① path 是从根走到当前节点前的共享路径，result 保存完整答案。
    private void traversal(TreeNode node, StringBuilder path, List<String> result) {
        // ② 空节点没有值可追加，直接返回。
        if (node == null) {
            return;
        }
        // ③ 先记旧长度、加自己；孩子结束后恢复，兄弟分支才不会串路径。
        int oldLength = path.length();
        if (oldLength > 0) {
            path.append("->");
        }
        path.append(node.val);
        if (node.left == null && node.right == null) {
            // 到叶子才是一条完整路径；toString 保存独立结果。
            result.add(path.toString());
        } else {
            traversal(node.left, path, result);
            traversal(node.right, path, result);
        }
        // 回到进入前的父路径，防止左分支内容混入右分支。
        path.setLength(oldLength);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    private static class State {
        TreeNode node;
        // 每个栈状态带独立字符串路径，所以不需要共享路径的撤销。
        String path;

        State(TreeNode node, String path) {
            this.node = node;
            this.path = path;
        }
    }

    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Deque<State> stack = new ArrayDeque<>();
        stack.push(new State(root, String.valueOf(root.val)));
        while (!stack.isEmpty()) {
            State state = stack.pop();
            TreeNode node = state.node;
            // 到叶子才收集完整的根到叶路径。
            if (node.left == null && node.right == null) {
                result.add(state.path);
            }
            if (node.right != null) {
                String nextPath = state.path + "->" + node.right.val;
                stack.push(new State(node.right, nextPath));
            }
            if (node.left != null) {
                String nextPath = state.path + "->" + node.left.val;
                stack.push(new State(node.left, nextPath));
            }
        }
        return result;
    }
}
```

### 3.20 [404. 左叶子之和](https://leetcode.cn/problems/sum-of-left-leaves/)

#### 一句话总结

> 这道题本质是：同时满足“是左孩子”和“是叶子”才计入答案。

#### 思路分析

先分清两个条件：“左孩子”且“叶子”。只看节点自己，无法知道它是不是左孩子，所以从父节点检查。  
递归返回当前子树内部的左叶子总和；空树为 0。左孩子若是叶子直接取值，否则继续递归左边。  
右子树的根不是左孩子，但它内部仍可能有左叶子，所以还要加上递归右子树的结果。

#### 方法选择

递归后序汇总各子树贡献，当前节点直接识别自己的左叶子；迭代用栈做同样的局部判断。

递归三部曲：① 返回当前子树内所有左叶子的和；② 空为 0；③ 左孩子若为叶子直接取值，否则递归左树，再加右树的内部左叶子和。

#### 解题模板

看到“节点属性依赖父子关系” → 从父节点判断或传方向参数。时间 O(n)，两法 O(h) 空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回当前子树内部所有左叶子的和，不把当前根自动算进去。
    public int sumOfLeftLeaves(TreeNode root) {
        // ② 空树贡献为 0。
        if (root == null) {
            return 0;
        }
        // ③ 从父节点认出左叶子；不是叶子就继续找，再加右树内部贡献。
        int leftSum;
        if (isLeaf(root.left)) {
            leftSum = root.left.val;
        } else {
            leftSum = sumOfLeftLeaves(root.left);
        }
        // 右孩子本身不计入，但右子树内部仍可能有左叶子。
        return leftSum + sumOfLeftLeaves(root.right);
    }

    private boolean isLeaf(TreeNode node) {
        return node != null && node.left == null && node.right == null;
    }
}
```

```Java
            return 0;

            // 从父节点检查左孩子，必须同时满足“在左边”和“是叶子”。

            }
            if (node.right != null) {
                stack.push(node.right);
            }
            if (node.left != null) {
                stack.push(node.left);
            }
        }
        return sum;
    }
}
```

### 3.21 [513. 找树左下角的值](https://leetcode.cn/problems/find-bottom-left-tree-value/)

#### 一句话总结

> 这道题本质是：在最大深度中选择第一个从左到右出现的节点。

#### 思路分析

题目要的是“最深层的第一个节点”，不是沿左指针走到头。先确定深度，再在这一深度保留最左。  
递归先左后右，带 depth；第一次到达更深层时更新答案，同层后来的节点不覆盖它，所以比较必须用 >。空节点返回。  
队列法每层记下队首值，越往下越覆盖，最终保留下来的就是最底层最左值。

#### 方法选择

递归前序携带深度，严格 `depth > deepest` 保留同层第一个；BFS 按层覆盖答案。本题保证根非空。

递归三部曲：① 节点与深度，更新字段答案；② 空返回；③ 发现新深度时记录当前值，再左、右递归。

#### 解题模板

看到“最深层最左/右” → 深度优先的首次规则，或 BFS 边界项。时间 O(n)，空间 DFS O(h)、BFS O(w)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    private int deepest;

    private int answer;

    public int findBottomLeftValue(TreeNode root) {
        deepest = -1;
        answer = root.val;
        traversal(root, 0);
        return answer;
    }

    // ① depth 是当前层；deepest 和 answer 记录已见最深层及其首节点。
    private void traversal(TreeNode node, int depth) {
        // ② 空节点不更新答案。
        if (node == null) {
            return;
        }
        // ③ 先左后右，只在更深时更新；同层后来的节点不能覆盖最左值。
        if (depth > deepest) {
            deepest = depth;
            answer = node.val;
        }
        traversal(node.left, depth + 1);
        traversal(node.right, depth + 1);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public int findBottomLeftValue(TreeNode root) {
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int result = root.val;
        while (!queue.isEmpty()) {
            // 先固定本层数量；本轮新入队的孩子留到下一层处理。
            int levelSize = queue.size();
            // 每层开始时队首是本层最左节点；更深一层会覆盖答案。
            result = queue.peek().val;
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }
        return result;
    }
}
```

### 3.22 [112. 路径总和](https://leetcode.cn/problems/path-sum/)

#### 一句话总结

> 这道题本质是：把目标逐层减去当前值，在叶子处判断是否恰好消耗完。

#### 思路分析

只问“有没有一条”，就不必保存所有路径。从根往下走，每经过一个节点，就从目标里扣掉它的值。  
exists(node, remaining) 表示：从当前节点走到某个叶子，能否凑出 remaining。空节点返回 false；到叶子才检查 remaining == node.val。  
非叶子把 remaining - node.val 交给孩子，左或右成功即可。节点可能为负，剩余值为负也不能直接剪枝。

#### 方法选择

前序消费当前值，再把剩余目标交给孩子；返回值通过逻辑或汇总并短路。迭代保存节点与到达该节点之前的剩余目标。

递归三部曲：① 当前子树是否有根到叶路径满足 remaining；② 空 false，叶子判断 remaining 是否等于节点值；③ 减去当前值，判断左或右是否存在。

#### 解题模板

看到“存在一条根到叶路径” → DFS 带剩余目标＋叶子判定＋短路。时间 O(n)，两法 O(h) 空间；内部使用 long 避免连续减法溢出。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        return exists(root, targetSum);
    }

    // ① remaining 是当前节点到叶子还需凑出的和，尚未扣当前值。
    private boolean exists(TreeNode node, long remaining) {
        // ② 空树没有根到叶路径，所以返回 false。
        if (node == null) {
            return false;
        }
        // ③ 到叶子才判成功；非叶子扣掉自己，把剩余任务交给任一孩子。
        if (node.left == null && node.right == null) {
            return remaining == node.val;
        }
        // 数字按值传递，每个孩子拿相同余量，不需要手动恢复。
        long nextRemaining = remaining - node.val;
        // 任一侧找到即可；|| 会在左侧成功时停止搜索。
        return exists(node.left, nextRemaining) || exists(node.right, nextRemaining);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    private static class State {
        TreeNode node;
        // 保存到达当前节点之前的余量，弹出时再扣当前值。
        long remaining;

        State(TreeNode node, long remaining) {
            this.node = node;
            this.remaining = remaining;
        }
    }

    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) {
            return false;
        }
        Deque<State> stack = new ArrayDeque<>();
        stack.push(new State(root, targetSum));
        while (!stack.isEmpty()) {
            State state = stack.pop();
            TreeNode node = state.node;
            long remaining = state.remaining - node.val;
            // 扣完且到叶子才成功；非叶子余量为 0 也不能提前返回。
            if (node.left == null && node.right == null && remaining == 0) {
                return true;
            }
            if (node.right != null) {
                stack.push(new State(node.right, remaining));
            }
            if (node.left != null) {
                stack.push(new State(node.left, remaining));
            }
        }
        return false;
    }
}
```

### 3.23 [113. 路径总和 II（关联补充）](https://leetcode.cn/problems/path-sum-ii/)

#### 一句话总结

> 这道题本质是：在路径总和判断之外，保存每一条满足条件的路径快照。

#### 思路分析

和 112 一样向下扣目标，但这次要保存所有满足条件的路径，找到一条后还要继续。  
递归带 remaining 和共享 path：进入时加当前值、扣剩余目标；到叶子且恰好扣完，就复制 path 放进结果。空节点返回。  
左右都处理后删除当前路径末尾，让兄弟分支回到父路径。数字参数按值传递不用恢复，共享列表要恢复；保存答案必须复制。

#### 方法选择

推荐前序＋显式回溯。迭代用“进入/退出”事件模拟调用栈，共享一条 path，避免每次分支都复制前缀。

递归三部曲：① 节点、剩余目标、当前路径、结果；② 空返回，叶子且余量为 0 则复制路径；③ 加入当前、递归两侧、删除最后一个元素。

#### 解题模板

看到“输出所有满足条件的路径” → 必须遍历所有候选，结果复制、工作路径撤销。令 L 为结果包含的节点总数，时间 O(n + L)，两法 O(h) 辅助空间。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        traversal(root, targetSum, new ArrayList<>(), result);
        return result;
    }

    // ① remaining 尚未扣当前值；path 是共享的当前路径，结果要复制。
    private void traversal(TreeNode node, long remaining,
            List<Integer> path, List<List<Integer>> result) {
        // ② 空节点没有路径可继续，直接返回。
        if (node == null) {
            return;
        }
        // ③ 加自己、扣目标，到合格叶子存快照；两边搜索完后撤销当前节点。
        path.add(node.val);
        long nextRemaining = remaining - node.val;
        if (node.left == null && node.right == null && nextRemaining == 0) {
            // 保存副本；直接放 path，后续撤销会把已有答案改掉。
            result.add(new ArrayList<>(path));
        }
        traversal(node.left, nextRemaining, path, result);
        traversal(node.right, nextRemaining, path, result);
        // path 被各层共享，返回前删掉自己，恢复父路径。
        path.remove(path.size() - 1);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    private static class Frame {
        TreeNode node;
        long remaining;
        // false 模拟进入递归，true 模拟返回时撤销路径。
        boolean exit;

        Frame(TreeNode node, long remaining, boolean exit) {
            this.node = node;
            this.remaining = remaining;
            this.exit = exit;
        }
    }

    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        List<Integer> path = new ArrayList<>();
        Deque<Frame> stack = new ArrayDeque<>();
        stack.push(new Frame(root, targetSum, false));
        while (!stack.isEmpty()) {
            Frame frame = stack.pop();
            // 退出时移除当前节点，恢复父路径后再处理兄弟分支。
            if (frame.exit) {
                path.remove(path.size() - 1);
                continue;
            }
            TreeNode node = frame.node;
            path.add(node.val);
            long remaining = frame.remaining - node.val;
            if (node.left == null && node.right == null && remaining == 0) {
                // 答案保存副本，避免退出事件撤销共享 path 时破坏结果。
                result.add(new ArrayList<>(path));
            }
            // 退出事件最后执行，确保左右子树处理期间父路径一直存在。
            stack.push(new Frame(node, remaining, true));
            if (node.right != null) {
                stack.push(new Frame(node.right, remaining, false));
            }
            if (node.left != null) {
                stack.push(new Frame(node.left, remaining, false));
            }
        }
        return result;
    }
}
```

### 3.24 [106. 从中序与后序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/)

#### 一句话总结

> 这道题本质是：用后序定位根，用中序确定左右子树的成员与大小。

#### 思路分析

先从后序最后一个值找到根；根在中序中的位置，又把节点分成左子树和右子树。左右两部分继续做同样的事。

区间统一用 [left, right)：根是 postorder[postRight - 1]；左子树节点数 = pivot - inLeft，所以后序前 leftSize 个归左，余下去掉根后归右。  
build 返回这个区间建好的子树根；空区间返回 null，非空建根，再把两次递归结果接到 root.left、root.right。中序下标表避免每次重新找根。

| 子树 | 中序区间 | 后序区间 |
|-|-|-|
| 左 | `[inLeft, pivot)` | `[postLeft, postLeft + leftSize)` |
| 右 | `[pivot + 1, inRight)` | `[postLeft + leftSize, postRight - 1)` |

#### 方法选择

递归先创建根，再挂接左右子树，是前序式构造；不要因输入是后序就误判处理顺序。迭代逆向读后序，顺序为“根右左”；逆向中序是“右根左”，用于判断何时从右侧回到祖先并转左。

递归三部曲：① 两个序列的对应区间，返回构造出的根；② 空区间返回 null；③ 取根、找中序分割点、按大小切后序，递归接回左右孩子。

#### 解题模板

看到“中序＋另一种遍历重建，节点值唯一” → 定根＋中序切分。递归时间 O(n)、空间 O(n)（索引表＋栈）；迭代时间 O(n)、空间 O(h)。重复值时这个下标映射不能直接使用。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public TreeNode buildTree(int[] inorder, int[] postorder) {
        Map<Integer, Integer> positions = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            positions.put(inorder[i], i);
        }
        return build(postorder, 0, postorder.length, 0, inorder.length, positions);
    }

    // ① 两组 [left, right) 区间描述同一棵子树；返回建好的根。
    private TreeNode build(int[] postorder, int postLeft, int postRight,
            int inLeft, int inRight, Map<Integer, Integer> positions) {
        // ② 空区间没有节点，返回 null 供父节点挂接。
        if (postLeft == postRight) {
            return null;
        }
        // ③ 后序末尾是根；中序定位根后，用左侧节点数切分后序。
        int rootValue = postorder[postRight - 1];
        int pivot = positions.get(rootValue);
        int leftSize = pivot - inLeft;
        TreeNode root = new TreeNode(rootValue);
        // 后序先左后右再根；左区间取前 leftSize 个，右区间排除末尾根。
        root.left = build(postorder, postLeft, postLeft + leftSize,
                inLeft, pivot, positions);
        root.right = build(postorder, postLeft + leftSize, postRight - 1,
                pivot + 1, inRight, positions);
        return root;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public TreeNode buildTree(int[] inorder, int[] postorder) {
        if (postorder.length == 0) {
            return null;
        }
        TreeNode root = new TreeNode(postorder[postorder.length - 1]);
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        // 倒着读后序为根→右→左；倒着读中序为右→根→左。
        int inorderIndex = inorder.length - 1;
        for (int i = postorder.length - 2; i >= 0; i--) {
            TreeNode parent = stack.peek();
            TreeNode child = new TreeNode(postorder[i]);
            // 还没到当前根的中序位置，说明继续构造右侧。
            if (parent.val != inorder[inorderIndex]) {
                parent.right = child;
            } else {
                while (!stack.isEmpty()
                        && stack.peek().val == inorder[inorderIndex]) {
                    parent = stack.pop();
                    inorderIndex--;
                }
                // 匹配中序后弹回祖先，下一节点接最后弹出祖先的左侧。
                parent.left = child;
            }
            stack.push(child);
        }
        return root;
    }
}
```

### 3.25 [105. 从前序与中序遍历序列构造二叉树（关联补充）](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

#### 一句话总结

> 这道题本质是：前序提供根的出现顺序，中序提供子树边界。

#### 思路分析

先从前序第一个值找到根，再到中序里定位根；中序左边归左子树，右边归右子树。  
左子树大小是 pivot - inLeft。前序中根后面先放左子树，所以左起点是 preLeft + 1，右起点要再跳过 leftSize 个节点。  
build 返回当前区间的子树根；中序空区间返回 null，非空建根、递归两侧并接回。区间始终用左闭右开，避免边界混用。

#### 方法选择

递归前序式构造。迭代按前序读入：栈顶尚未匹配中序则进入左子树；连续匹配中序意味着左侧已完成，弹栈回溯，下一节点挂到最后弹出祖先的右侧。

递归三部曲：① 前序起点＋中序半开区间，返回子树根；② 中序空区间返回 null；③ 根为前序起点，计算左大小，左前序起点＋1，右前序起点＋1＋左大小。

#### 解题模板

看到“构造题” → 先明确根来自哪里，再统一区间；仅前序＋后序一般不能唯一确定普通二叉树。时间 O(n)，递归 O(n) 空间，迭代 O(h)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        Map<Integer, Integer> positions = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            positions.put(inorder[i], i);
        }
        return build(preorder, 0, 0, inorder.length, positions);
    }

    // ① preLeft 指向子树根；[inLeft, inRight) 圈定这棵子树的全部节点。
    private TreeNode build(int[] preorder, int preLeft, int inLeft, int inRight,
            Map<Integer, Integer> positions) {
        // ② 中序区间为空，说明这棵子树为空。
        if (inLeft == inRight) {
            return null;
        }
        // ③ 前序起点是根；中序左侧数量决定两边的前序起点。
        TreeNode root = new TreeNode(preorder[preLeft]);
        int pivot = positions.get(root.val);
        int leftSize = pivot - inLeft;
        root.left = build(preorder, preLeft + 1, inLeft, pivot, positions);
        // 跳过前序里的根和整棵左子树，才到右子树起点。
        root.right = build(preorder, preLeft + leftSize + 1,
                pivot + 1, inRight, positions);
        return root;
    }
}
```

### 3.26 [654. 最大二叉树](https://leetcode.cn/problems/maximum-binary-tree/)

#### 一句话总结

> 这道题本质是：区间最大值做根，左右区间递归成子树。

#### 思路分析

题目已经告诉你根怎么选：当前区间的最大值做根；它左边建左子树，右边建右子树。  
build(nums, left, right) 返回 [left, right) 的树根；空区间返回 null。找最大值下标、建根，再递归两侧，切分时不要再次包含这个最大值。  
先掌握这个分治写法。进阶单调栈按从左到右建树：新值更大时，把较小的右链收进它的左边；更大的旧节点把新节点接到右边。

#### 方法选择

先掌握前序式分治构造，再学 O(n) 单调栈。新值比栈顶大时弹出，小节点被新节点覆盖；最后弹出的子树成为新节点左孩子，未弹出的更大栈顶把新节点接作右孩子。

递归三部曲：① 数组半开区间，返回最大树根；② 空区间返回 null；③ 扫描最大下标，创建根，递归左右区间。

#### 解题模板

看到“区间极值作根” → 分治；进一步看到“最近更大元素决定层级” → 单调栈。递归最坏 O(n²) 时间、O(n) 栈；迭代 O(n) 时间、O(n) 栈。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        return build(nums, 0, nums.length);
    }

    // ① 返回 nums[left, right) 构成的最大二叉树根。
    private TreeNode build(int[] nums, int left, int right) {
        // ② 空区间没有节点，返回 null。
        if (left == right) {
            return null;
        }
        // ③ 找区间最大值建根，再递归两侧；根下标不能重复进入子区间。
        int maximumIndex = left;
        for (int i = left + 1; i < right; i++) {
            if (nums[i] > nums[maximumIndex]) {
                maximumIndex = i;
            }
        }
        TreeNode root = new TreeNode(nums[maximumIndex]);
        root.left = build(nums, left, maximumIndex);
        root.right = build(nums, maximumIndex + 1, right);
        return root;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        for (int value : nums) {
            TreeNode node = new TreeNode(value);
            // 新值更大，弹出的较小右链归入新节点左树；最后弹出者是这棵树的根。
            while (!stack.isEmpty() && stack.peek().val < value) {
                node.left = stack.pop();
            }
            if (!stack.isEmpty()) {
                // 留下的栈顶更大且在左边，新节点成为它的右孩子。
                stack.peek().right = node;
            }
            stack.push(node);
        }
        // 栈底是没有更大父节点的最大值，即整棵树的根。
        return stack.peekLast();
    }
}
```

### 3.27 [617. 合并二叉树](https://leetcode.cn/problems/merge-two-binary-trees/)

#### 一句话总结

> 这道题本质是：同步遍历对应位置，重叠则相加，单侧存在则直接保留。

#### 思路分析

两棵树按同一个位置对齐：两边都有节点就相加，只有一边有节点就保留那一边。  
mergeTrees(a, b) 返回合并后的子树根。任一边空，直接返回另一边；否则改 a 的值，再把左右合并结果接回 a。  
必须接回返回值，因为 a 原本空的位置可能由 b 补上。这份写法复用输入节点，会修改第一棵树并可能共享第二棵树的节点。

#### 方法选择

前序先合并当前值，再接回孩子；迭代用节点对保持位置对应。若需要完全独立的新树，必须新建节点并复制单侧子树，不能直接返回输入节点。

递归三部曲：① 两个根，返回合并后的根；② 一侧空，返回另一侧；③ 值相加，递归并接回左右孩子。

#### 解题模板

看到“双树逐位置运算” → 双指针递归，先决定是否复用节点。最坏时间 O(n₁ + n₂)，实际只深入双方都非空的区域；递归和 DFS 栈空间上界 O(h₁ + h₂)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 两个参数表示同一位置的子树；返回合并后的根。
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        // ② 一边为空，直接复用另一边；两边都空自然返回 null。
        if (root1 == null) {
            return root2;
        }
        // 第二棵空，第一棵原样保留；这里不会新建独立副本。
        if (root2 == null) {
            return root1;
        }
        // ③ 两边都有才相加；孩子可能换根，必须接回两次递归的返回值。
        root1.val += root2.val;
        root1.left = mergeTrees(root1.left, root2.left);
        root1.right = mergeTrees(root1.right, root2.right);
        return root1;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        if (root1 == null) {
            return root2;
        }
        if (root2 == null) {
            return root1;
        }
        Deque<TreeNode[]> stack = new ArrayDeque<>();
        // 每对节点代表两棵树中的同一位置，值写回第一棵。
        stack.push(new TreeNode[] {root1, root2});
        while (!stack.isEmpty()) {
            TreeNode[] pair = stack.pop();
            TreeNode target = pair[0];
            TreeNode source = pair[1];
            target.val += source.val;
            if (target.left == null) {
                // 目标侧为空就直接复用来源侧；两边都有才继续成对处理。
                target.left = source.left;
            } else if (source.left != null) {
                stack.push(new TreeNode[] {target.left, source.left});
            }
            if (target.right == null) {
                target.right = source.right;
            } else if (source.right != null) {
                stack.push(new TreeNode[] {target.right, source.right});
            }
        }
        return root1;
    }
}
```

### 3.28 [700. 二叉搜索树中的搜索](https://leetcode.cn/problems/search-in-a-binary-search-tree/)

#### 一句话总结

> 这道题本质是：利用子树值域，每次排除不可能包含目标的一侧。

#### 思路分析

先利用 BST 的大小关系：目标比根小，只可能在左边；比根大，只可能在右边。  
searchBST 返回找到的节点。当前为空说明没有找到，返回 null；值相等就返回当前节点；否则直接返回选中分支的搜索结果。  
只走一条路径，不需要同时遍历两边；迭代把这次递归换成移动 cur。

#### 方法选择

递归或 while 均可，迭代更省空间。它是有方向的单分支搜索，不是为了得到有序序列的中序遍历。

递归三部曲：① 返回当前子树中目标节点，找不到为 null；② 空或命中立即返回；③ 目标小则左，大则右，返回该分支答案。

#### 解题模板

看到“BST 查一个值” → 比较根值后只走一侧。时间 O(h)，递归 O(h) 空间，迭代 O(1)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回目标节点本身；没找到返回 null。
    public TreeNode searchBST(TreeNode root, int val) {
        // ② 空树表示没找到，值相等则已经命中，都无需继续。
        if (root == null || root.val == val) {
            return root;
        }
        // ③ BST 排除另一侧，只递归可能含目标的一边，并把结果返回。
        if (val < root.val) {
            return searchBST(root.left, val);
        }
        return searchBST(root.right, val);
    }
}
```

### 3.29 [98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)

#### 一句话总结

> 这道题本质是：验证全局有序约束，而不只是父子之间的大小。

#### 思路分析

BST 要求的是整棵左子树都小于根、整棵右子树都大于根，只比父子会漏掉违反祖先限制的节点。  
先想中序：合法 BST 的值应该严格递增。递归先检查左边，再把当前值与刚访问的 previous 比较，最后检查右边；空树为真。  
另一种想法是向下带允许范围 (lower, upper)：走左边缩小上界，走右边提高下界，当前值必须严格落在范围内。

#### 方法选择

递归和迭代中序均比较前驱；补充边界递归，它在当前节点检查祖先约束后下降，是前序式检查。不要说“BST 属性必须用中序”，边界法同样成立。

递归三部曲：① `validate(node)` 检查子树，并维护已访问前驱；② 空 true；③ 左合法后比较当前与前驱，再更新前驱并检查右。边界法则返回当前子树是否全部处于 `(lower, upper)`。

#### 解题模板

看到“合法 BST” → 中序严格递增或祖先边界。相等必须失败；字段入口重置；边界用 long。时间 O(n)，三法 O(h) 空间。

#### Java代码

##### 方法1：递归：中序比较前驱

```Java
import java.util.*;

class Solution {
    private TreeNode previous;

    public boolean isValidBST(TreeNode root) {
        // 每次入口重置，避免上次调用的前驱影响本次判断。
        previous = null;
        return validate(root);
    }

    // ① 检查当前子树；previous 保存整个中序过程的上一个节点。
    private boolean validate(TreeNode node) {
        // ② 空树不会破坏严格递增，返回 true。
        if (node == null) {
            return true;
        }
        // ③ 先左、再比当前与前驱、最后右；任一步失败就停止。
        if (!validate(node.left)) {
            return false;
        }
        // 必须严格递增；相等也不是本题的合法 BST。
        if (previous != null && node.val <= previous.val) {
            return false;
        }
        previous = node;
        return validate(node.right);
    }
}
```

##### 方法2：递归：传递上下界

```Java
import java.util.*;

class Solution {
    public boolean isValidBST(TreeNode root) {
        // 边界用 long，允许节点本身取 int 的最小或最大值。
        return within(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    // ① 当前子树所有值必须在 (lower, upper) 内，边界来自全部祖先。
    private boolean within(TreeNode node, long lower, long upper) {
        // ② 空树没有违反边界的节点，返回 true。
        if (node == null) {
            return true;
        }
        // ③ 先检查当前值；左边收紧上界，右边收紧下界。
        if (node.val <= lower || node.val >= upper) {
            return false;
        }
        return within(node.left, lower, node.val)
                && within(node.right, node.val, upper);
    }
}
```

##### 方法3：迭代

```Java

    public boolean isValidBST(TreeNode root) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        TreeNode previous = null;
        while (cur != null || !stack.isEmpty()) {
            // 沿左链压栈，保存之后返回并处理中间节点的位置。
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;

            // 中序轮到当前值；必须大于前驱，否则立即失败。
            cur = stack.pop();
            if (previous != null && cur.val <= previous.val) {
                return false;

            previous = cur;
            cur = cur.right;
```

### 3.30 [530. 二叉搜索树的最小绝对差](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/)

#### 一句话总结

> 这道题本质是：有序序列的最小差一定出现在相邻元素之间。

#### 思路分析

BST 的中序是有序的，最小差只会出现在相邻两个值之间，所以不用两两比较。  
递归先走左边；轮到当前节点时，它前面紧挨着的是 previous，只计算当前值减 previous 的值，再把 previous 更新为当前，最后走右边。  
空节点返回；第一个节点没有前驱，跳过比较。previous 记录的是中序上一个节点，不是父节点。

#### 方法选择

递归中序与迭代中序完全同一处理逻辑：比较前驱、更新答案、移动前驱。不必先存完整数组。

递归三部曲：① 遍历当前子树，维护前驱与最小差；② 空返回；③ 左递归、计算当前与前驱差、更新前驱、右递归。

#### 解题模板

看到“BST 上的相邻数值关系” → 中序＋previous。时间 O(n)，空间 O(h)。本题保证至少两个节点，值范围使差可用 int；通用大范围数据应先转 long 再减。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    private TreeNode previous;

    private int minimum;

    public int getMinimumDifference(TreeNode root) {
        previous = null;
        minimum = Integer.MAX_VALUE;
        traversal(root);
        return minimum;
    }

    // ① 中序访问当前子树；previous 和 minimum 保存相邻比较状态。
    private void traversal(TreeNode node) {
        // ② 空节点没有数值可比较。
        if (node == null) {
            return;
        }
        // ③ 先完成左边，当前才紧挨 previous；比较后更新前驱，再走右边。
        traversal(node.left);
        if (previous != null) {
            minimum = Math.min(minimum, node.val - previous.val);
        }
        // 比较完成再更新，不能先覆盖前驱再求差。
        previous = node;
        traversal(node.right);
    }
}
```

##### 方法2：迭代

```Java
        while (cur != null || !stack.isEmpty()) {

                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            // 有序序列只需比较相邻值；第一个没有前驱。
            if (previous != null) {
                result = Math.min(result, cur.val - previous.val);
            }
            // 比较后再更新前驱，供下一个中序节点使用。
            previous = cur;
            cur = cur.right;
        }
        return result;
    }
```

### 3.31 [501. 二叉搜索树中的众数](https://leetcode.cn/problems/find-mode-in-binary-search-tree/)

#### 一句话总结

> 这道题本质是：把中序有序序列中的连续相等段转换为频次统计。

#### 思路分析

中序把相同值放在一起，所以找最高频率就变成了统计连续相同的一段。  
递归按“左→当前→右”访问；空节点返回。当前值等于 previous 就让 count 加 1，否则从 1 开始。  
count 超过历史最大次数时清空旧答案并记录当前值；相等时追加。入口重置状态，避免同一个 Solution 再调用时混入旧结果。

#### 方法选择

中序使相同值相邻，递归和迭代共享同一个 `record` 逻辑。入口必须重置全部字段。本题允许重复，区别于 98 的严格 BST。

递归三部曲：① 遍历子树并更新连续段状态；② 空返回；③ 左递归、统计当前值、右递归。

#### 解题模板

看到“有序输入的频次” → 连续段计数，通常无需 Map。时间 O(n)。栈 O(h)；下述单遍可变候选列表最坏 O(n)，因为早期候选可能最后被清空，不能一概把它算作最终输出。严格压缩这部分空间可两遍遍历，先求最高频次与答案数量，再定长填充。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    private Integer previous;

    private int count;

    private int maximumCount;

    private List<Integer> modes;

    private void reset() {
        previous = null;
        count = 0;
        maximumCount = 0;
        modes = new ArrayList<>();
    }

    public int[] findMode(TreeNode root) {
        // 新一次遍历必须清空上次调用留下的计数和答案。
        reset();
        traversal(root);
        return toArray();
    }

    // ① 中序访问当前子树，连续计数和众数由共享字段维护。
    private void traversal(TreeNode node) {
        // ② 空节点不参与频次统计。
        if (node == null) {
            return;
        }
        // ③ 左→当前→右让相同值连续出现；record 只需统计连续段。
        traversal(node.left);
        record(node.val);
        traversal(node.right);
    }

    private void record(int value) {
        // 中序中相同值连续：相同就续段，不同就从 1 重新计数。
        if (previous != null && previous == value) {
            count++;
        } else {
            count = 1;
        }
        if (count > maximumCount) {
            maximumCount = count;
            // 出现更高频率，原来的候选都不再是众数。
            modes.clear();
            modes.add(value);
        // 达到相同最高频率，当前值也应列入答案。
        } else if (count == maximumCount) {
            modes.add(value);
        }
        previous = value;
    }

    private int[] toArray() {
        int[] result = new int[modes.size()];
        for (int i = 0; i < modes.size(); i++) {
            result[i] = modes.get(i);
        }
        return result;
    }
}
```

### 3.32 [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

#### 一句话总结

> 这道题本质是：向上汇报目标出现的位置，第一个汇合处就是最近公共祖先。

#### 思路分析

从某个节点看，p、q 要么分在左右两边，要么都在一边，要么当前节点本身就是一个目标。先让两边报告发现了什么。  
递归返回“发现的目标，或已经确定的公共祖先”；空返回 null，遇到 p 或 q 返回自己。题目保证两个目标都存在，所以目标本身也可能是祖先。  
左右都非空，当前节点就是汇合点；只有一边非空，把那一边的结果继续向上传；都空就返回 null。

#### 方法选择

后序：必须先知道两边的发现结果。遇到 p/q 提前返回，是因为题目保证两者都存在，且节点允许是自己的祖先。迭代建父节点表，再求祖先链首次交点。

递归三部曲：① 返回当前子树中发现的目标或已确定的 LCA；② 空返回 null，当前为 p/q 返回当前；③ 左右都有返回当前，只有一侧有返回那侧，两侧都无返回 null。

#### 解题模板

看到“普通树两个目标的汇合” → 后序返回发现信息。按节点引用比较，不能只比较值。时间 O(n)，递归 O(h)，迭代 O(n) 空间。若不保证目标存在，递归需另外验证存在性或返回计数。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回本子树发现的目标，或已经确定的公共祖先；未发现返回 null。
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // ② 空返回 null；遇到 p/q 返回自己，因为目标也可以是祖先。
        if (root == null || root == p || root == q) {
            return root;
        }
        // ③ 先让左右报告；两边都有则在当前汇合，一边有则继续向上传。
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        // 左右各有目标（或已确定结果），它们在当前节点汇合。
        if (left != null && right != null) {
            return root;
        }
        if (left != null) {
            return left;
        }
        return right;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root,
            TreeNode p, TreeNode q) {
        if (root == null) {
            return null;
        }
        // 先记录父节点，后面才能从目标向上走。
        Map<TreeNode, TreeNode> parents = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        parents.put(root, null);
        stack.push(root);
        while (!stack.isEmpty() && (!parents.containsKey(p) || !parents.containsKey(q))) {
            TreeNode node = stack.pop();
            if (node.left != null) {
                parents.put(node.left, node);
                stack.push(node.left);
            }
            if (node.right != null) {
                parents.put(node.right, node);
                stack.push(node.right);
            }
        }
        if (!parents.containsKey(p) || !parents.containsKey(q)) {
            return null;
        }
        // 保存 p 的整条祖先链，再让 q 向上找第一个交点。
        Set<TreeNode> ancestors = new HashSet<>();
        TreeNode cur = p;
        while (cur != null) {
            ancestors.add(cur);
            cur = parents.get(cur);
        }
        cur = q;
        // q 从下往上，第一个交点就是最近公共祖先。
        while (!ancestors.contains(cur)) {
            cur = parents.get(cur);
        }
        return cur;
    }
}
```

### 3.35 [450. 删除二叉搜索树中的节点](https://leetcode.cn/problems/delete-node-in-a-bst/)

#### 一句话总结

> 这道题本质是：删除目标后，为原位置选择仍满足 BST 顺序的替代根。

#### 思路分析

先按 BST 规则找到目标，再问“删掉后谁接替它”：无孩子返回空；只有一个孩子返回那个孩子。  
两个孩子都有时，选右子树最小值接替。它大于左边所有值，且不大于右边剩余值；它没有左孩子，随后删除它就变成简单情况。  
递归返回删除后的子树根，所以父节点要接回；空节点表示没找到。复制后继值后，还要删除原后继，避免出现两个相同值。

| 情况 | 返回/替换结果 |
|-|-|
| 没找到 | 保留原结构 |
| 无左孩子 | 用右孩子替代，右也空即删除叶子 |
| 无右孩子 | 用左孩子替代 |
| 两个孩子 | 复制后继值，再删除原后继节点 |

#### 方法选择

递归先判断当前关系再下降，返回修改后子树根；关键是结构分类，不必硬套单一遍历名。迭代保留 parent，以便修改父节点的孩子引用；删除根单独接收 replacement。

递归三部曲：① 返回删除 key 后的子树根；② 空返回 null；③ 未命中只改一侧，命中按孩子情况替换，最后返回新根。

#### 解题模板

看到“删除树节点” → 先列孩子数量，再确定谁接替。时间 O(h)，递归 O(h) 空间，迭代 O(1)。以下采用改值方案；若外部业务依赖节点对象身份，需改成真正移动节点。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回删除后的子树根；删掉当前根时，返回的节点可能改变。
    public TreeNode deleteNode(TreeNode root, int key) {
        // ② 空位置说明没找到目标，返回 null。
        if (root == null) {
            return null;
        }
        // ③ 未命中只改一侧；命中后按孩子数量，决定由谁接替当前根。
        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        } else {
            // 无孩子或只有右孩子：由右边接替；返回值可能为 null。
            if (root.left == null) {
                return root.right;
            }
            // 只有左孩子：由左边接替。
            if (root.right == null) {
                return root.left;
            }
            // 两个孩子都在：右子树最小节点是中序后继，且没有左孩子。
            TreeNode successor = root.right;
            while (successor.left != null) {
                successor = successor.left;
            }
            root.val = successor.val;
            // 复制后继值后，删掉原后继，避免重复，并接回修改后的右树。
            root.right = deleteNode(root.right, successor.val);
        }
        return root;
    }
}
```

```Java
        // 迭代没有返回值接回机制，需要记住父节点来改孩子引用。
        TreeNode parent = null;
        TreeNode cur = root;
        while (cur != null && cur.val != key) {
            parent = cur;
            if (key < cur.val) {
                cur = cur.left;
            } else {
                cur = cur.right;
            }
        }
        if (cur == null) {
            return root;
        }
        // 两个孩子：复制右侧最小值，再把待删除对象改成后继。
        if (cur.left != null && cur.right != null) {
            TreeNode successorParent = cur;
            TreeNode successor = cur.right;
            while (successor.left != null) {
                successorParent = successor;
                successor = successor.left;
            }
            cur.val = successor.val;
            parent = successorParent;
            cur = successor;
        }
        // 后继没有左孩子；一般待删节点至多一个孩子，由非空侧接替。
        TreeNode replacement = cur.left;
        if (replacement == null) {
            replacement = cur.right;
        }
        // 删的是整棵树根，直接返回 replacement 作为新根。
        if (parent == null) {
            return replacement;
        }
        if (parent.left == cur) {
            parent.left = replacement;
        } else {
            parent.right = replacement;
        }
        return root;
    }
}
```

### 3.36 【重要，很妙】[669. 修剪二叉搜索树](https://leetcode.cn/problems/trim-a-binary-search-tree/)

#### 一句话总结

> 这道题本质是：按 BST 的整棵子树值域剪枝，同时保留可能合法的另一侧后代。

#### 思路分析

先看当前值能否保留：小于 low，当前和整棵左子树都太小，但右边可能合法；大于 high 则对称。  
trimBST 返回修剪后的子树根。空返回 null；太小就返回修剪后的右树，太大就返回修剪后的左树，不能直接把整棵都置空。  
当前值合法时保留它，再把左右修剪结果接回。形成习惯：根可能被删除的树操作，都用返回值告诉父节点新的根是谁。

#### 方法选择

递归先判断当前值域，属于自顶向下剪枝，并接回修剪后的子树。迭代先找到合法根，再分别沿左边界移除过小节点、沿右边界移除过大节点。

递归三部曲：① 返回保留 `[low, high]` 后的子树根；② 空返回 null；③ 小于 low 返回修剪后的右树，大于 high 返回修剪后的左树，合法则接回两侧。

#### 解题模板

看到“BST 区间过滤” → 利用整侧不可能合法，保留另一侧递归结果。递归最坏 O(n) 时间、O(h) 空间；下述边界迭代仅沿两条边界路径移动，O(h) 时间、O(1) 空间，不含运行时垃圾回收成本。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    // ① 返回保留 [low, high] 后的子树根，根可能被替换。
    public TreeNode trimBST(TreeNode root, int low, int high) {
        // ② 空树无需修剪，返回 null。
        if (root == null) {
            return null;
        }
        // ③ 利用 BST 舍弃整侧；越界时返回仍可能合法的一侧，合法时接回两侧。
        if (root.val < low) {
            // 当前和左侧都太小；右侧可能合法，要递归保留，不能直接返回 null。
            return trimBST(root.right, low, high);
        }
        if (root.val > high) {
            // 当前和右侧都太大；合法节点只可能留在左侧。
            return trimBST(root.left, low, high);
        }
        // 当前合法，接回修剪后的孩子；孩子的根可能已换掉。
        root.left = trimBST(root.left, low, high);
        root.right = trimBST(root.right, low, high);
        return root;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public TreeNode trimBST(TreeNode root, int low, int high) {
        // 先沿可能合法的一侧移动，找到能保留的新根。
        while (root != null && (root.val < low || root.val > high)) {
            if (root.val < low) {
                root = root.right;
            } else {
                root = root.left;
            }
        }
        if (root == null) {
            return null;
        }
        TreeNode cur = root;
        while (cur != null) {
            while (cur.left != null && cur.left.val < low) {
                // 左孩子太小，它和其左侧都丢弃，但右侧可能合法，要接上。
                cur.left = cur.left.right;
            }
            cur = cur.left;
        }
        cur = root;
        while (cur != null) {
            while (cur.right != null && cur.right.val > high) {
                // 右孩子太大，对称地保留它仍可能合法的左侧。
                cur.right = cur.right.left;
            }
            cur = cur.right;
        }
        return root;
    }
}
```

### 3.37 【重要，简明，中序构造】[108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

#### 一句话总结

> 这道题本质是：利用中点把有序区间均匀分成左右子树，主动保证平衡。

#### 思路分析

数组有序，选一个数做根，它左边自然更小、右边自然更大；为了平衡，选中间数，让两边数量接近。  
build 返回 [left, right) 的树根；空区间返回 null。选中点建根，左边递归 [left, middle)，右边递归 [middle + 1, right)。  
每个子区间继续选中点，就能同时保持有序和平衡。输入数组有序，不代表构造代码必须按中序执行；这里先建根，再建两侧。

#### 方法选择

递归前序式构造：先建中点，再构造孩子；迭代用区间任务显式模拟递归。偶数长度选择任一中间值都可以。

递归三部曲：① 数组半开区间，返回平衡 BST 根；② 空区间返回 null；③ 选 `left + (right - left) / 2` 建根，构造 `[left, middle)` 与 `[middle + 1, right)`。

#### 解题模板

看到“有序数组＋平衡树” → 中点分治；与 654 的“极值分割”区分。两法 O(n) 时间、O(log n) 辅助空间，输出新树另需 O(n)。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length);
    }

    // ① 返回 nums[left, right) 构成的平衡 BST 根。
    private TreeNode build(int[] nums, int left, int right) {
        // ② 空区间没有节点，返回 null。
        if (left == right) {
            return null;
        }
        // ③ 有序保证左小右大；选中点让两侧数量接近，再分别建孩子。
        int middle = left + (right - left) / 2;
        TreeNode root = new TreeNode(nums[middle]);
        root.left = build(nums, left, middle);
        root.right = build(nums, middle + 1, right);
        return root;
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    private static class Task {
        TreeNode node;
        int left;
        int right;

        Task(TreeNode node, int left, int right) {
            this.node = node;
            this.left = left;
            this.right = right;
        }
    }

    public TreeNode sortedArrayToBST(int[] nums) {
        if (nums.length == 0) {
            return null;
        }
        TreeNode root = new TreeNode(0);
        Deque<Task> stack = new ArrayDeque<>();
        // 一个任务表示：把指定半开区间建成以 node 为根的子树。
        stack.push(new Task(root, 0, nums.length));
        while (!stack.isEmpty()) {
            Task task = stack.pop();
            // 当前区间选中点；左右区间分别交给新任务，排除中点。
            int middle = task.left + (task.right - task.left) / 2;
            task.node.val = nums[middle];
            if (middle + 1 < task.right) {
                task.node.right = new TreeNode(0);
                stack.push(new Task(task.node.right, middle + 1, task.right));
            }
            if (task.left < middle) {
                task.node.left = new TreeNode(0);
                stack.push(new Task(task.node.left, task.left, middle));
            }
        }
        return root;
    }
}
```

### 3.38 [538. 把二叉搜索树转换为累加树](https://leetcode.cn/problems/convert-bst-to-greater-tree/)

#### 一句话总结

> 这道题本质是：按值从大到小访问，将有序序列的后缀和写回节点。

#### 思路分析

当前节点需要“原值 + 所有更大值的和”，所以应先访问大值：BST 按右→根→左走，恰好从大到小。  
递归带共享累计和 sum；空节点返回。先处理右子树，再把当前旧值加进 sum 并写回，最后处理左子树。  
轮到当前节点时，sum 已包含之前所有更大值，因此无需再搜索一遍；入口先清零，避免重复调用留下旧状态。

#### 方法选择

递归右中左；迭代沿右链压栈，弹出处理后转左。它是反中序，不是后序。

递归三部曲：① 遍历子树并维护较大值累计和；② 空返回；③ 先右树，累计当前旧值并写回，再左树。

#### 解题模板

看到“BST 中所有更大元素的聚合” → 反中序＋累计状态。入口重置累计和。时间 O(n)，空间 O(h)，修改原树；代码依题目范围用 int 保存累加结果。

#### Java代码

##### 方法1：递归

```Java
import java.util.*;

class Solution {
    private int sum;

    public TreeNode convertBST(TreeNode root) {
        // 每次转换重新开始累计，避免复用 Solution 时带入旧结果。
        sum = 0;
        accumulate(root);
        return root;
    }

    // ① sum 是已访问的更大原值之和；遍历时直接修改节点值。
    private void accumulate(TreeNode node) {
        // ② 空节点没有值可累加。
        if (node == null) {
            return;
        }
        // ③ 右→根→左从大到小；先累加当前旧值再写回，供更小节点使用。
        accumulate(node.right);
        sum += node.val;
        node.val = sum;
        accumulate(node.left);
    }
}
```

##### 方法2：迭代

```Java
import java.util.*;

class Solution {
    public TreeNode convertBST(TreeNode root) {
        int runningSum = 0;
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            // 先沿右链走到底，反中序才能从大到小访问。
            while (cur != null) {
                stack.push(cur);
                cur = cur.right;
            }
            cur = stack.pop();
            // 先加原值再写回，此时累计和已包含所有更大的原值。
            runningSum += cur.val;
            cur.val = runningSum;
            cur = cur.left;
        }
        return root;
    }
}
```

### 4.3 写完代码后的自检

- 递归返回值能否用一句话定义？空节点返回值能否参与父节点运算？

- 修改子树后是否接回返回根？删除根时调用方是否保存了新根？
- 共享路径是否复制结果并撤销修改？同一个对象重复调用时字段是否重置？
- BST 是否只检查了父子关系？能单分支搜索时是否无意义地遍历了两侧？
- 复杂度是否包括哈希表、路径复制和候选集合？是否把 BST 误当成必然平衡？
