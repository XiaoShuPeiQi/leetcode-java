## 61. 131. 分割回文串（回溯）

[力扣题目](https://leetcode.cn/problems/palindrome-partitioning/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0131-palindrome-partitioning/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnZa7TymoXfGIsz0OVqP9OH0)

### 一句话总结

从第一个没被切走的字符开始，枚举这一段的右端点，只沿回文段往下切。

### 拿到这道题的第一思路

**数据结构。** `path` 存当前已经选出的片段，`result` 存完整方案。当前这层只决定「下一段切多长」，用相向双指针判断选中的这一段是不是回文。

**怎么想。** 和第 58 题枚举下一次选哪个数一样，这里枚举下一刀的位置。选定 `s[startIndex..end]` 后，递归处理从 `end + 1` 开始的剩余后缀。

### 关键变量与始终保持的规则

`path` 拼起来刚好是 `startIndex` 之前的前缀，里面每一段都已经通过回文检查。到达串尾时把 `path` 的副本放入 `result`，回到上一层再删掉刚选的那一段。

### 实例走过程

`s = "aab"`。先选 `"a"`，再选 `"a"` 和 `"b"`，收下 `["a","a","b"]`。退回第二个 `a` 时，尝试把末两字切成 `"ab"`，检查失败。退回根层改选 `"aa"`，接上 `"b"`，收下 `["aa","b"]`。最终返回这两种方案。

### Java代码

```java
import java.util.*;

class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> result = new ArrayList<>();
        List<String> path = new ArrayList<>();
        backtracking(s, 0, path, result);
        return result;
    }

    private void backtracking(String s, int startIndex,
            List<String> path, List<List<String>> result) {
        //走到最后了
        if (startIndex == s.length()) {
            result.add(new ArrayList<>(path));
            return;
        }
        for (int end = startIndex; end < s.length(); end++) {
            // 当前段不是回文，换一个段尾。
            if (!isPalindrome(s, startIndex, end)) {
                continue;
            }
            String segment = s.substring(startIndex, end + 1);
            path.add(segment);
            // 从下一段起点继续。
            backtracking(s, end + 1, path, result);
            path.remove(path.size() - 1);
        }
    }
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### 易错点

Java 的 `substring` 右边界是开区间，因此取到 `end` 要写 `end + 1`。一个候选段失败时用 `continue`，后面更长的候选还有可能是回文，例如 `"ab"` 失败后 `"aba"` 可以通过。

### 复杂度

最坏时间 O(n·2ⁿ)。辅助空间 O(n)，用于递归栈和当前路径。输出另计，最坏 O(n·2ⁿ)。

## 62. 51. N 皇后（回溯）

[力扣题目](https://leetcode.cn/problems/n-queens/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0051-n-queens/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnLkD9kqxnC59mridkUKTzvc)

### 一句话总结

每层为一行选一列，同时检查列和两条对角线，递归回来时一起撤销。

### 拿到这道题的第一思路

**数据结构。** `board` 是棋盘。三个布尔数组 `columns`、`diagonals`、`antiDiagonals` 记录冲突。进入下一行之前，当前行只有一个皇后，所以按行递归就处理了同行冲突。

**怎么想。** 在一条对角线上，行和列同增时差值固定，行增列减时和固定。前者用 `row - col + n - 1` 平移到非负下标，后者用 `row + col`。两个下标的取值都是 0 到 2n − 2。

### 关键变量与始终保持的规则

进入 `backtracking(row, ...)` 时，前 `row` 行各有一个皇后，布尔标记与棋盘对应。放置后递归到 `row + 1`。当 `row == n` 时逐行转成字符串保存到 `result`。试下一候选列前，恢复本次写入的棋盘格和三个标记。

### 实例走过程

`n = 4`，列号从 0 开始。第 0 行试列 0，第 1 行试列 2，第 2 行找不到合法列，于是撤销第 1 行的列 2。第 0 行改试列 1 后，能依次放到列序列 `[1,3,0,2]`，保存 `[".Q..","...Q","Q...","..Q."]`。继续搜索会找到列序列 `[2,0,3,1]`，最终返回两块棋盘。

### Java代码

```java
import java.util.*;

class Solution {
    public List<List<String>> solveNQueens(int n) {
        char[][] board = new char[n][n];
        for (char[] row : board) {
            Arrays.fill(row, '.');
        }
        List<List<String>> result = new ArrayList<>();
        boolean[] columns = new boolean[n];
        boolean[] diagonals = new boolean[2 * n - 1];
        boolean[] antiDiagonals = new boolean[2 * n - 1];
        backtracking(0, board, columns, diagonals, antiDiagonals, result);
        return result;
    }

    private void backtracking(int row, char[][] board, boolean[] columns,
            boolean[] diagonals, boolean[] antiDiagonals, List<List<String>> result) {
        int n = board.length;
        if (row == n) {
            List<String> path = new ArrayList<>();
            for (char[] line : board) {
                path.add(new String(line));
            }
            result.add(path);
            return;
        }
        for (int col = 0; col < n; col++) {
            // 同一斜线 row - col 相同。
            int diagonal = row - col + n - 1;
            // 另一方向 row + col 相同。
            int antiDiagonal = row + col;
            if (columns[col] || diagonals[diagonal] || antiDiagonals[antiDiagonal]) {
                continue;
            }
            board[row][col] = 'Q';
            columns[col] = true;
            diagonals[diagonal] = true;
            antiDiagonals[antiDiagonal] = true;
            backtracking(row + 1, board, columns, diagonals, antiDiagonals, result);
            // 撤销皇后和占用标记。
            board[row][col] = '.';
            columns[col] = false;
            diagonals[diagonal] = false;
            antiDiagonals[antiDiagonal] = false;
        }
    }
}
```

### 易错点

想不清斜线下标时，手算 `(0,1)` 和 `(1,2)`，它们的 `row - col` 都是 −1。保存答案时复制每一行，回溯共用的 `board` 之后还要改。

### 复杂度

设有效方案数为 S。每层枚举 n 列，合法的前缀还受列唯一约束，时间上界 O(n·n! + S·n²)。辅助空间 O(n²)，用于棋盘及搜索状态。输出另计 O(S·n²)。

## 63. 35. 搜索插入位置（二分查找）

[力扣题目](https://leetcode.cn/problems/search-insert-position/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0035-search-insert-position/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnYTut6TN6aHFLy1XJQ7WKpJ)

### 一句话总结

有序且无重复，找到就返回下标，找不到时返回二分结束的 `left`。

### 拿到这道题的第一思路

**数据结构。** 有序数组和两个边界 `left`、`right`。每次取中点 `mid`，按它与目标值的大小关系排除一侧。

**怎么想。** 如果 `nums[mid] < target`，到 `mid` 为止都在插入点前面。如果 `nums[mid] > target`，从 `mid` 起都应该在目标值后面。

### 关键变量与始终保持的规则

候选下标在闭区间 `[left,right]`。移走的左侧位置都小于目标，移走的右侧位置都大于目标。区间空时 `left == right + 1`，`left` 正好是两个区域的分界。

### 实例走过程

`nums = [1,3,5,6]`，`target = 2`。从 `[0,3]` 开始，`mid = 1`，值 3 偏大，令 `right = 0`。再看 `mid = 0`，值 1 偏小，令 `left = 1`。区间变空，返回 1，插到 1 和 3 之间。

### Java代码

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                return mid;
            }
        }
        return left; // 未命中时，left就是插入位置
    }
}
```

### 易错点

循环条件是 `left <= right`。插到最右端时答案可以等于 `nums.length`，直接返回下标即可。

### 复杂度

时间 O(log n)，辅助空间 O(1)。

## 64. 74. 搜索二维矩阵（二分查找）

[力扣题目](https://leetcode.cn/problems/search-a-2d-matrix/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0074-search-a-2d-matrix/) · [代码随想录 · Java](https://programmercarl.com/hot100/0074.search-a-2d-matrix.html)

### 一句话总结

把逐行连续有序的矩阵看作一条有序序列，对虚拟下标做二分。

### 拿到这道题的第一思路

**数据结构。** 矩阵本身和虚拟的一维闭区间 `[0, rows × cols − 1]`。每一行有 `cols` 个位置。

**怎么想。** 题目保证下一行的首元素大于上一行的末元素，因此逐行读下去仍然有序。虚拟下标除以列数得到行号，取余得到列号，直接访问原矩阵。

### 关键变量与始终保持的规则

`mid / cols` 是跨过的完整行数，`mid % cols` 是在当前行内的偏移。比较 `value` 后用 `mid ± 1` 缩闭区间，命中返回 `true`，区间为空返回 `false`。

### 实例走过程

`matrix = [[1,3,5],[7,9,11]]`，`target = 9`。下标范围 `[0,5]`，先取 `mid = 2`，对应 `(0,2)` 的 5。令 `left = 3` 后取 `mid = 4`，对应 `(1,1)` 的 9，返回 `true`。

### Java代码

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int rows = matrix.length;
        int cols = matrix[0].length;
        int left = 0, right = rows * cols - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int row = mid / cols;
            int col = mid % cols;
            int value = matrix[row][col];

            if (value < target) {
                left = mid + 1;
            } else if (value > target) {
                right = mid - 1;
            } else {
                return true;
            }
        }
        return false;
    }
}
```

### 易错点

坐标换算都用列数 `cols`。第 21 题的「搜索二维矩阵 II」只给出行列各自有序，做这类题要先读清给出的排序条件。

### 复杂度

r 行 c 列，时间 O(log(rc))，辅助空间 O(1)。

## 65. 34. 在排序数组中查找元素的第一个和最后一个位置（二分查找）

[力扣题目](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0034-find-first-and-last-position-of-element-in-sorted-array/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnJLCdVv5UPGi4e8TubKNPHb)

### 一句话总结

二分两次，每次命中先记下位置，再朝要求的那侧找有没有更靠边的目标值。

### 拿到这道题的第一思路

**数据结构。** 有序数组、闭区间和候选答案 `answer`。共用 `findBoundary`，用 `findLeft` 决定命中后继续查哪一侧。

**怎么想。** 目标值相等的位置必然连成一段。找左端时命中就缩右边，找右端时命中就缩左边。遇到大小不等时照常二分。

### 关键变量与始终保持的规则

`answer` 始终是目前找到的最靠目标侧的命中下标，初始为 −1。找到更靠边的下标就覆盖它。主方法把两次返回值分别存在 `first`、`last`，再返回数组 `[first,last]`。

### 实例走过程

`nums = [5,7,7,8,8,10]`，`target = 8`。两轮都先排除下标 0–2，再命中 4。找左端时保存 4 后往左找到 3。找右端时保存 4 后检查下标 5，值 10 大于 8，于是保留 4。返回 `[3,4]`。

### Java代码

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int first = findBoundary(nums, target, true);
        int last = findBoundary(nums, target, false);
        return new int[]{first, last};
    }

    private int findBoundary(int[] nums, int target, boolean findLeft) {
        int left = 0;
        int right = nums.length - 1;
        int answer = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                answer = mid; // 先保存命中，再继续找边界
                if (findLeft) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }
        }
        return answer;
    }
}
```

### 易错点

命中后先做 `answer = mid`，再移动边界。若完全没命中，两次搜索都会返回 −1，结果自然为 `[-1,-1]`。

### 复杂度

两次二分合计 O(log n) 时间，辅助空间 O(1)。

## 66. 33. 搜索旋转排序数组（二分查找）

[力扣题目](https://leetcode.cn/problems/search-in-rotated-sorted-array/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0033-search-in-rotated-sorted-array/) · [代码随想录 · Java](https://programmercarl.com/hot100/0033.search-in-rotated-sorted-array.html)

### 一句话总结

先辨认中点两侧哪一半有序，再用那半的值域决定目标是否留在其中。

### 拿到这道题的第一思路

**数据结构。** 互不相同的旋转有序数组和候选闭区间。未旋转时整段有序，旋转后至多有一处从大值跳到小值。

**怎么想。** 检查 `nums[left] <= nums[mid]`。成立时左半有序，可以比较目标是否在左端到中点的值域。否则用同样的方式判断右半。

### 关键变量与始终保持的规则

若目标存在，它始终在当前 `[left,right]` 内。先检查 `nums[mid] == target`，然后由有序一侧的值域选定保留哪半，移动到 `mid - 1` 或 `mid + 1`。

### 实例走过程

`nums = [4,5,6,7,0,1,2]`，`target = 0`。先到 `mid = 3`，左半 4–7 有序，0 在其值域外，令 `left = 4`。再到 `mid = 5`，值 1，左半 0–1 有序，0 在左半，令 `right = 4`。最后命中下标 4。

### Java代码

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) return mid;

            if (nums[left] <= nums[mid]) { // 左半区有序
                if (nums[left] <= target && target < nums[mid]) right = mid - 1;
                else left = mid + 1;
            } else { // 右半区有序
                if (nums[mid] < target && target <= nums[right]) left = mid + 1;
                else right = mid - 1;
            }
        }
        return -1;
    }
}
```

### 易错点

判定左半有序用 `<=`，`left == mid` 时单元素区间也有序。目标值域允许等于当前外侧端点，中点已经单独检查。

### 复杂度

时间 O(log n)，辅助空间 O(1)。

## 67. 153. 寻找旋转排序数组中的最小值（二分查找）

[力扣题目](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0153-find-minimum-in-rotated-sorted-array/) · [代码随想录 · Java](https://programmercarl.com/hot100/0153.find-minimum-in-rotated-sorted-array.html)

### 一句话总结

每轮用中点与当前右端点的大小关系，判断最小值还可能在哪一半。

### 拿到这道题的第一思路

**数据结构。** 互不相同的旋转有序数组。令 `[left,right]` 始终包含最小值。

**怎么想。** `nums[mid] > nums[right]` 表示从中点到右端经历了大小跳变，最小值在中点右边。否则中点到右端已经递增，最小值至多在中点位置。

### 关键变量与始终保持的规则

右侧有跳变时做 `left = mid + 1`，右侧递增时做 `right = mid`，保留中点本身。搜索收敛到一个下标后，返回 `nums[left]`。

### 实例走过程

`nums = [4,5,6,7,0,1,2]`。`mid = 3` 时 7 大于右端的 2，`left = 4`。接着 `mid = 5` 时 1 小于 2，`right = 5`。再取 `mid = 4`，0 小于右端的 1，`right = 4`，返回 0。

### Java代码

```java
class Solution {
    public int findMin(int[] nums) {
        int left = 0;
        int right = nums.length - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > nums[right]) {
                // mid在前半段（较大元素），最小值在右边
                left = mid + 1;
            } else {
                // mid在后半段（较小元素），最小值在左边或就是mid
                right = mid;
            }
        }

        return nums[left];
    }
}
```

### 易错点

循环用 `left < right`。写 `right = mid - 1` 会漏掉中点就是最小值的情况，例如 `[3,1,2]`。

### 复杂度

时间 O(log n)，辅助空间 O(1)。

## 68. 4. 寻找两个正序数组的中位数（二分查找）

[力扣题目](https://leetcode.cn/problems/median-of-two-sorted-arrays/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0004-median-of-two-sorted-arrays/) · [代码随想录 · Java](https://programmercarl.com/hot100/0004.median-of-two-sorted-arrays.html)

### 一句话总结

把中位数转成第 k 小问题，每次排除一段确认排在第 k 小之前的元素，同时减少 k。

### 拿到这道题的第一思路

**数据结构。** 两个有序数组。用 `start1`、`start2` 指向尚未排除的后缀，`k` 表示在两个后缀合起来后的名次，从 1 开始数。

**怎么想。** 设 `half = k / 2`，比较两个后缀的第 `half` 个元素。若左边的探针更小，左边前 `half` 个元素可以排除。把并列元素按这次排除的一侧优先排列，段尾前面至多各有 `half − 1` 个，两侧共 `2·half − 2` 个，所以这段可以放在第 k 名以前。另一侧同理。

### 关键变量与始终保持的规则

跳过 `half` 个元素时，只移动对应的一侧起点，并把名次改成 `k - half`。某侧凑不够 `half` 个，用本题值域外的 `Integer.MAX_VALUE` 作探针，让足够长的一侧先排除。若一侧耗尽，就在另一侧直接取第 k 个。若 `k == 1`，取两个后缀首元素中的较小值。

### 实例走过程

`nums1 = [1,3]`，`nums2 = [2,4]`。总数为 4，要第 2 小和第 3 小。两次的第一轮都用 `half = 1`，先排除 1。找第 2 小时只剩第 1 小要找，取 3 和 2 的较小值 2。找第 3 小时剩第 2 小，比较 3 和 2 排除 2，再比较 3 和 4 取 3。返回 `(2 + 3) / 2.0 = 2.5`。

### Java代码

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int total = m + n;

        if (total % 2 == 1) {
            return findKth(nums1, 0, nums2, 0, total / 2 + 1);
        } else {
            int left = findKth(nums1, 0, nums2, 0, total / 2);
            int right = findKth(nums1, 0, nums2, 0, total / 2 + 1);
            return (left + right) / 2.0;
        }
    }

    private int findKth(int[] nums1, int start1, int[] nums2, int start2, int k) {
        if (start1 >= nums1.length) {
            return nums2[start2 + k - 1];
        }
        if (start2 >= nums2.length) {
            return nums1[start1 + k - 1];
        }
        if (k == 1) {
            return Math.min(nums1[start1], nums2[start2]);
        }

        int half = k / 2;
        int mid1 = start1 + half - 1 < nums1.length ? nums1[start1 + half - 1] : Integer.MAX_VALUE;
        int mid2 = start2 + half - 1 < nums2.length ? nums2[start2 + half - 1] : Integer.MAX_VALUE;

        if (mid1 < mid2) {
            return findKth(nums1, start1 + half, nums2, start2, k - half);
        } else {
            return findKth(nums1, start1, nums2, start2 + half, k - half);
        }
    }
}
```

### 易错点

`k` 是从 1 开始的名次，数组下标是从 0 开始，所以当前探针是 `start + half - 1`。原始总长度为奇数时只查 `total / 2 + 1`。为偶数时用浮点除法求中间两项的均值。

### 复杂度

每轮大致把 k 减半。时间 O(log(m+n))，递归栈 O(log(m+n))。

## 69. 20. 有效的括号（栈）

[力扣题目](https://leetcode.cn/problems/valid-parentheses/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0020-valid-parentheses/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcn41cHm2cUCT3Rk1xgPrrFLc)

### 一句话总结

开括号入栈时存入它期待的闭括号，遇到闭括号就和栈顶核对。

### 拿到这道题的第一思路

**数据结构。** 一个后进先出的 `Deque<Character>`。最近打开的括号应该最先关闭，例如 `{[]}` 先闭合方括号。

**怎么想。** 读到 `(`、`[`、`{` 分别把 `)`、`]`、`}` 压栈。读到闭括号时，检查此刻有没有待匹配项，以及类型是否正好吻合。

### 关键变量与始终保持的规则

栈中每一项都对应一个还没闭合的括号，栈顶是下一项必须出现的闭括号。匹配就弹栈，失败立即返回 `false`。处理结束时用 `stack.isEmpty()` 判断是否全部匹配。

### 实例走过程

`s = "{[]}"`。读到 `{` 后，栈里等待 `}`。再读到 `[`，从栈底到栈顶等待 `"}]"`。接着读到 `]`、`}`，依次匹配并弹栈，最后返回 `true`。输入 `"([)]"` 时，第三个字符是 `)`，此时期待的是 `]`，立即返回 `false`。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == '(') {
                // 压入期待的右括号，栈顶表示下一步应匹配谁。
                stack.push(')');
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            } else {
                // 右括号多余或类型不符，立即失败。
                if (stack.isEmpty() || stack.peek() != c) {
                    return false;
                }

                stack.pop();
            }
        }

        // 遍历结束还留有期待的括号，说明左括号多余。
        return stack.isEmpty();
    }
}
```

### 易错点

先检查栈是否为空再比较栈顶。扫描结束后也要检查一次空栈，输入 `"("` 就是在最后一步被判为无效。

### 复杂度

时间 O(n)，辅助空间 O(n)，包括栈和 `toCharArray()` 产生的数组。

## 70. 155. 最小栈（栈）

[力扣题目](https://leetcode.cn/problems/min-stack/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0155-min-stack/) · [代码随想录 · Java](https://programmercarl.com/hot100/0155.min-stack.html)

### 一句话总结

每次入栈同时保存这一刻的最小值，弹栈时把这个最小值快照也一起弹出。

### 拿到这道题的第一思路

**数据结构。** 数据栈 `stack` 和最小值栈 `minStack`，两个栈始终一样高。

**怎么想。** 当前最小值只取决于此前最小值和新入栈的数。为每一层保留当时的最小值，回到上一层时就能直接恢复。

### 关键变量与始终保持的规则

`minStack` 的每一层存数据栈从底到该层的最小值。 `push` 压入 `val` 并记录最小值，`pop` 同步弹出。`top` 读数据栈顶，`getMin` 读最小值栈顶。

### 实例走过程

依次压入 3、1、1。最小值栈从底到顶为 `[3,1,1]`。弹出一个 1 后最小值仍是 1。再弹出一个 1，数据栈顶和最小值一起回到 3。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MinStack {
    private final Deque<Integer> stack;
    private final Deque<Integer> minStack;

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);

        // 记录数据栈处于当前状态时的最小值
        if (minStack.isEmpty()) {
            minStack.push(val);
        } else {
            minStack.push(Math.min(val, minStack.peek()));
        }
    }

    public void pop() {
        // 两个栈同步弹出，恢复到上一个状态
        stack.pop();
        minStack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

### 易错点

这个版本每次 `push` 都向两个栈入栈，即使新值等于或大于已有最小值，也要给新层保存快照。

### 复杂度

`push` 均摊 O(1)，`pop`、`top`、`getMin` 均为 O(1)。存 n 个元素时用 O(n) 空间。

## 71. 394. 字符串解码（栈）

[力扣题目](https://leetcode.cn/problems/decode-string/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0394-decode-string/) · [代码随想录 · Java（补齐 import）](https://programmercarl.com/hot100/0394.decode-string.html)

### 一句话总结

遇到左方括号保存外层前缀和重复次数，遇到右方括号就解开当前层并拼回外层。

### 拿到这道题的第一思路

**数据结构。** `numStack` 存每层重复次数，`strStack` 存进入该层前的外层前缀。`curStr` 收集当前层已解码的文字，`num` 收集还在读取的数字。

**怎么想。** 遇到数字按十进制累积。读到 `[` 时把次数和外层前缀成对压栈，重新开始构造内层。读到 `]` 时弹出这一对状态，用「外层前缀 + 重复后的内层」更新 `curStr`。

### 关键变量与始终保持的规则

两个栈的对应位置属于同一层。左括号之后要清零 `num` 并新建当前层缓冲区。右括号用 `temp` 固定这一层要重复的字符串，再构造新的 `curStr`。扫描完返回 `curStr.toString()`。

### 实例走过程

`s = "3[a2[c]]"`。第一次入栈保存次数 3 和空前缀。读到第二个左括号时保存次数 2 和前缀 `"a"`。读到第一个右括号时，`"a"` 接上两个 `"c"`，得到 `"acc"`。最后把 `"acc"` 重复 3 次，返回 `"accaccacc"`。

### Java代码

```java
import java.util.Stack;

class Solution {
    public String decodeString(String s) {
        Stack<Integer> numStack = new Stack<>();    // 数字栈
        Stack<String> strStack = new Stack<>();     // 字符串栈
        StringBuilder curStr = new StringBuilder(); // 当前累积的字符串
        int num = 0;                                // 当前数字

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 累积数字（可能是多位数）
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 遇到 '[', 入栈，开始新的一层
                numStack.push(num);
                strStack.push(curStr.toString());
                num = 0;
                curStr = new StringBuilder();
            } else if (c == ']') {
                // 遇到 ']', 出栈，解码当前层
                int repeatTimes = numStack.pop();
                String prevStr = strStack.pop();

                // 当前字符串重复 repeatTimes 次，拼接到上一层
                String temp = curStr.toString();
                curStr = new StringBuilder(prevStr);
                for (int i = 0; i < repeatTimes; i++) {
                    curStr.append(temp);
                }
            } else {
                // 字母，累积到当前字符串
                curStr.append(c);
            }
        }

        return curStr.toString();
    }
}
```

### 易错点

多位次数用 `num = num * 10 + (c - '0')`。例如 `"12[a]"` 的次数是 12。每次出栈时先把内层现有内容记下来，之后才能以外层前缀重建缓冲区。

### 复杂度

设输入长度 n、解码长度 L、右括号数量 b。每次合并都可能复制一段已有前缀或已展开文本，时间上界 O(n + b·L)，空间 O(n + L)。

## 72. 739. 每日温度（栈）

[力扣题目](https://leetcode.cn/problems/daily-temperatures/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0739-daily-temperatures/) · [代码随想录 · Java](https://programmercarl.com/hot100/0739.daily-temperatures.html)

### 一句话总结

用单调栈存尚未等到升温的日期，下一个更热的日期出现时结算等待天数。

### 拿到这道题的第一思路

**数据结构。** 栈存日期下标，`answer` 是与输入等长的结果数组，初始值为 0。

**怎么想。** 从左往右读温度。当天比栈顶更热，栈顶那天就等到了右边第一个更热的日期，弹出后把下标差写到对应答案。继续比较新栈顶，当天可能同时结算几天。

### 关键变量与始终保持的规则

从栈底到栈顶，对应温度单调不增。整个过程只给弹出的下标写 `answer[index] = i - index`。扫描结束仍在栈里的日期没有等到更热的一天，保留 0。

### 实例走过程

`temperatures = [73,74,74,71,75]`。第 1 天结算第 0 天，等待 1 天。第 2 天与第 1 天同温，一起留栈，第 3 天也入栈。第 4 天连续结算第 3、2、1 天，分别等待 1、2、3 天。返回 `[1,3,2,1,0]`。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] answer = new int[temperatures.length];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < temperatures.length; i++) {
            // 当前温度为栈顶日期找到了右侧第一个更高温度
            while (!stack.isEmpty()
                    && temperatures[i] > temperatures[stack.peek()]) {
                int index = stack.pop();
                answer[index] = i - index;
            }
            stack.push(i);
        }

        return answer;
    }
}
```

### 易错点

比较用严格大于 `>`。必须用 `while` 处理所有能被这一天结算的栈顶，存下标才能计算天数。

### 复杂度

每个下标最多入栈一次、出栈一次，时间 O(n)，辅助空间 O(n)，输出另计 O(n)。

## 73. 84. 柱状图中最大的矩形（栈）

[力扣题目](https://leetcode.cn/problems/largest-rectangle-in-histogram/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0084-largest-rectangle-in-histogram/) · [代码随想录 · Java](https://programmercarl.com/hot100/0084.largest-rectangle-in-histogram.html)

### 一句话总结

较矮的柱子出现时，结算被它挡住的较高柱子能撑出的矩形面积。

### 拿到这道题的第一思路

**数据结构。** `newHeights` 在原高度数组两端各补一个 0，栈里存这个新数组的下标。`result` 记录目前最大面积。

**怎么想。** 先固定矩形的高度为某根柱子的高度。向右碰到较矮柱子时，矩形不能再延伸，于是弹出高度待结算的柱子。弹栈后的新栈顶给出本次计算的左界，当天的下标 `i` 给出右界。

### 关键变量与始终保持的规则

栈底到栈顶对应高度单调不减。每次弹出的 `mid` 提供高度，宽度是两个边界之间的柱子数 `i - stack.peek() - 1`。相同高度会共同留栈，靠右的等高柱先结算，靠左的等高柱随后能覆盖更宽的区间。

### 实例走过程

`heights = [2,1,5,6,2,3]`，补零后为 `[0,2,1,5,6,2,3,0]`。扫到新下标 5、高度 2 时，先弹高度 6，宽 `5 - 3 - 1 = 1`，面积 6。再弹高度 5，宽 `5 - 2 - 1 = 2`，面积 10。尾部的 0 触发剩余正高度结算，最大面积仍为 10。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int largestRectangleArea(int[] heights) {
        int[] newHeights = new int[heights.length + 2];
        System.arraycopy(heights, 0, newHeights, 1, heights.length);

        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        int result = 0;

        for (int i = 1; i < newHeights.length; i++) {
            while (newHeights[i] < newHeights[stack.peek()]) {
                int mid = stack.pop();
                int width = i - stack.peek() - 1;
                result = Math.max(result, newHeights[mid] * width);
            }
            stack.push(i);
        }

        return result;
    }
}
```

### 易错点

算宽度时用「弹出之后」的栈顶。首部的 0 提供安全的左边界，尾部的 0 让一直上升的柱子也能被结算。相等的柱子会保留，因此新栈顶有时和弹出的柱子等高。

### 复杂度

时间 O(n)。补零数组和栈共用 O(n) 辅助空间。

## 74. 215. 数组中的第 K 个最大元素（堆）

[力扣题目](https://leetcode.cn/problems/kth-largest-element-in-an-array/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0215-kth-largest-element-in-an-array/) · [代码随想录 · 快速选择法的 Java 三路分区实现](https://programmercarl.com/hot100/0215.kth-largest-element-in-an-array.html)

### 一句话总结

把第 K 大换成升序下标 `n - k`，每轮把候选区间按基准值分三段，然后只到目标所在的一段继续找。

### 拿到这道题的第一思路

**数据结构。** 原数组、目标下标 `targetIndex` 和当前候选区间 `[left,right]`。快速选择只需要定位一个名次。

**怎么想。** 从候选区间随机挑一个基准值 `pivot`，一趟把值分成「小于、等于、大于」三段。最终等于段占用的下标就是这些值排完序后会占的位置。目标下标落在等于段时返回基准，否则继续缩小到对应侧。

### 关键变量与始终保持的规则

分区期间，`[left, less)` 已确认小于基准，`[less, scan)` 等于基准，`[scan, greater]` 还没检查，`(greater, right]` 已确认大于基准。分区结束时等于段为 `[less, greater]`。

### 实例走过程

`nums = [3,2,3,1,2,4,5,5,6]`，`k = 4`，目标升序下标是 5。假设第一轮选到基准 3，小于它的有 3 个，等于它的有 2 个，等于段占下标 3–4。继续找右段。若这轮选到 5，两个 5 占下标 6–7，转到左侧，只剩下标 5 的 4，返回 4。

### Java代码

```java
import java.util.concurrent.ThreadLocalRandom;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        int targetIndex = nums.length - k;
        int left = 0;
        int right = nums.length - 1;

        while (left < right) {
            int pivotIndex = ThreadLocalRandom.current().nextInt(left, right + 1);
            int pivot = nums[pivotIndex];
            int less = left;
            int scan = left;
            int greater = right;

            // 把候选区间分成小于、等于、大于 pivot 的三段。
            while (scan <= greater) {
                if (nums[scan] < pivot) {
                    swap(nums, less, scan);
                    less++;
                    scan++;
                } else if (nums[scan] > pivot) {
                    swap(nums, scan, greater);
                    greater--; // 换到 scan 的数还需要检查。
                } else {
                    scan++;
                }
            }

            if (targetIndex < less) {
                right = less - 1;
            } else if (targetIndex > greater) {
                left = greater + 1;
            } else {
                return pivot;
            }
        }

        return nums[left];
    }

    private void swap(int[] nums, int first, int second) {
        int saved = nums[first];
        nums[first] = nums[second];
        nums[second] = saved;
    }
}
```

### 易错点

相等的值各占一个名次。把 `scan` 处的大值与 `greater` 处交换后，要重新检查换到 `scan` 的数。代码会在原数组上交换元素。

### 复杂度

随机选基准时，期望时间 O(n)，最坏 O(n²)。迭代实现的辅助空间 O(1)。

## 75. 347. 前 K 个高频元素（堆）

[力扣题目](https://leetcode.cn/problems/top-k-frequent-elements/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0347-top-k-frequent-elements/) · [算法学习总笔记（Java）原码 · 小顶堆版](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnmhlmLqPgLv1X5if14I3Z6b)

### 一句话总结

先用哈希表统计频次，再用小顶堆留下频次最高的 k 个数。

### 拿到这道题的第一思路

**数据结构。** `count` 把数值映射到频次，`minHeap` 存 `[数值, 频次]`，按频次从小到大比较。

**怎么想。** 每次把一种数值及其频次加入候选。超过 k 个时，淘汰频次最低的那个，留下此前见过的最强候选。

### 关键变量与始终保持的规则

处理完一种数值之后，堆中保存目前的前 k 高频候选，堆顶是候选里频次最低的。遍历完频次表后，从结果数组的尾部往前填入弹出的数值，最后返回 `result`。

### 实例走过程

`nums = [1,1,1,2,2,3]`，`k = 2`。频次是 1→3、2→2、3→1。假设按 1、2、3 的顺序处理，第三种加入后堆超过 k 项，频次为 1 的数值 3 出堆。最后先弹出 2，填到 `result[1]`，再弹出 1，填到 `result[0]`，返回 `[1,2]`。

### Java代码

```java
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();

        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        PriorityQueue<int[]> minHeap =
                new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));

        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            minHeap.offer(new int[]{entry.getKey(), entry.getValue()});

            // 人数超额时，淘汰当前候选里频率最低的。
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }

        int[] result = new int[k];

        for (int i = k - 1; i >= 0; i--) {
            // 堆弹出的是数值与频次；答案只要数值。
            result[i] = minHeap.poll()[0];
        }

        return result;
    }
}
```

### 易错点

比较器看 `a[1]`，结果取 `[0]`。哈希表的遍历顺序没有保证，题目允许答案采用任意顺序。

### 复杂度

设 u 为不同数值的数量。哈希计数与堆操作合计期望时间 O(n + u·log(k+1))，辅助空间 O(u + k)，输出另计 O(k)。

## 76. 295. 数据流的中位数（堆）

[力扣题目](https://leetcode.cn/problems/find-median-from-data-stream/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0295-find-median-from-data-stream/) · [代码随想录 · Java（补齐 import）](https://programmercarl.com/hot100/0295.find-median-from-data-stream.html)

### 一句话总结

用大顶堆存较小一半，小顶堆存较大一半，查询时只看两个堆顶。

### 拿到这道题的第一思路

**数据结构。** `maxHeap` 的堆顶是较小一半的最大值，`minHeap` 的堆顶是较大一半的最小值。这两个值正好靠在有序序列的中间。

**怎么想。** 新数先放进 `maxHeap`，再把其中的最大值移到 `minHeap`。如果较大一半的数量反超，就把它的最小值移回较小一半。移动两个堆的交界值，既能保持分半，也能保持大小关系。

### 关键变量与始终保持的规则

每次 `addNum` 结束时，`maxHeap` 中任一值都小于等于 `minHeap` 中任一值。`maxHeap` 的大小等于 `minHeap` 或比它多 1。数量为奇数时读 `maxHeap.peek()`，偶数时求两个堆顶的平均值。

### 实例走过程

依次加入 3、1、2、5。左右两半先是 `{3} | {}`，加入 1 后为 `{1} | {3}`，中位数是 2。再加入 2，变成 `{1,2} | {3}`，中位数仍是 2。加入 5 后为 `{1,2} | {3,5}`，两个堆顶是 2 和 3，返回 2.5。

### Java代码

```java
import java.util.PriorityQueue;

class MedianFinder {
    private PriorityQueue<Integer> maxHeap; // 大顶堆
    private PriorityQueue<Integer> minHeap; // 小顶堆

    public MedianFinder() {
        maxHeap = new PriorityQueue<>((a, b) -> b - a);
        minHeap = new PriorityQueue<>();
    }

    public void addNum(int num) {
        maxHeap.offer(num);
        minHeap.offer(maxHeap.poll());

        if (minHeap.size() > maxHeap.size()) {
            maxHeap.offer(minHeap.poll());
        }
    }

    public double findMedian() {
        if (maxHeap.size() > minHeap.size()) {
            return maxHeap.peek();
        } else {
            return (maxHeap.peek() + minHeap.peek()) / 2.0;
        }
    }
}
```

### 易错点

较小的一半用大顶堆，才能快速取出靠近中间的最大值。偶数时除以 `2.0`。题目保证首次查询前已添加元素，且数值范围内的两项相加与比较器做差都在 `int` 范围内。

### 复杂度

`addNum` 均摊 O(log n)，`findMedian` 为 O(1)。两个堆合计占 O(n) 空间。

## 77. 121. 买卖股票的最佳时机（贪心算法）

[力扣题目](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0121-best-time-to-buy-and-sell-stock/) · [算法学习总笔记（Java）原码 · 最低买价版](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcn0deGqw276e6vS1EI17wf9f)

### 一句话总结

把今天当成卖出日，记录此前的最低买价，并用今天的利润更新历史最好答案。

### 拿到这道题的第一思路

**数据结构。** `low` 记录截至当天所见的最低价格，`result` 记录目前的最大利润。

**怎么想。** 固定卖出日时，买入越便宜越好。扫描每一天，先更新最低价，再计算 `price - low`。碰到新低时这项利润是 0，允许的「不交易」也正是 0。

### 关键变量与始终保持的规则

每轮结束后，`low` 是已扫描前缀中最小的价格，`result` 是这个前缀内最多完成一次买卖的最大收益。只要收益为正，最低买价就一定来自今天之前。收益为 0 时可以不交易。

### 实例走过程

`prices = [7,1,5,3,6,4]`。前两天最低价从 7 变成 1，利润保持 0。价格为 5 时得到 4，`result = 4`。到价格 6 时得到 5，`result = 5`。最后的 4 只能带来 3，返回 5。

### Java代码

```java
import java.util.*;

class Solution {
    public int maxProfit(int[] prices) {
        int low = Integer.MAX_VALUE, result = 0;
        for (int price : prices) {
            low = Math.min(low, price);
            result = Math.max(result, price - low);
        }
        return result;
    }
}

```

### 易错点

今天的候选利润使用已经扫过的价格更新。`result` 初始为 0，像 `[7,6,4,3,1]` 一路下跌时返回 0。

### 复杂度

时间 O(n)，辅助空间 O(1)。

## 78. 55. 跳跃游戏（贪心算法）

[力扣题目](https://leetcode.cn/problems/jump-game/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0055-jump-game/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnOjNvjibE15MgowdK3BWAIe)

### 一句话总结

站在可达的下标上，持续扩大最远能到的位置 `cover`。

### 拿到这道题的第一思路

**数据结构。** 一个最远边界 `cover`，起始为 0。每个位置给出可以跳的最大距离，因此从一个可达位置向前可以覆盖连续的一段。

**怎么想。** 扫描目前可达的下标 `i`，用 `i + nums[i]` 尝试扩大覆盖区间。只要覆盖到终点就可以提前成功。

### 关键变量与始终保持的规则

`[0,cover]` 内的下标都可达。只有 `i <= cover` 才能用该位置的跳跃能力。当 `cover >= nums.length - 1` 时返回 `true`，扫完可达范围仍未覆盖终点时返回 `false`。

### 实例走过程

`nums = [3,2,1,0,4]`。从 0 可以到下标 3。继续扫描下标 1、2、3，三个位置都只能把最远处推到 3。下标 4 在覆盖外，循环结束并返回 `false`。

### Java代码

```java
class Solution {
    public boolean canJump(int[] nums) {
        int cover = 0;
        for (int i = 0; i < nums.length && i <= cover; i++) {
            cover = Math.max(cover, i + nums[i]);
            if (cover >= nums.length - 1) return true;
        }
        return false;
    }
}
```

### 易错点

数组长度为 1 时起点就是终点。检查更新后的覆盖范围即可。循环必须带条件 `i <= cover`。

### 复杂度

时间 O(n)，辅助空间 O(1)。

## 79. 45. 跳跃游戏 II（贪心算法）

[力扣题目](https://leetcode.cn/problems/jump-game-ii/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0045-jump-game-ii/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcn70Dsj7lyvuxojvaTSJc5Kh)

### 一句话总结

扫完当前步数覆盖的这一层，再多跳一次，把边界扩到下一层的最远点。

### 拿到这道题的第一思路

**数据结构。** `steps` 记跳数，`curEnd` 记用这些步数已经覆盖的边界，`nextEnd` 记再跳一步能覆盖到的最远位置。

**怎么想。** 沿着第 78 题的覆盖范围继续想。为了算最少步数，先扫完当前这一层的起跳位置，取它们下一跳能到的最远位置。扫到当前层边界时，一次性进入下一层。

### 关键变量与始终保持的规则

遍历到 `i` 时先更新 `nextEnd = max(nextEnd, i + nums[i])`。只有 `i == curEnd` 才做 `steps++` 和 `curEnd = nextEnd`。每次推进的是同样次数的所有跳法所能覆盖的最远边界，首次覆盖终点所需的层数就是最少跳数。

### 实例走过程

`nums = [2,3,1,1,4]`。`i = 0` 时算出下一层最远到 2，完成第一跳，`steps = 1, curEnd = 2`。扫描 `i = 1` 时把 `nextEnd` 推到 4，`i = 2` 时保持 4。扫到 2 后完成第二跳，`curEnd = 4`，返回 2。

### Java代码

```java
class Solution {
    public int jump(int[] nums) {
        int curEnd = 0;
        int nextEnd = 0;
        int steps = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            nextEnd = Math.max(nextEnd, i + nums[i]);
            if (i == curEnd) {
                steps++; // 扫完一层，才增加一步
                curEnd = nextEnd;
            }
        }
        return steps;
    }
}
```

### 易错点

循环只处理到倒数第二个下标，终点无需再起跳。题目保证能到终点。若数组长度为 1，循环不执行，直接返回 0。

### 复杂度

时间 O(n)，辅助空间 O(1)。

## 80. 763. 划分字母区间（贪心算法）

[力扣题目](https://leetcode.cn/problems/partition-labels/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0763-partition-labels/) · [算法学习总笔记（Java）原码](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcngXwXsOL0OUgxJdVR1N70qf)

### 一句话总结

每段右边界至少要包含已见字符的最后一次出现位置，走到这个边界就可以切一段。

### 拿到这道题的第一思路

**数据结构。** 长度为 26 的数组 `last` 保存每个小写字母最后出现的下标，`result` 保存各段长度。

**怎么想。** 先从左往右扫一遍，因后来的出现会覆盖前面的记录，最终得到 `last`。第二遍扫描时，遇到一个段内字母，就检查它最后在哪里出现，把本段右界延到足够远。到达边界就切，可以让段数最多。

### 关键变量与始终保持的规则

`start` 是当前段起点，`end` 是这一段内已扫描字母的最晚出现位置。更新 `end` 后，若 `i == end`，当前段内任何字母在后面都不会再出现，可以保存长度 `i - start + 1`，并将下一段起点移到 `i + 1`。

### 实例走过程

`s = "abac"`。最后位置是 `last[a] = 2, last[b] = 1, last[c] = 3`。从下标 0 出发遇到 a，边界推到 2。扫到 b 时边界仍为 2。走到 2 切出 `"aba"`，记录长度 3。接着在下标 3 切出 `"c"`，返回 `[3,1]`。

### Java代码

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) last[s.charAt(i) - 'a'] = i;
        List<Integer> result = new ArrayList<>();
        int start = 0;
        int end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {
                result.add(i - start + 1);
                start = i + 1;
            }
        }
        return result;
    }
}
```

### 易错点

先用当前字母更新右界，再判断是否可以切。长度由闭区间两端相减加 1 得到。

### 复杂度

两遍扫描共 O(n) 时间。固定字母表用 O(1) 辅助空间，输出占 O(p)，p 为切出的段数。
