# 15 · 三数之和 — 展老师小课堂

哈希表 · 3Sum

## 题意

从 nums 选取三个不同下标，使对应值之和为 0。返回所有按值区分的三元组，每组只出现一次。

官方原题：https://leetcode.cn/problems/3sum/

## 课堂示例

输入：nums = [-1, 0, 1, 2, -1, -4]

预期结果：[[-1,-1,2],[-1,0,1]]

实际结果：[[-1,-1,2],[-1,0,1]]

测试来源：与飞书本题“实例走过程”使用相同输入。

## 状态含义

用排序+双指针作为主解。i、left、right严格递增排列为 i<left<right，保证三个下标不同；排序把相同值放在一起，才能按层去重。哈希不是不能做，而是这里双指针更便于统一移动、剪枝和去重。

## 状态变化

这道题本质是：排序后固定一个数，让另外两个数从两端夹逼，同时跳过重复数值组合。

## Java 解法

```java
import java.util.*;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) {
                break;
            }
            // 同一层固定值只处理一次，仍允许一组中有相同数值。
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;
            while (left < right) {
                long sum = (long) nums[i] + nums[left] + nums[right];
                if (sum < 0) {
                    left++;
                } else if (sum > 0) {
                    right--;
                } else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    // 先保存，再跨过相同的左右值。
                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }
                    left++;
                    right--;
                }
            }
        }
        return result;
    }
}
```
