# 理论基础

## 先想清楚：哪些小问题会反复用到

拿到一道最优值、可行性或计数题，先想最直接的枚举：当前可以做什么选择，选完以后还剩什么任务。如果不同选择会到达同一个剩余任务，就考虑记录这个任务的结果。DP保存的是“一个状态的结果”，不是保存所有搜索路径。

写状态时必须把影响后续决策的信息放进去。例如股票仅记天数还不够，要区分持股与空仓；冷冻期还要知道是否刚卖；树形打家劫舍则把“偷或不偷当前节点”的两种结果一起返回。

| 五步 | 自己要回答的问题 | 对应检查 |
| --- | --- | --- |
| 状态含义 | dp下标代表什么范围？值是长度、金额、方案数还是布尔值？ | 以i结尾与前i项的最好结果不能混用 |
| 状态转移 | 当前结果从哪几种互不遗漏的选择而来？ | 最优值用max/min，方案数通常累加，可行性用或 |
| 初始化 | 最小任务的答案是什么？不可达怎样表示？ | 空方案计数常为1；空前缀长度常为0；最少代价不能全设0 |
| 遍历顺序 | 每次读取的是上一轮、当前轮还是内部区间？ | 倒序避免重复选，正序允许重复选；区间按依赖决定方向 |
| 手工推演 | 小输入中每一步写了哪个格子，读了哪些来源？ | 先算表再看代码；边界、相等值、零和不可达都要检查 |

## 三个最容易混用的状态

| 状态 | 当前元素必须选吗 | 答案位置 |
| --- | --- | --- |
| dp[i]：以i结尾的最好结果 | 必须，如300、674、53 | 通常取所有结尾的最大值 |
| dp[i][j]：两个前缀的最好结果 | 不一定，如1143、72 | 完整前缀对应的右下角 |
| dp[i][j]：闭区间[i,j]的结果 | 由两端及内部区间决定，如647、516 | 计数所有合法区间，或返回完整区间 |

## 空间压缩先放在理解之后

本章大多保留完整一维或二维DP表，便于看到状态的含义与来源。只有当你能指出每个读取值属于哪一轮，才压缩空间。压缩后不是简单删掉一维：它会改变同一轮中读到新值还是旧值，背包遍历方向正由此产生。

# 背包与易混题速查

## 先用二维表看清0-1背包

令 dp[i][j] 表示只考虑前 i 个物品、容量不超过 j 的最大价值。第 i 个物品（数组下标 i-1）重量 w、价值 v：不选它读 dp[i-1][j]；选它读 dp[i-1][j-w]+v。两条来源都在上一行，每个物品因此最多选一次。

```text
物品(weight,value)：(1,15)、(3,20)、(4,30)，容量4
容量j：     0  1  2  3  4
前0个物品： 0  0  0  0  0
前1个物品： 0 15 15 15 15
前2个物品： 0 15 15 20 35
前3个物品： 0 15 15 20 35
最后的35来自重量1和3，不是重量4的单个物品。
```

压成一维后，0-1背包必须容量倒序。处理重量1时，如果从小到大更新，dp[2]会读到本轮刚写出的dp[1]=15，变成30，相当于同一物品用了两次。倒序时dp[j-w]尚未被本轮修改，仍表示上一轮。

```text
0-1最大价值：
for 每个物品(w,v):
    for j 从 capacity 倒序到 w:
        dp[j] = max(dp[j], dp[j-w] + v)

完全背包最大价值（每种物品无限次）：
for 每种物品(w,v):
    for j 从 w 正序到 capacity:
        dp[j] = max(dp[j], dp[j-w] + v)

以上为解释遍历顺序的伪代码，不是独立力扣提交代码。
```

## 背包不等于都求最大价值

| 任务 | dp表示什么 | 更新方式 | 顺序与对应题 |
| --- | --- | --- | --- |
| 能否装满 | 恰好凑j是否可行 | 或：旧dp[j]或dp[j-x] | 0-1倒序，416 |
| 最接近容量 | 容量内最大重量 | max(dp[j],dp[j-x]+x) | 0-1倒序，1049 |
| 使用不同下标的方案数 | 恰好凑j的方案 | dp[j]+=dp[j-x] | 0-1倒序，494；0也要处理 |
| 两种容量最多选几个 | 不超过i个0、j个1的最多数量 | max(旧值,来源+1) | 两种容量倒序，474 |
| 无序组合数 | 已处理种类凑j的组合 | dp[j]+=dp[j-coin] | 硬币外层，金额正序，518 |
| 有序序列数 | 总和i的全部序列 | 累加每种最后一步的来源 | 总和外层，物品内层，377、70进阶 |
| 最少数量 | 恰好凑i的最少枚数 | min(dp[i],dp[i-coin]+1) | 小金额先算；322、279 |
| 能否拼成前缀 | 前i个字符是否可拆 | 可拆前缀且最后单词匹配 | 前缀长度外层，139 |

518与377为什么不同：用1、2凑3，硬币外层只产生1+1+1和1+2两种组合；目标和外层会按最后一步分出1+2、2+1，得到三种有序序列。不要仅凭“组合”二字选循环，先读题目是否区分顺序。

## 完全背包、多重背包和爬楼梯进阶

完全背包允许一种物品任取，所以压成一维后容量正序读取当前物品的已更新状态。多重背包规定第i种最多count[i]件：理解阶段先用二维表枚举取q件，q从0到min(count[i],j/weight[i])，来源必须是上一种物品那一行；也可拆成有限个0-1物品。这些理论页不是新增力扣题。

爬楼梯进阶允许一次走1到m阶：令dp[i]为到达第i阶的走法数，dp[0]=1；外层枚举台阶i，内层枚举最后一步step，累加dp[i-step]。普通力扣70就是m=2，不需要重复创建题目。

## [509. 斐波那契数](https://leetcode.cn/problems/fibonacci-number/)

[交互式调试器：509 斐波那契数](https://xiaoshupeiqi.github.io/leetcode-java/problems/0509-fibonacci-number/)

### 一句话总结

**把前两个已知结果相加，得到下一个结果。**

### 思路分析

拿到这道题的第一思路：F(n) 已经依赖 F(n-1)、F(n-2)。直接递归会重复算相同的数字，把每个结果存下来即可。

### 动态规划五步

1. 状态含义：dp[i] 表示第 i 个斐波那契数，不是前 i 项的和。
2. 状态转移：dp[i] = dp[i-1] + dp[i-2]，两个依赖都已经在左边算出。
3. 初始化：dp[0]=0、dp[1]=1；n<2 时直接返回 n，避免访问不存在的下标1。
4. 遍历顺序：i 从2递增到 n。保留整个数组便于对照递推过程。

### 实例走过程

```text
n=5
dp[0]=0，dp[1]=1
i=2：0+1=1
i=3：1+1=2
i=4：1+2=3
i=5：2+3=5，返回5。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。自选小规模示例。

### Java代码

```java
class Solution {
    public int fib(int n) {
        if (n < 2) return n;
        int[] dp = new int[n + 1];
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2]; // 两个更小状态合成当前状态
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

n=0 也有明确结果0；不要一上来就写 dp[1]。

O(n) 时间，O(n) 辅助空间。

## [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)

[交互式调试器：70 爬楼梯](https://xiaoshupeiqi.github.io/leetcode-java/problems/0070-climbing-stairs/)

### 一句话总结

**按最后一步爬1阶还是2阶，把方案分成两类。**

### 思路分析

拿到这道题的第一思路：先站在第 n 阶往回看。最后一步只能从 n-1 或 n-2 来；把这两处已有的方案数相加。

### 动态规划五步

1. 状态含义：dp[i] 表示恰好到达第 i 阶的不同走法数。
2. 状态转移：dp[i]=dp[i-1]+dp[i-2]。最后一步不同，两类走法不会重复。
3. 初始化：dp[0]=1 表示不走也是一种起始方案；dp[1]=1。力扣本题 n>=1。
4. 遍历顺序：i 从2到 n；两项都取更小台阶的结果。

### 实例走过程

```text
n=4
dp=[1,1,0,0,0]
第2阶：1+1=2
第3阶：2+1=3
第4阶：3+2=5
例如1+1+2与2+1+1是不同走法。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。自选小规模示例。

### Java代码

```java
class Solution {
    public int climbStairs(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

这是有顺序的走法数。进阶版若允许1到m阶，内层枚举最后一步 step=1..m；仍然先枚举目标阶数，不能把它当无序硬币组合。

O(n) 时间，O(n) 辅助空间。

## [746. 使用最小花费爬楼梯](https://leetcode.cn/problems/min-cost-climbing-stairs/)

[交互式调试器：746 使用最小花费爬楼梯](https://xiaoshupeiqi.github.io/leetcode-java/problems/0746-min-cost-climbing-stairs/)

### 一句话总结

**计算到达每一阶的最低花费，楼顶在数组最后一项之后。**

### 思路分析

拿到这道题的第一思路：每次可以迈1或2阶，不能只挑眼前便宜的台阶。先记录到达每个位置的最低累计花费，再决定从哪里跨来。

### 动态规划五步

1. 状态含义：dp[i] 表示到达下标 i 的位置所需的最小花费；此时尚未支付 cost[i]。楼顶是 n。
2. 状态转移：dp[i]=min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])。从哪一阶离开，就支付哪一阶费用。
3. 初始化：dp[0]=dp[1]=0，因为可以免费从0或1开始。
4. 遍历顺序：i 从2到 n，包含楼顶；返回 dp[n]。

### 实例走过程

```text
cost=[10,15,20]，楼顶下标3
dp[0]=0，dp[1]=0
dp[2]=min(0+15,0+10)=10
dp[3]=min(10+20,0+15)=15
从下标1直接跨到楼顶。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        int[] dp = new int[n + 1];
        for (int i = 2; i <= n; i++) {
            dp[i] = Math.min(dp[i - 1] + cost[i - 1],
                    dp[i - 2] + cost[i - 2]); // 付费发生在离开台阶时
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

不要把“到达当前阶的花费”与“已支付当前阶费用”混为一谈。最后一项 cost[n-1] 仍是台阶，楼顶没有 cost[n]。

O(n) 时间，O(n) 辅助空间。

## [62. 不同路径](https://leetcode.cn/problems/unique-paths/)

[交互式调试器：62 不同路径](https://xiaoshupeiqi.github.io/leetcode-java/problems/0062-unique-paths/)

### 一句话总结

**每个格子的路径数等于上方与左方路径数之和。**

### 思路分析

拿到这道题的第一思路：机器人只能往下或往右，倒着看某个格子，只可能从上方或左方进入。先把这两个来源存成表。

### 动态规划五步

1. 状态含义：dp[i][j] 表示从左上角到第 i 行第 j 列的路径数；下标从0开始。
2. 状态转移：dp[i][j]=dp[i-1][j]+dp[i][j-1]。
3. 初始化：第一行、第一列都只有直走这一种路径，均设为1。
4. 遍历顺序：从上到下、从左到右；每个内部格子依赖上、左。

### 实例走过程

```text
m=3，n=3
初始化边界后：
1 1 1
1 0 0
1 0 0
依次填表：
1 1 1
1 2 3
1 3 6
返回右下角6。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。自选小规模示例。

### Java代码

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 易错点与复杂度

m 是行数，n 是列数；返回 dp[m-1][n-1]。只有一行或一列时答案为1。

O(mn) 时间，O(mn) 辅助空间。

## [63. 不同路径 II](https://leetcode.cn/problems/unique-paths-ii/)

[交互式调试器：63 不同路径 II](https://xiaoshupeiqi.github.io/leetcode-java/problems/0063-unique-paths-ii/)

### 一句话总结

**遇到障碍就保留0，其余格子累加上方和左方。**

### 思路分析

拿到这道题的第一思路：沿用62的来源分析，但障碍格不能进入，更不能把路径传给后面的格子。把障碍的路径数固定为0即可。

### 动态规划五步

1. 状态含义：dp[i][j] 表示到达该格的有效路径数；障碍为0。
2. 状态转移：非障碍格累加存在的上邻格与左邻格；障碍直接跳过。
3. 初始化：起点是障碍则返回0；否则 dp[0][0]=1，其余先为0。
4. 遍历顺序：按行从左到右，起点单独跳过，边界只加存在的来源。

### 实例走过程

```text
障碍位于中心：
0 0 0
0 1 0
0 0 0
填出的dp：
1 1 1
1 0 1
1 1 2
中心不传递路径，右下角为2。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int uniquePathsWithObstacles(int[][] obstacleGrid) {
        int m = obstacleGrid.length, n = obstacleGrid[0].length;
        if (obstacleGrid[0][0] == 1) return 0;
        int[][] dp = new int[m][n];
        dp[0][0] = 1;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (obstacleGrid[i][j] == 1 || (i == 0 && j == 0)) continue;
                if (i > 0) dp[i][j] += dp[i - 1][j];
                if (j > 0) dp[i][j] += dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 易错点与复杂度

第一行被障碍截断后，后续格子不能全部初始化为1；统一按来源相加可以自然处理。终点是障碍时也返回0。

O(mn) 时间，O(mn) 辅助空间，不改输入。

## [343. 整数拆分](https://leetcode.cn/problems/integer-break/)

[交互式调试器：343 整数拆分](https://xiaoshupeiqi.github.io/leetcode-java/problems/0343-integer-break/)

### 一句话总结

**固定拆出的第一段，再决定剩余部分继续拆还是直接使用。**

### 思路分析

拿到这道题的第一思路：必须至少拆成两段。先枚举第一段 j，剩余 i-j 既可以整段保留，也可以继续拆；只保留乘积更大的选择。

### 动态规划五步

1. 状态含义：dp[i] 表示整数 i 至少拆成两个正整数后的最大乘积。
2. 状态转移：对每个1<=j<i，候选是 j*(i-j) 与 j*dp[i-j]，与当前 dp[i] 取最大。
3. 初始化：dp[0]、dp[1] 为0，没有合法的至少两段拆法；从 i=2 开始枚举会得到 dp[2]=1。
4. 遍历顺序：i 从2到 n，j 从1到 i-1；更小整数的最佳拆分已经算过。

### 实例走过程

```text
n=5
dp[2]=1，dp[3]=2，dp[4]=4
i=5，j=1：max(1*4,1*dp[4])=4
j=2：max(2*3,2*dp[3])=6
其余候选不超过6，返回6。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。自选小规模示例。

### Java代码

```java
class Solution {
    public int integerBreak(int n) {
        int[] dp = new int[n + 1];
        for (int i = 2; i <= n; i++) {
            for (int j = 1; j < i; j++) {
                int product = Math.max(j * (i - j), j * dp[i - j]);
                dp[i] = Math.max(dp[i], product);
            }
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

只写 j*dp[i-j] 会漏掉“不再拆剩余部分”的情况；不能把不拆分的 i 直接算成 dp[i]。

O(n²) 时间，O(n) 辅助空间。

### Java代码

```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            for (int root = 1; root <= i; root++) {
                dp[i] += dp[root - 1] * dp[i - root];
            }
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

左右选择用乘法，不同根用加法；这里统计的是结构数量，不需要真的创建 TreeNode。

## [416. 分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)

[交互式调试器：416 分割等和子集](https://xiaoshupeiqi.github.io/leetcode-java/problems/0416-partition-equal-subset-sum/)

### 一句话总结

**每个数只能用一次，检查能否恰好凑出总和的一半。**

### 思路分析

拿到这道题的第一思路：两组相等就各占总和一半。总和为奇数直接失败；接下来把每个数看成只能选一次的物品。

### 动态规划五步

1. 状态含义：dp[j] 表示已处理的数能否组成恰好为 j 的子集。
2. 状态转移：不选当前 num 时保留旧 dp[j]；选它时看旧 dp[j-num]，所以 dp[j] |= dp[j-num]。
3. 初始化：dp[0]=true，空子集能凑0，其余为 false。target=sum/2。
4. 遍历顺序：外层枚举数，内层 j 从 target 倒序到 num，保证来源仍属于上一轮。

### 实例走过程

```text
nums=[1,5,11,5]，target=11
初始可达{0}
处理1后{0,1}
处理5后{0,1,5,6}
处理11后出现11，说明一组可取[11]
另一组[1,5,5]同样为11。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) sum += num;
        if (sum % 2 != 0) return false;
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num]; // 倒序：当前数最多选一次
            }
        }
        return dp[target];
    }
}
```

### 易错点与复杂度

容量正序会让同一个数在一轮内重复使用；这里要求恰好等于 target，不能只返回最接近的和。

O(n*target) 时间，O(target) 辅助空间。

## [494. 目标和](https://leetcode.cn/problems/target-sum/)

[交互式调试器：494 目标和](https://xiaoshupeiqi.github.io/leetcode-java/problems/0494-target-sum/)

### 一句话总结

**把符号分配转成“选出和为 (sum+target)/2 的子集”并统计方案。**

### 思路分析

拿到这道题的第一思路：正号组总和 P、负号组总和 N 满足 P-N=target，P+N=sum，因此 P=(sum+target)/2。每个下标只分配一次，转为0-1背包计数。

### 动态规划五步

1. 状态含义：dp[j] 表示从已处理下标中选出总和 j 的方案数；相同数值的不同下标仍是不同选择。
2. 状态转移：dp[j] += dp[j-num]：保留不选当前下标的方案，再加选它的方案。
3. 初始化：若 |target|>sum 或 sum+target 为奇数，返回0；dp[0]=1。
4. 遍历顺序：外层枚举 num，内层 j 从容量倒序到 num；num=0 时必须包含 j=0。

### 实例走过程

```text
nums=[1,1,1,1,1]，target=3
sum=5，正号组和为4
处理四个1后，凑4的方案为1
处理第五个1后，dp[4]=旧dp[4]+旧dp[3]=1+4=5
对应任选一个下标放负号。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) sum += num;
        if (Math.abs(target) > sum || (sum + target) % 2 != 0) return 0;
        int bag = (sum + target) / 2;
        int[] dp = new int[bag + 1];
        dp[0] = 1;
        for (int num : nums) {
            for (int j = bag; j >= num; j--) {
                dp[j] += dp[j - num]; // num=0 时也要更新，正负零是两种方案
            }
        }
        return dp[bag];
    }
}
```

### 易错点与复杂度

0 的正负号是两种选择，处理一个0会使每个可达容量的方案数翻倍；不能忽略0，也不能把相同数字去重。

O(n*bag) 时间，O(bag) 辅助空间，bag=(sum+target)/2。

## [474. 一和零](https://leetcode.cn/problems/ones-and-zeroes/)

[交互式调试器：474 一和零](https://xiaoshupeiqi.github.io/leetcode-java/problems/0474-ones-and-zeroes/)

### 一句话总结

**每个字符串消耗两种容量：0的数量和1的数量。**

### 思路分析

拿到这道题的第一思路：目标是最多选几个字符串，限制却有两个。把0和1分别当成背包容量，一个字符串整体选或不选。

### 动态规划五步

1. 状态含义：dp[i][j] 表示最多使用 i 个0和 j 个1时，可以选择的最多字符串数。
2. 状态转移：当前串有 zeros 个0、ones 个1：dp[i][j]=max(dp[i][j],dp[i-zeros][j-ones]+1)。
3. 初始化：dp 全0，表示一个字符串都不选；容量不要求用尽。
4. 遍历顺序：外层每次处理一个字符串，两个容量 i、j 都倒序，防止重复使用同一字符串。

### 实例走过程

```text
strs=["10","0001","111001","1","0"]，m=5，n=3
"10"消耗(1,1)，"0001"消耗(3,1)
"111001"消耗(2,4)，超过1的容量，不选
再取"1"和"0"，总消耗(5,3)，共4个。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int findMaxForm(String[] strs, int m, int n) {
        int[][] dp = new int[m + 1][n + 1];
        for (String str : strs) {
            int zeros = 0, ones = 0;
            for (char c : str.toCharArray()) {
                if (c == '0') zeros++;
                else ones++;
            }
            for (int i = m; i >= zeros; i--) {
                for (int j = n; j >= ones; j--) {
                    dp[i][j] = Math.max(dp[i][j], dp[i - zeros][j - ones] + 1);
                }
            }
        }
        return dp[m][n];
    }
}
```

### 易错点与复杂度

每个字符串是一个物品，收益为1；不能把字符分别拆开选择。两个维度都要倒序，某个字符串可以只消耗一种容量。

O(L+Kmn) 时间，O(mn) 辅助空间；K为字符串数，L为总字符数。

本组：完全背包与拆分

```java
class Solution {
    public int change(int amount, int[] coins) {
        int[] dp = new int[amount + 1];
        dp[0] = 1;
        for (int coin : coins) {
            for (int j = coin; j <= amount; j++) {

    }
}
```

### Java代码

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = i;
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

枚举的是正平方数，不能包含0，否则状态依赖自己且没有推进。

## [139. 单词拆分](https://leetcode.cn/problems/word-break/)

[交互式调试器：139 单词拆分](https://xiaoshupeiqi.github.io/leetcode-java/problems/0139-word-break/)

### 一句话总结

**检查每个前缀，能否从一个已可拆分的前缀再接一个单词。**

### 思路分析

拿到这道题的第一思路：先找第一个单词也可以搜索，但不同分割会反复到达同一位置。只记录字符串前 i 个字符能否拆分，最后一个单词来自字典。

### 动态规划五步

1. 状态含义：dp[i] 表示 s 的前 i 个字符 s[0,i) 可以由字典单词拼出。
2. 状态转移：若 dp[i-len] 为 true，且 word 匹配 s 中从 i-len 开始的一段，则 dp[i]=true。
3. 初始化：dp[0]=true，空前缀可以作为首个单词之前的起点。
4. 遍历顺序：外层前缀长度 i=1..s.length；内层枚举最后一个 word，找到可行来源即可 break。

### 实例走过程

```text
s="leetcode"，wordDict=["leet","code"]
dp[0]=true
i=4：前缀"leet"匹配，dp[0]可行，因此dp[4]=true
i=8：最后单词"code"匹配，dp[4]可行，因此dp[8]=true
返回true；字典单词允许重复使用。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
import java.util.List;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;
        for (int i = 1; i <= s.length(); i++) {
            for (String word : wordDict) {
                int len = word.length();
                if (i >= len && dp[i - len] && s.startsWith(word, i - len)) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
```

### 易错点与复杂度

字典中有某个后缀还不够，它前面的前缀也必须可拆。用 startsWith(word,start) 对照原串，避免反复创建子串。

O(N*K*L) 时间上界，O(N) 辅助空间；N为字符串长度，K为单词数，L为最长单词长度。

### 一句话总结

**到每间房时，在“不偷它”与“偷它并跳过前一间”之间选更大值。**

### 思路分析

拿到这道题的第一思路：单独看金额最大的一间可能挡住两边更好的组合。按前缀记录最优结果；当前房是否偷，只影响能否连接前一间。

### 动态规划五步

1. 状态含义：dp[i] 表示只考虑前 i 间房，能够取得的最大金额。nums 的当前下标是 i-1。
2. 状态转移：dp[i]=max(dp[i-1],dp[i-2]+nums[i-1])。
3. 初始化：dp[0]=0，dp[1]=nums[0]；空数组防御性返回0。
4. 遍历顺序：i 从2到 n，先完成更短前缀，再处理当前房。

### 实例走过程

```text
nums=[2,7,9,3,1]
dp[0]=0，dp[1]=2
i=2：max(2,0+7)=7
i=3：max(7,2+9)=11
i=4：max(11,7+3)=11
i=5：max(11,11+1)=12，偷2、9、1。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
        int[] dp = new int[n + 1];
        dp[1] = nums[0];
        for (int i = 2; i <= n; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i - 1]);
        }
        return dp[n];
    }
}
```

### 易错点与复杂度

dp[i] 并不表示一定偷第 i 间，而是前 i 间的最好结果；若写成“必须偷”就需要不同递推。

O(n) 时间，O(n) 辅助空间。

## [213. 打家劫舍 II](https://leetcode.cn/problems/house-robber-ii/)

[交互式调试器：213 打家劫舍 II](https://xiaoshupeiqi.github.io/leetcode-java/problems/0213-house-robber-ii/)

### 一句话总结

**环形约束拆成“排除最后一间”和“排除第一间”两次线性计算。**

### 思路分析

拿到这道题的第一思路：环只比直线多了首尾相邻的限制。合法答案至少排除首尾之一，因此分别计算两段直线，取更大结果。

### 动态规划五步

1. 状态含义：robRange 的 dp[i] 表示当前闭区间内前 i 间房的最大金额。
2. 状态转移：区间内部仍是 max(dp[i-1],dp[i-2]+当前房金额)。最终比较[0,n-2]与[1,n-1]。
3. 初始化：单间房直接返回；区间 dp[0]=0、dp[1]=nums[left]。
4. 遍历顺序：分别从两个区间的第二间房向右推进；两次 DP 互不共享数组。

### 实例走过程

```text
nums=[2,3,2]
排除末房，区间[2,3]最大为3
排除首房，区间[3,2]最大为3
取max(3,3)=3
首尾两个2不能一起取。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int rob(int[] nums) {
        if (nums.length == 1) return nums[0];
        return Math.max(robRange(nums, 0, nums.length - 2),
                robRange(nums, 1, nums.length - 1));
    }

    private int robRange(int[] nums, int left, int right) {
        int len = right - left + 1;
        int[] dp = new int[len + 1];
        dp[1] = nums[left];
        for (int i = 2; i <= len; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[left + i - 1]);
        }
        return dp[len];
    }
}
```

### 易错点与复杂度

这两种情况允许都不偷首尾，覆盖范围有重叠没有关系，因为只取最大值。n=1必须单独处理，不能构造空区间。

O(n) 时间，O(n) 辅助空间；两段依次处理。

## [337. 打家劫舍 III](https://leetcode.cn/problems/house-robber-iii/)

[交互式调试器：337 打家劫舍 III](https://xiaoshupeiqi.github.io/leetcode-java/problems/0337-house-robber-iii/)

### 一句话总结

**每个节点向父节点返回两项：不偷自己、偷自己的最大金额。**

### 思路分析

拿到这道题的第一思路：树没有固定的“前两间”，但父子不能同偷。先让左右子树把偷与不偷两种结果都交回来，父节点再组合。

### 动态规划五步

1. 状态含义：traverse(node) 返回 int[2]：下标0是不偷该节点时整棵子树的最大金额，下标1是偷该节点时的最大金额。
2. 状态转移：不偷 node：左右孩子各取偷或不偷的最大值。偷 node：node.val+left[0]+right[0]，孩子必须不偷。
3. 初始化：空节点返回[0,0]；主方法取根节点两种状态的最大值。
4. 遍历顺序：后序：先左子树、再右子树，最后算当前节点。递归参数是当前节点，返回值是两种约束下的子树最优解。

### 实例走过程

```text
root=[3,2,3,null,3,null,1]
叶子3返回[0,3]，叶子1返回[0,1]
左孩子2返回[3,2]
右孩子3返回[1,3]
根不偷：max(3,2)+max(1,3)=6
根偷：3+3+1=7，返回7。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int rob(TreeNode root) {
        int[] result = traverse(root);
        return Math.max(result[0], result[1]);
    }

    private int[] traverse(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        int[] left = traverse(node.left);
        int[] right = traverse(node.right);
        int skip = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
        int take = node.val + left[0] + right[0]; // 偷父节点，孩子必须不偷
        return new int[]{skip, take};
    }
}
```

### 易错点与复杂度

偷当前节点时只能用孩子“不偷”的状态；不偷当前节点时，孩子可以偷也可以不偷。别把孩子值和整棵子树结果混淆。TreeNode 由力扣提供。

O(n) 时间，O(h) 辅助空间（递归栈及沿栈保留的状态），h为树高。

本组：股票状态

拿到这道题的第一思路：以后卖出能赚多少，取决于此前以什么成本持有股票。每天分别记录持股与空仓的最好收益，最多只买卖一次。

```java
        if (n == 0) return 0;

        for (int i = 1; i < n; i++) {
```

[交互式调试器：123 买卖股票的最佳时机 III](https://xiaoshupeiqi.github.io/leetcode-java/problems/0123-best-time-to-buy-and-sell-stock-iii/)

**把最多两笔交易展开成第一次买、第一次卖、第二次买、第二次卖四个状态。**

### 思路分析

拿到这道题的第一思路：持股/空仓不足以区分还剩几次交易。给交易阶段编号，后一个阶段只能由前一个阶段完成一次操作而来。

1. 状态含义：dp[i][0]=不操作；[1]=第一次持股；[2]=第一次卖出后的空仓；[3]=第二次持股；[4]=第二次卖出后的空仓。阶段表示“至多走到这里”，允许零收益的虚拟早期交易。
2. 状态转移：奇数阶段买：max(昨日同阶段,昨日前阶段-price)；偶数阶段卖：max(昨日同阶段,昨日前阶段+price)。

4. 遍历顺序：天数递增，阶段1..4都只读上一行。

### 实例走过程

```text

第2天[-3,2,-3,2]
第3天[0,2,2,2]
第5天[0,3,2,5]
最后[0,4,2,6]，利润6，例如0买3卖、1买4卖。
```

### Java代码

```java

    public int maxProfit(int[] prices) {
        int n = prices.length;
        if (n == 0) return 0;
        int[][] dp = new int[n][5];
        dp[0][1] = dp[0][3] = -prices[0];
        for (int i = 1; i < n; i++) {
            for (int j = 1; j <= 4; j++) {
                int delta = j % 2 == 1 ? -prices[i] : prices[i];
                dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - 1] + delta);
            }
        }
        return dp[n - 1][4];

}
```

### 易错点与复杂度

这里是“最多两笔”，不是必须两笔；最终返回空仓状态4。不要把买和卖的加减号写反。

## [188. 买卖股票的最佳时机 IV](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/)

[交互式调试器：188 买卖股票的最佳时机 IV](https://xiaoshupeiqi.github.io/leetcode-java/problems/0188-best-time-to-buy-and-sell-stock-iv/)

### 一句话总结

**把两笔交易的四阶段推广到 k 笔交易的 2k 个操作阶段。**

### 思路分析

拿到这道题的第一思路：123的四个阶段来自两次买卖。给每次买、卖继续编号，就能保留相同转移；实际有效交易数不超过天数的一半。

### 动态规划五步

1. 状态含义：dp[i][j] 为第 i 天结束时阶段 j 的最大收益；0为空操作，奇数持股，偶数空仓。
2. 状态转移：奇数 j 从 j-1 阶段买入，偶数 j 从 j-1 阶段卖出；都与昨日同阶段取最大。
3. 初始化：k=0或天数<2返回0；将k限制为min(k,n/2)。第0天所有奇数阶段为-price[0]，偶数为0。
4. 遍历顺序：按天推进，每天枚举阶段1..2k，只使用上一行。

### 实例走过程

```text
k=2，prices=[3,2,6,5,0,3]
第0天四状态[-3,0,-3,0]
第1天[-2,0,-2,0]
第2天[-2,4,-2,4]
第4天[0,4,4,4]
第5天[0,4,4,7]，两笔2→6、0→3，合计7。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int maxProfit(int k, int[] prices) {
        int n = prices.length;
        if (k == 0 || n < 2) return 0;
        k = Math.min(k, n / 2);
        int[][] dp = new int[n][2 * k + 1];
        for (int j = 1; j <= 2 * k; j += 2) dp[0][j] = -prices[0];
        for (int i = 1; i < n; i++) {
            for (int j = 1; j <= 2 * k; j++) {
                int delta = j % 2 == 1 ? -prices[i] : prices[i];
                dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - 1] + delta);
            }
        }
        return dp[n - 1][2 * k];
    }
}
```

### 易错点与复杂度

数组大小为2k+1，最后一个阶段下标是2k。最多交易次数太大时要限制，避免建立没有意义的大表。

O(nK) 时间，O(nK) 辅助空间，K=min(k,⌊n/2⌋)。

**把空仓拆成“休息可买”和“今天刚卖”，阻止卖出次日立即买入。**

### 思路分析

拿到这道题的第一思路：普通持股/空仓丢失了昨天是否刚卖的信息。额外记录“今天卖出”，买入只能从昨天已经休息的状态出发。

### 动态规划五步

1. 状态含义：dp[i][0]=持股；[1]=空仓且今天没有卖出（次日可买）；[2]=今天刚卖出。
2. 状态转移：持股=max(昨日持股,昨日休息-price)；休息=max(昨日休息,昨日刚卖)；刚卖=昨日持股+price。
3. 初始化：第0天持股=-price，休息=0，刚卖设为负无穷占位，因为当天不能先持有一股再从昨日卖出。
4. 遍历顺序：天数递增，只从上一天转移。最后取休息或刚卖的最大值。

### 实例走过程

```text
prices=[1,2,3,0,2]，每日[持股,休息,刚卖]
第0天[-1,0,不可达]
第1天[-1,0,1]
第2天[-1,1,2]
第3天[1,2,-1]：用第2天休息收益1买入
第4天[1,2,3]，返回3。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        if (n == 0) return 0;
        int[][] dp = new int[n][3];
        dp[0][0] = -prices[0];
        dp[0][2] = Integer.MIN_VALUE / 2;
        for (int i = 1; i < n; i++) {
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] - prices[i]);
            dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][2]);
            dp[i][2] = dp[i - 1][0] + prices[i];
        }
        return Math.max(dp[n - 1][1], dp[n - 1][2]);
    }
}
```

### 易错点与复杂度

买入不能从“昨天刚卖”转移。第2天卖出后第3天应冷冻，不能用收益2在第3天买入。负无穷用 Integer.MIN_VALUE/2 留出算术空间。

O(n) 时间，O(n) 辅助空间。

拿到这道题的第一思路：手续费会让小涨幅交易变得不划算。每天仍比较持股和空仓，但卖出拿到的钱要先扣 fee。

1. 状态含义：dp[i][0]=第 i 天结束持股的最大净收益；dp[i][1]=空仓的最大净收益。
2. 状态转移：持股=max(昨日持股,昨日空仓-price)；空仓=max(昨日空仓,昨日持股+price-fee)。
3. 初始化：第0天持股=-price[0]，空仓=0；这里约定手续费统一在卖出时支付。

```java
class Solution {

        int n = prices.length;
        if (n == 0) return 0;
        int[][] dp = new int[n][2];
        dp[0][0] = -prices[0];
        for (int i = 1; i < n; i++) {
```

## [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

[交互式调试器：300 最长递增子序列](https://xiaoshupeiqi.github.io/leetcode-java/problems/0300-longest-increasing-subsequence/)

### 一句话总结

**固定子序列的最后一个位置，再找前面比它小的结尾接上。**

### 思路分析

拿到这道题的第一思路：可以跳过元素，但必须保持原顺序。若答案以 nums[i] 结束，它的前一个选中值必须在前面并且更小；逐个试这些前驱。

### 动态规划五步

1. 状态含义：dp[i] 表示以 nums[i] 结尾的最长严格递增子序列长度，必须选 nums[i]。
2. 状态转移：枚举 j<i，若 nums[j]<nums[i]，则 dp[i]=max(dp[i],dp[j]+1)。
3. 初始化：每个 dp[i] 初始为1，单个元素本身就是合法子序列；result记录所有结尾的最大值。
4. 遍历顺序：i 从左到右，j 扫描 i 之前所有位置；不能只比较相邻位置。

### 实例走过程

```text
nums=[10,9,2,5,3,7,101,18]
各结尾dp=[1,1,1,2,2,3,4,4]
处理7时能接到2、5、3后面，最好长度3
处理18时接7，得到长度4
例如[2,3,7,18]，返回4。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] dp = new int[nums.length];
        int result = 0;
        for (int i = 0; i < nums.length; i++) {
            dp[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
            }
            result = Math.max(result, dp[i]);
        }
        return result;
    }
}
```

### 易错点与复杂度

严格递增使用<，不能使用<=。答案是整个dp的最大值，不一定是 dp[n-1]，例如[1,2,3,0]。

O(n²) 时间，O(n) 辅助空间。

## [718. 最长重复子数组](https://leetcode.cn/problems/maximum-length-of-repeated-subarray/)

[交互式调试器：718 最长重复子数组](https://xiaoshupeiqi.github.io/leetcode-java/problems/0718-maximum-length-of-repeated-subarray/)

### 一句话总结

**要求连续，相等时接左上角，不等时当前结尾长度归零。**

### 思路分析

拿到这道题的第一思路：找两段连续且一样的数组，先固定两段的结束位置。如果末尾相等，就把前一对结尾的共同段延长1。

### 动态规划五步

1. 状态含义：dp[i][j] 表示以 nums1[i-1]、nums2[j-1] 结束的最长公共连续段长度。i、j 是前缀长度，不是当前元素下标。
2. 状态转移：末尾相等：dp[i][j]=dp[i-1][j-1]+1；不相等保持0。
3. 初始化：第0行、第0列为0，空前缀没有非空连续段；result初始0。
4. 遍历顺序：i、j 从1递增；答案在所有格子中取最大，不一定在右下角。

### 实例走过程

```text
nums1=[1,2,3,2,1]，nums2=[3,2,1,4,7]
(3,1)末尾3相等，长度1
(4,2)末尾2相等，接左上角得到2
(5,3)末尾1相等，接左上角得到3
共同连续段[3,2,1]，返回3。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int[][] dp = new int[nums1.length + 1][nums2.length + 1];
        int result = 0;
        for (int i = 1; i <= nums1.length; i++) {
            for (int j = 1; j <= nums2.length; j++) {
                if (nums1[i - 1] == nums2[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
                result = Math.max(result, dp[i][j]);
            }
        }
        return result;
    }
}
```

### 易错点与复杂度

不相等不能取上方或左方最大值，否则允许跳过元素，变成1143的公共子序列。

O(mn) 时间，O(mn) 辅助空间。

### 一句话总结

### 思路分析

拿到这道题的第一思路：两个字符串都可以跳过字符。固定两段前缀，比较末尾；相同就把它配成一对，不同就分别缩短其中一个前缀。

### 动态规划五步

1. 状态含义：dp[i][j] 表示 text1前i个字符与text2前j个字符的最长公共子序列长度。
2. 状态转移：相等：dp[i-1][j-1]+1；不相等：max(dp[i-1][j],dp[i][j-1])。
3. 初始化：第0行、第0列为0，空串和任何串的公共子序列长度为0。
4. 遍历顺序：行列都递增，依赖左上、上、左；返回右下角。

### 实例走过程

```text
text1="abcde"，text2="ace"
处理"a"时，公共长度为1

```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int[][] dp = new int[text1.length() + 1][text2.length() + 1];
        for (int i = 1; i <= text1.length(); i++) {
            for (int j = 1; j <= text2.length(); j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }

        return dp[text1.length()][text2.length()];
    }
}
```

### 易错点与复杂度

允许不连续但必须保留相对顺序。与718不同，状态表示整个前缀的最好结果，所以不相等时可以继承上/左。

O(mn) 时间，O(mn) 辅助空间。

## [392. 判断子序列](https://leetcode.cn/problems/is-subsequence/)

[交互式调试器：392 判断子序列](https://xiaoshupeiqi.github.io/leetcode-java/problems/0392-is-subsequence/)

### 一句话总结

**只允许跳过 t 中的字符，检查能否按顺序匹配完整个 s。**

### 思路分析

拿到这道题的第一思路：这题可用双指针；在动态规划章节，把它看成受限的公共子序列：s 要完整保留，t 可以删去字符。

### 动态规划五步

1. 状态含义：dp[i][j] 表示 s前i个字符与t前j个字符中，能够按顺序匹配的最长长度。
2. 状态转移：相等取 dp[i-1][j-1]+1；不等只跳过t的末尾，取dp[i][j-1]。最终长度等于s.length才成功。
3. 初始化：第0行、第0列全0，空s总能匹配。
4. 遍历顺序：两个前缀长度递增；不等时仅向左继承，因为只能消耗t中未匹配的字符。

### 实例走过程

```text
s="abc"，t="ahbgdc"
处理s="a"时在t位置0匹配
处理s="ab"时在t位置2匹配第二个字符
处理s="abc"时在t位置5匹配第三个字符
右下角长度3，等于s.length，返回true。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int[][] dp = new int[s.length() + 1][t.length() + 1];
        for (int i = 1; i <= s.length(); i++) {
            for (int j = 1; j <= t.length(); j++) {
                if (s.charAt(i - 1) == t.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = dp[i][j - 1];
                }
            }
        }
        return dp[s.length()][t.length()] == s.length();
    }
}
```

### 易错点与复杂度

本章为统一前缀DP而保留二维表；实际只判断是否为子序列时，双指针可降到O(1)空间。空s返回true，顺序颠倒则不成立。

O(mn) 时间，O(mn) 辅助空间；m=s.length，n=t.length。

## [115. 不同的子序列](https://leetcode.cn/problems/distinct-subsequences/)

[交互式调试器：115 不同的子序列](https://xiaoshupeiqi.github.io/leetcode-java/problems/0115-distinct-subsequences/)

### 一句话总结

**末尾相等时，累加“用这个字符”和“不用这个字符”的方案数。**

### 思路分析

拿到这道题的第一思路：392只问能不能匹配，这题问有多少种删除方式。对s当前字符分两类：拿它匹配t的末尾，或直接跳过它。

### 动态规划五步

1. 状态含义：dp[i][j] 表示 s前i个字符中，选出等于t前j个字符的子序列的方案数；按下标选择计数。
2. 状态转移：相等：dp[i-1][j-1]+dp[i-1][j]；不等：dp[i-1][j]。
3. 初始化：dp[i][0]=1：删除全部字符得到空串，只有一种；dp[0][j>0]=0。
4. 遍历顺序：i、j 从1递增；读取上一行。用long相加并把超过int范围的计数饱和到Integer.MAX_VALUE，避免无关前缀计数溢出。

### 实例走过程

```text
s="rabbbit"，t="rabbit"
前三个字符"rab"匹配"rab"有1种
第四个字符b：可选第三或第四个b，匹配"rab"有2种
三个b选两个形成"rabb"共有3种
后面i、t各有固定匹配，最终3种。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int numDistinct(String s, String t) {
        long[][] dp = new long[s.length() + 1][t.length() + 1];
        for (int i = 0; i <= s.length(); i++) dp[i][0] = 1;
        for (int i = 1; i <= s.length(); i++) {
            for (int j = 1; j <= t.length(); j++) {
                dp[i][j] = dp[i - 1][j]; // 不使用当前 s 字符
                if (s.charAt(i - 1) == t.charAt(j - 1)) {
                    dp[i][j] = Math.min(Integer.MAX_VALUE, dp[i][j] + dp[i - 1][j - 1]);
                }
            }
        }
        return (int) dp[s.length()][t.length()];
    }
}
```

### 易错点与复杂度

不能相等时只取左上角，会漏掉跳过当前相同字符的方案。最终答案保证在int内；计数仅非负累加，饱和的大状态若能贡献最终答案，最终也会超界，因此饱和不会改变题目保证范围内的答案。

O(mn) 时间，O(mn) 辅助空间。

## [583. 两个字符串的删除操作](https://leetcode.cn/problems/delete-operation-for-two-strings/)

[交互式调试器：583 两个字符串的删除操作](https://xiaoshupeiqi.github.io/leetcode-java/problems/0583-delete-operation-for-two-strings/)

### 一句话总结

**末尾相同就保留；末尾不同，只能删掉其中一边再比较。**

### 思路分析

拿到这道题的第一思路：两边都只能删除，不能替换字符。固定两个前缀，如果末尾相同就无需操作；不同就分别尝试删一边。

### 动态规划五步

1. 状态含义：dp[i][j] 表示让word1前i个字符与word2前j个字符相同所需的最少删除次数。
2. 状态转移：相等取dp[i-1][j-1]；不同取min(dp[i-1][j],dp[i][j-1])+1。同时删两边可以分成两次，无需单独写。
3. 初始化：dp[i][0]=i，dp[0][j]=j，因为要把非空前缀全删成空串。
4. 遍历顺序：前缀长度从小到大，依赖左上、上、左。

### 实例走过程

```text
word1="sea"，word2="eat"
删掉word1的s，剩"ea"
删掉word2的t，剩"ea"
填表最后dp[3][3]=2
也可用公共子序列"ea"长度2核对：3+3-2*2=2。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int[][] dp = new int[word1.length() + 1][word2.length() + 1];
        for (int i = 0; i <= word1.length(); i++) dp[i][0] = i;
        for (int j = 0; j <= word2.length(); j++) dp[0][j] = j;
        for (int i = 1; i <= word1.length(); i++) {
            for (int j = 1; j <= word2.length(); j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + 1;
                }
            }
        }
        return dp[word1.length()][word2.length()];
    }
}
```

### 易错点与复杂度

末尾不同不能写左上角+1，那是允许替换的编辑距离。只删当前word1末尾对应上方，删word2末尾对应左方。

O(mn) 时间，O(mn) 辅助空间。

## [72. 编辑距离](https://leetcode.cn/problems/edit-distance/)

[交互式调试器：72 编辑距离](https://xiaoshupeiqi.github.io/leetcode-java/problems/0072-edit-distance/)

### 一句话总结

**末尾不同时，分别尝试删除、插入、替换，取代价最小的一种。**

### 思路分析

拿到这道题的第一思路：从583迁移，这次不仅能删，还能插入和替换。先把更短前缀变好，再用一次操作处理当前末尾。

### 动态规划五步

1. 状态含义：dp[i][j] 表示把word1前i个字符转换成word2前j个字符的最少编辑次数。
2. 状态转移：相等取左上角；不同取min(上方删除,左方插入,左上替换)+1。左方表示先把word1前i字符变成word2前j-1字符，再插入word2[j-1]。
3. 初始化：dp[i][0]=i（全部删除），dp[0][j]=j（全部插入）。
4. 遍历顺序：i、j 从1递增，先算当前格的三个更小前缀。

### 实例走过程

```text
word1="horse"，word2="ros"
替换h→r：horse→rorse
删除中间的r：rorse→rose
删除末尾e：rose→ros
共3次；二维表右下角也是3。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int[][] dp = new int[word1.length() + 1][word2.length() + 1];
        for (int i = 0; i <= word1.length(); i++) dp[i][0] = i;
        for (int j = 0; j <= word2.length(); j++) dp[0][j] = j;
        for (int i = 1; i <= word1.length(); i++) {
            for (int j = 1; j <= word2.length(); j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(dp[i - 1][j - 1],
                            Math.min(dp[i - 1][j], dp[i][j - 1])) + 1;
                }
            }
        }
        return dp[word1.length()][word2.length()];
    }
}
```

### 易错点与复杂度

这里的上/左是状态坐标的变化，不是直接移动字符串指针。替换只有末尾不同时才加1；相同时不能多加操作。

## [647. 回文子串](https://leetcode.cn/problems/palindromic-substrings/)

[交互式调试器：647 回文子串](https://xiaoshupeiqi.github.io/leetcode-java/problems/0647-palindromic-substrings/)

### 一句话总结

**区间两端相同，并且内部已经是回文，当前区间才是回文。**

### 思路分析

拿到这道题的第一思路：每个子串由起点和终点确定。先判断更小的内部区间是否回文，再看能否包上相同的两个端点；每个成功区间计数一次。

### 动态规划五步

1. 状态含义：dp[i][j] 表示闭区间 s[i..j] 是否为回文子串；result统计合法区间数。
2. 状态转移：s[i]==s[j] 且（j-i<=1 或 dp[i+1][j-1]）时为true，result加1。
3. 初始化：布尔表先全false；长度1自然成立，长度2只要两端相等，不读空内部。
4. 遍历顺序：i 从右向左，j 从 i 到末尾递增，确保内部的下一行已经算出。

### 实例走过程

```text
s="aaa"
i=2："a"，计数1
i=1："a"、"aa"，计数3
i=0："a"、"aa"、"aaa"，计数6
相同文本但起点不同的子串分别计数。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int countSubstrings(String s) {
        boolean[][] dp = new boolean[s.length()][s.length()];
        int result = 0;
        for (int i = s.length() - 1; i >= 0; i--) {
            for (int j = i; j < s.length(); j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i <= 1 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;
                    result++;
                }
            }
        }
        return result;
    }
}
```

### 易错点与复杂度

子串必须连续；统计的是位置区间，不是不同的文本集合。若i从左到右，所依赖的dp[i+1][j-1]可能还没填。

O(n²) 时间，O(n²) 辅助空间。

## [516. 最长回文子序列](https://leetcode.cn/problems/longest-palindromic-subsequence/)

[交互式调试器：516 最长回文子序列](https://xiaoshupeiqi.github.io/leetcode-java/problems/0516-longest-palindromic-subsequence/)

### 一句话总结

**两端相同就都选；不同时分别舍弃一端，保留更长的回文子序列。**

### 思路分析

拿到这道题的第一思路：与647的区别是可以跳过字符。固定一段区间，若两端相等，就把它们包在内部最优回文外面；不等就至少跳过一端。

### 动态规划五步

1. 状态含义：dp[i][j] 表示闭区间s[i..j]内最长回文子序列的长度，不要求连续。
2. 状态转移：相等取dp[i+1][j-1]+2；不相等取max(dp[i+1][j],dp[i][j-1])。
3. 初始化：dp[i][i]=1；下三角的0表示空内部区间，长度2时可以直接用。空串防御性返回0。
4. 遍历顺序：i 从右向左；每行先设对角线，再让j从i+1向右，依赖下方、左方和左下。

### 实例走过程

```text
s="bbbab"
区间[0,2]="bbb"的长度是3
区间[1,3]="bba"可选"bb"，长度2
最外两端b相同：dp[0][4]=dp[1][3]+2=4
可选下标0、1、2、4的"bbbb"。
```

实例来源：本章实例走过程；与本地main和网页回放输入一致。采用力扣公开示例。

### Java代码

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        if (n == 0) return 0;
        int[][] dp = new int[n][n];
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

### 易错点与复杂度

不能要求内部整个区间都回文，那会变成回文子串。最终返回整个区间dp[0][n-1]，而不是数多少个区间。

O(n²) 时间，O(n²) 辅助空间。
