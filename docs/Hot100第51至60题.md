## 51. 200. 岛屿数量（图论）

[力扣题目](https://leetcode.cn/problems/number-of-islands/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0200-number-of-islands/) · [代码随想录 · Java](https://programmercarl.com/hot100/0200.number-of-islands.html#java)

### 一句话总结

> 扫描到一块仍为 '1' 的陆地，岛屿数加一，再用递归 DFS 标记整个岛。

### 拿到这道题的第一思路

`grid` 同时存陆水状态和访问标记。递归参数 `row`、`col` 表示本层要检查的格子。

从左上角逐行扫描。发现新岛后，先把起点改为 '0'，再依次往上、下、左、右递归。越界或遇到 '0' 就返回上一层。

### 关键变量与始终保持的规则

进入 `dfs` 时先验证下标和陆地状态。通过检查就先写 '0'，之后相邻调用即使走回来也会立即返回。

### 实例走过程

`grid=["11000","11000","00100","00011"]`。从 (0,0) 进入 DFS，依次首次访问 (1,0)、(1,1)、(0,1)，返回外层时左上角四格都已清除。随后从 (2,2) 和 (3,3) 再启动两次 DFS，返回 3。

### Java代码

```java
class Solution {
    public int numIslands(char[][] grid) {
        int result = 0;
        for (int row = 0; row < grid.length; row++) {
            for (int col = 0; col < grid[0].length; col++) {
                if (grid[row][col] == '1') {
                    result++;
                    dfs(grid, row, col);
                }
            }
        }
        return result;
    }

    private void dfs(char[][] grid, int row, int col) {
        if (row < 0 || row >= grid.length || col < 0 || col >= grid[0].length
                || grid[row][col] != '1') {
            return;
        }
        grid[row][col] = '0';
        dfs(grid, row - 1, col);
        dfs(grid, row + 1, col);
        dfs(grid, row, col - 1);
        dfs(grid, row, col + 1);
    }
}
```

### 易错点

先判越界再读 `grid[row][col]`。只走四方向，(1,1) 与 (2,2) 相邻于对角线，属于不同岛。函数会原地修改 `grid`。

### 复杂度

时间 O(mn)，递归栈最坏 O(mn)。连通分量很深时，Java 调用栈可能耗尽。

## 52. 994. 腐烂的橘子（图论）

[力扣题目](https://leetcode.cn/problems/rotting-oranges/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0994-rotting-oranges/) · [代码随想录 · Java](https://programmercarl.com/hot100/0994.rotting-oranges.html#java) · [总笔记·层序遍历](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcn3AjQUyhkRST6aI6AcUA6xe)

### 一句话总结

> 所有初始烂橘子同时入队，每处理一层，时间增加一分钟。

### 拿到这道题的第一思路

`queue` 记录待扩散的坐标，`fresh` 记录仍为 1 的橘子数，`minutes` 记录已经开始处理的分钟数。

先扫描网格，统计新鲜橘子，并收集所有腐烂坐标。每轮先读 `size = queue.size()` 并让 `minutes++`，只处理本轮开始时的坐标。

### 关键变量与始终保持的规则

感染一个邻居时即把它设为 2，减少 `fresh` 并入队。新入队的格子从下一轮开始扩散。

### 实例走过程

`grid=[[2,1,1],[1,1,0],[0,1,1]]`。从 (0,0) 出发，第 1 分钟感染 (0,1)、(1,0)，第 2 分钟感染 (0,2)、(1,1)，随后依次感染 (2,1)、(2,2)。`fresh` 降为 0，返回 4。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int orangesRotting(int[][] grid) {
        Queue<int[]> queue = new ArrayDeque<>();
        int fresh = 0;
        for (int row = 0; row < grid.length; row++) {
            for (int col = 0; col < grid[0].length; col++) {
                if (grid[row][col] == 2) {
                    queue.offer(new int[]{row, col});
                } else if (grid[row][col] == 1) {
                    fresh++;
                }
            }
        }

        int minutes = 0;
        int[][] directions = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
        while (!queue.isEmpty() && fresh > 0) {
            int size = queue.size();
            minutes++;
            while (size-- > 0) {
                int[] current = queue.poll();
                for (int[] direction : directions) {
                    int row = current[0] + direction[0];
                    int col = current[1] + direction[1];
                    if (row < 0 || row >= grid.length || col < 0 || col >= grid[0].length
                            || grid[row][col] != 1) {
                        continue;
                    }
                    grid[row][col] = 2;
                    fresh--;
                    queue.offer(new int[]{row, col});
                }
            }
        }
        return fresh == 0 ? minutes : -1;
    }
}
```

### 易错点

必须在每轮开头固定 `size`，并在入队时标记。初始 `fresh == 0` 返回 0；队列空时仍有新鲜橘子则返回 -1。

### 复杂度

时间 O(mn)，队列最坏占 O(mn)。

## 53. 207. 课程表（图论）

[力扣题目](https://leetcode.cn/problems/course-schedule/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0207-course-schedule/) · [代码随想录 · Java](https://programmercarl.com/hot100/0207.course-schedule.html#java)

### 一句话总结

> 先学习入度为 0 的课，每学完一门，就消掉它对后续课程的一项先修要求。

### 拿到这道题的第一思路

`graph.get(before)` 存学完 `before` 后可解锁的课程。`inDegree` 记尚未满足的先修数，`learned` 记已完成课程数。

按 `[course, before]` 建边 `before → course`。把所有零入度课程入队，然后逐门取出并更新邻接课程的入度。

### 关键变量与始终保持的规则

`--inDegree[next] == 0` 表示最后一个要求刚被满足，此时 `next` 才能入队。

### 实例走过程

`numCourses=4, prerequisites=[[1,0],[2,0],[3,1],[3,2]]`。初始只有 0 入队。学完 0 得到队列 [1,2]；依次出队后，3 的入度从 2 降到 1 再到 0。最后学习 3，`learned=4`，返回 true。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        int[] inDegree = new int[numCourses];
        for (int[] edge : prerequisites) {
            graph.get(edge[1]).add(edge[0]);
            inDegree[edge[0]]++;
        }

        Queue<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        int learned = 0;
        while (!queue.isEmpty()) {
            int current = queue.poll();
            learned++;
            for (int next : graph.get(current)) {
                if (--inDegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }
        return learned == numCourses;
    }
}
```

### 易错点

建边要从先修课指向后续课。若有环，环内课程的入度无法一起消为零，最终 `learned < numCourses`。

### 复杂度

设课程数为 V、先修关系数为 E。时间和额外空间都是 O(V+E)。

## 54. 208. 实现 Trie (前缀树)（图论）

[力扣题目](https://leetcode.cn/problems/implement-trie-prefix-tree/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0208-implement-trie-prefix-tree/) · [代码随想录 · Java](https://programmercarl.com/hot100/0208.implement-trie-prefix-tree.html#java)

### 一句话总结

> 每个字符对应一条子节点边，完整单词的最后一个节点单独标记。

### 拿到这道题的第一思路

`root` 是空前缀。节点的 `children` 有 26 个位置，`isEnd` 记录是否有单词在此结束。

`insert` 沿 `c - 'a'` 逐字走，遇空位先创建节点；`search` 和 `startsWith` 沿同样的路径查找，任意一步找不到孩子就返回 false。

### 关键变量与始终保持的规则

走完字符后，`search` 返回当前节点的 `isEnd`，`startsWith` 直接返回 true。

### 实例走过程

依次 `insert("apple")`、`search("apple")`、`search("app")`、`startsWith("app")`、`insert("app")`、`search("app")`。第一次查 `app` 能走到第二个 `p`，但词尾标记尚未设置；插入 `app` 后，这个节点和 `apple` 的末尾都会标为词尾。四次查询结果为 `[true, false, true, true]`。

### Java代码

```java
class Trie {
    private static class TrieNode {
        final TrieNode[] children = new TrieNode[26];
        boolean isEnd;
    }

    private final TrieNode root = new TrieNode();

    public Trie() {
    }

    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int index = c - 'a';
            if (node.children[index] == null) {
                node.children[index] = new TrieNode();
            }
            node = node.children[index];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int index = c - 'a';
            if (node.children[index] == null) {
                return false;
            }
            node = node.children[index];
        }
        return node.isEnd;
    }

    public boolean startsWith(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int index = c - 'a';
            if (node.children[index] == null) {
                return false;
            }
            node = node.children[index];
        }
        return true;
    }
}
```

### 易错点

共享前缀仍然要更新新单词的词尾标记。前缀查询走完整条路径就成功。

### 复杂度

长度 L 的字符串每次操作用时 O(L)。N 个节点占空间 O(26N)，固定字母表下为 O(N)。

## 55. 46. 全排列（回溯）

[力扣题目](https://leetcode.cn/problems/permutations/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0046-permutations/) · [代码随想录 · Java](https://programmercarl.com/hot100/0046.permutations.html#java) · [总笔记·全排列](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnpP03YXWuupcEBhVhSthDCb)

### 一句话总结

> 每层从头选一个尚未使用的下标，填满路径后复制一份排列。

### 拿到这道题的第一思路

`path` 用 `LinkedList` 保存当前排列，`used[i]` 对应该下标是否在路径上，`result` 保存路径副本。

每层都从 `i=0` 开始枚举。选中时设置 `used[i]` 并加入路径。返回后调用 `removeLast()`，再撤销 `used[i]`。

### 关键变量与始终保持的规则

递归入口处，`path` 的长度等于 `used` 中 true 的数量。路径长度为 n 时收集结果并返回。

### 实例走过程

`nums=[1,2,3]`。先选 1、2、3 得到 `[1,2,3]`；退回到 `[1]` 后尝试 3、2 得到 `[1,3,2]`。继续以 2、3 开头，最终得到 6 个排列。

### Java代码

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;

class Solution {
    private List<List<Integer>> result;
    private final LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> permute(int[] nums) {
        result = new ArrayList<>();
        backtracking(nums, new boolean[nums.length]);
        return result;
    }

    private void backtracking(int[] nums, boolean[] used) {
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) {
                continue;
            }
            used[i] = true;
            path.add(nums[i]);
            backtracking(nums, used);
            path.removeLast();
            used[i] = false;
        }
    }
}
```

### 易错点

`used` 按原数组下标标记。每次同时撤销路径和标记；收集时要复制 `path`。

### 复杂度

时间 O(n·n!)，递归栈与当前路径等额外空间 O(n)，结果占 O(n·n!)。

## 56. 78. 子集（回溯）

[力扣题目](https://leetcode.cn/problems/subsets/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0078-subsets/) · [代码随想录 · Java](https://programmercarl.com/hot100/0078.subsets.html#java) · [总笔记·子集](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnn9kMQjjzcldrJObw9rhgNh)

### 一句话总结

> 递归树上的每个节点对应一个子集，进入本层就收集当前路径。

### 拿到这道题的第一思路

`path` 是链表路径，`result` 保存快照，参数 `start` 是本层最小可选下标。

进入递归先复制 `path`。把 `nums[i]` 加到末尾后，从 `i+1` 继续选；返回时 `removeLast()`。

### 关键变量与始终保持的规则

同一条路径上的下标严格递增，因此每组下标只会访问一次。根节点的空路径也要收集。

### 实例走过程

`nums=[1,2]`。入口先收 `[]`，选 1 收 `[1]`，继续选 2 收 `[1,2]`；退回空路径后，从 2 开始收 `[2]`。

### Java代码

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;

class Solution {
    private List<List<Integer>> result;
    private final LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> subsets(int[] nums) {
        result = new ArrayList<>();
        backtracking(nums, 0);
        return result;
    }

    private void backtracking(int[] nums, int start) {
        result.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            backtracking(nums, i + 1);
            path.removeLast();
        }
    }
}
```

### 易错点

递归起点传 `i+1`。收集所有递归节点，包括没有元素可选的节点。

### 复杂度

时间 O(n·2ⁿ)，递归与当前路径额外空间 O(n)，结果占 O(n·2ⁿ)。

## 57. 17. 电话号码的字母组合（回溯）

[力扣题目](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0017-letter-combinations-of-a-phone-number/) · [代码随想录 · Java](https://programmercarl.com/hot100/0017.letter-combinations-of-a-phone-number.html#java) · [总笔记·电话号码的字母组合](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnsiN1NRIM7iCar1v3WZh7Dh)

### 一句话总结

> 每层从当前数字的映射中选一个字母，遍历完所有数字后收集字符串。

### 拿到这道题的第一思路

`numString` 让数字值直接作为下标，`num` 是处理到的数字位置，`temp` 是当前拼出的 `StringBuilder`。

把当前数字字符减去 `'0'`，取得它对应的字母串。逐个追加字母，递归到 `num+1`，回来删除末尾。

### 关键变量与始终保持的规则

进入第 `num` 层时，`temp.length() == num`。到达 `digits.length()` 时用 `temp.toString()` 保存结果。

### 实例走过程

`digits="23"`。先取 `a`，第 2 层枚举 `d/e/f` 得到 `ad/ae/af`，然后撤销 `a`。同样以 `b`、`c` 开头各生成 3 个，共 9 个。

### Java代码

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private List<String> list;
    private final StringBuilder temp = new StringBuilder();

    public List<String> letterCombinations(String digits) {
        list = new ArrayList<>();
        if (digits == null || digits.isEmpty()) {
            return list;
        }
        String[] numString = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        backtracking(digits, numString, 0);
        return list;
    }

    private void backtracking(String digits, String[] numString, int num) {
        if (num == digits.length()) {
            list.add(temp.toString());
            return;
        }

        String letters = numString[digits.charAt(num) - '0'];
        for (int i = 0; i < letters.length(); i++) {
            temp.append(letters.charAt(i));
            backtracking(digits, numString, num + 1);
            temp.deleteCharAt(temp.length() - 1);
        }
    }
}
```

### 易错点

映射的 0、1 位置留空，保证 `'2' - '0'` 直接索引到 `abc`。空输入直接返回空列表。

### 复杂度

最坏时间 O(n·4ⁿ)，递归与 `temp` 用 O(n) 额外空间，结果最坏占 O(n·4ⁿ)。

## 58. 39. 组合总和（回溯）

[力扣题目](https://leetcode.cn/problems/combination-sum/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0039-combination-sum/) · [代码随想录 · Java](https://programmercarl.com/hot100/0039.combination-sum.html#java) · [总笔记·组合总和](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnTOL5L8tq12F4ymGG4bW6ah)

### 一句话总结

> 排序后按下标递增选数，用累计和判断何时收集、何时停止枚举。

### 拿到这道题的第一思路

`sum` 是 `path` 内元素的总和。`start` 是本层起点。`path` 用链表支持 `removeLast()`。

先排序，若 `sum == target` 就收集并返回；循环只在 `sum + nums[i] <= target` 时继续。选中后递归传 `i`，允许复用这个位置。

### 关键变量与始终保持的规则

进入递归时携带 `sum + nums[i]`。父帧保留原 `sum`，回来只需撤销路径末尾。

### 实例走过程

`candidates=[2,3,6,7], target=7`。路径 `[2,2,2]` 的 `sum=6`，下一项最小也是 2，于是停止；回到 `[2,2]` 后选 3，得到 `[2,2,3]`。根层选 7，直接得到 `[7]`。

### Java代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.LinkedList;
import java.util.List;

class Solution {
    private List<List<Integer>> result;
    private final LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        result = new ArrayList<>();
        Arrays.sort(candidates);
        backtracking(candidates, target, 0, 0);
        return result;
    }

    private void backtracking(int[] nums, int target, int sum, int start) {
        if (sum == target) {
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < nums.length && sum + nums[i] <= target; i++) {
            path.add(nums[i]);
            backtracking(nums, target, sum + nums[i], i);
            path.removeLast();
        }
    }
}
```

### 易错点

`i` 与 `i+1` 决定同一个数可否复用。循环遇到第一项超出目标就结束，依赖候选值已经排序。Java 实现会原地排序输入。

### 复杂度

设 n 是候选数，D=⌊target/min(candidates)⌋，S 是实际访问的递归节点数，K 是结果数，时间 O(n log n+S+KD)，递归和路径用 O(D) 额外空间，结果最多占 O(KD)。

## 59. 22. 括号生成（回溯）

[力扣题目](https://leetcode.cn/problems/generate-parentheses/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0022-generate-parentheses/) · [代码随想录 · Java](https://programmercarl.com/hot100/0022.generate-parentheses.html#java) · [总笔记·回溯三部曲](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnHRsfE8p88xxSawvwouOR91)

### 一句话总结

> 左括号还有配额就能放，右括号要等前面已有未匹配的左括号才能放。

### 拿到这道题的第一思路

`left`、`right` 分别是已经写入的左右括号数，`path` 是当前括号串。

先判断 `path.length() == 2*n`，达到就保存。否则分别尝试 `left < n` 时加左括号、`right < left` 时加右括号，返回后删掉最后一个字符。

### 关键变量与始终保持的规则

每个递归前缀始终满足 `0 <= right <= left <= n`。长度到 `2*n` 时，左右两类的数量自然都等于 n。

### 实例走过程

`n=3`。优先试左分支，先得到 `((()))`。退回到 `((` 后试右分支，继续生成 `(()())` 和 `(())()`；以 `()` 开头的分支再生成 `()(())`、`()()()`。

### Java代码

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private List<String> result;

    public List<String> generateParenthesis(int n) {
        result = new ArrayList<>();
        backtracking(n, 0, 0, new StringBuilder());
        return result;
    }

    private void backtracking(int n, int left, int right, StringBuilder path) {
        if (path.length() == 2 * n) {
            result.add(path.toString());
            return;
        }
        if (left < n) {
            path.append('(');
            backtracking(n, left + 1, right, path);
            path.deleteCharAt(path.length() - 1);
        }
        if (right < left) {
            path.append(')');
            backtracking(n, left, right + 1, path);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

### 易错点

两类括号是独立分支，所以用两个 `if`。判断右括号可否放时对照 `right < left`。

### 复杂度

设 Cₙ 为第 n 个卡特兰数，时间 O(n·Cₙ)，递归与路径 O(n)，输出占 O(n·Cₙ)。

## 60. 79. 单词搜索（回溯）

[力扣题目](https://leetcode.cn/problems/word-search/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0079-word-search/) · [代码随想录 · Java](https://programmercarl.com/hot100/0079.word-search.html#java) · [总笔记·回溯三部曲](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnHRsfE8p88xxSawvwouOR91) · [总笔记·全排列](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnpP03YXWuupcEBhVhSthDCb)

### 一句话总结

> 从每个格子尝试匹配单词，路径上的格子暂时写成 '#'，从递归返回时复原。

### 拿到这道题的第一思路

`index` 是待匹配字符的位置。`board` 临时保存路径标记，`saved` 记当前格原字符。

先检查单词是否匹配完毕。否则，越界、字符不同或看见 '#' 就返回 false。命中后用短路或按下、上、右、左继续查找。

### 关键变量与始终保持的规则

`index == word.length()` 代表上一层已经匹配最后一个字符。无论接下来的分支是否成功，都先恢复本层字符，再返回 `found`。

### 实例走过程

`board=["ABCE","SFCS","ADEE"], word="ABCCED"`。成功路径为 (0,0)→(0,1)→(0,2)→(1,2)→(2,2)→(2,1)。每走一步可看到一个字符变成 '#'；成功后一路返回，各格依次恢复。

### Java代码

```java
class Solution {
    private int rows;
    private int cols;

    public boolean exist(char[][] board, String word) {
        rows = board.length;
        cols = board[0].length;
        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (backtracking(board, word, row, col, 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean backtracking(char[][] board, String word, int row, int col, int index) {
        if (index == word.length()) {
            return true;
        }
        if (row < 0 || row >= rows || col < 0 || col >= cols
                || board[row][col] == '#' || board[row][col] != word.charAt(index)) {
            return false;
        }

        char saved = board[row][col];
        board[row][col] = '#';
        boolean found = backtracking(board, word, row + 1, col, index + 1)
                || backtracking(board, word, row - 1, col, index + 1)
                || backtracking(board, word, row, col + 1, index + 1)
                || backtracking(board, word, row, col - 1, index + 1);
        board[row][col] = saved;
        return found;
    }
}
```

### 易错点

成功终止条件要在读当前坐标之前；匹配完最后一个字母时，下一次调用可能已越界。原字符恢复写在 `return found` 之前。

### 复杂度

设单词长度为 L，时间上界 O(mn·4·3^(L−1))，递归栈 O(L)。
