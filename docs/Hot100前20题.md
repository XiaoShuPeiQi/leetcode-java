## 01. 1. 两数之和（哈希）

[力扣题目](https://leetcode.cn/problems/two-sum/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0001-two-sum/)

沿用总笔记中本题的主解。

### 一句话总结

> 用当前数需要的另一半，查询已经遍历过的数。

### 拿到这道题的第一思路

1. 最直接是固定一个数，再扫描后面有没有target-nums[i]，时间O(n²)。
2. 第二层循环只是在查找一个值，可以用Map把“值→下标”存起来。
3. 先查temp；找到时分别写入res[0]和res[1]，没找到才把当前数及下标放进map。循环结束统一返回res。题目保证恰好一个答案。

### 关键变量与始终保持的规则

res长度为2，res[0]保存之前那个数的下标，res[1]保存当前下标；temp=target-nums[i]；map只包含已经处理过的元素。

### 实例走过程

```text
nums=[2,7,11,15], target=9
初始res=[0,0]，map为空
i=0：temp=7，没找到，保存2→0
i=1：temp=2，找到下标0，写入res[0]=0、res[1]=1
i=2、3继续检查，没有其他配对；循环结束返回res=[0,1]。
```

### Java代码

```java
import java.util.*;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        int[] res = new int[2]; // res[0]和res[1]分别保存两个数的下标
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int temp = target - nums[i];
            if (map.containsKey(temp)) {
                res[0] = map.get(temp); // 之前那个数的下标
                res[1] = i;            // 当前数的下标
            } else {
                map.put(nums[i], i); // 没找到配对时，记录当前数供后面查询
            }
        }

        return res;
    }
}
```

### 易错点

res保存下标，不是数值。找到配对时写res，只有没找到时才执行map.put，避免用当前下标和自己配对。此写法利用题目保证恰好一个答案；无解情况不属于本题输入范围。

### 复杂度

平均时间O(n)，额外空间O(n)。

## 02. 49. 字母异位词分组（哈希）

[力扣题目](https://leetcode.cn/problems/group-anagrams/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0049-group-anagrams/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 排序后的字符相同，就把单词放进同一组。

### 拿到这道题的第一思路

1. 逐对判断是否异位词会重复比较。既然只看每种字母的数量，先为每个单词生成共同标识。
2. 沿用哈希表章节“把不方便比较的对象转成key”的思路：排序后的字符串作为key，Map的value保存一组原单词。
3. 每个单词只归入自己的key，最后收集所有分组；组间与组内顺序均不影响答案。

### 关键变量与始终保持的规则

res保存最终的分组列表；key是排序后的字符序列；map[key]保存拥有相同key的一组原字符串。先创建组、再加入单词，最后把各组放入res。

### 实例走过程

```text
strs=["eat","tea","tan","ate","nat","bat"]
eat→aet：[eat]；tea→aet：[eat,tea]
tan→ant：[tan]；ate→aet：[eat,tea,ate]
nat→ant：[tan,nat]；bat→abt：[bat]
得到三组，返回顺序不固定。
```

### Java代码

```java
import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> res = new ArrayList<>(); // 保存最终的各组单词
        Map<String, List<String>> map = new HashMap<>();

        for (String str : strs) {
            char[] chars = str.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);

            if (!map.containsKey(key)) { // 第一次遇到这个key，先创建一组
                List<String> group = new ArrayList<>();
                map.put(key, group);
            }
            List<String> group = map.get(key);
            group.add(str); // 把原单词放入对应分组
        }

        for (List<String> group : map.values()) {
            res.add(group);
        }
        return res;
    }
}
```

### 易错点

不能直接用char[]作内容相等的key；必须new String(chars)。空字符串和重复字符串都要保留。

### 复杂度

设单词数n、最长长度L：时间O(nL log(L+1))，保存key和分组共O(nL+n)空间。

### 方法对比

计数签名也可做key，时间可降到O(nL)，但必须用分隔符编码26个计数，避免不同计数组合拼成同一个字符串。排序key更直观。

## 03. 128. 最长连续序列（哈希）

[力扣题目](https://leetcode.cn/problems/longest-consecutive-sequence/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0128-longest-consecutive-sequence/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 只从没有前驱的数出发，向右数完整段。

### 拿到这道题的第一思路

1. 排序后扫描很直接，但时间O(n log n)。题目要求O(n)，先用HashSet支持平均O(1)查数并去重。
2. 如果每个数都向右找，长连续段会被重复扫描。一个数的前驱num-1存在，说明它不是段起点，跳过。
3. 只有段起点向右扩展，各段互不重叠，累计扩展次数为不同数的数量。

### 关键变量与始终保持的规则

set存不同数；num是候选起点；current是本段末尾；length是本段长度；res是最长长度。

### 实例走过程

```text
nums=[100,4,200,1,3,2]
set={1,2,3,4,100,200}，遍历顺序不作保证
1无前驱：1→2→3→4，长度4
2、3、4有前驱，跳过；100和200各为1
返回4。
```

### Java代码

```java
import java.util.*;

class Solution {
    public int longestConsecutive(int[] nums) {
        int res = 0; // 保存已经找到的最长连续段长度
        Set<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }

        for (int num : set) {
            if (set.contains(num - 1)) { // 有前驱就不是起点，避免重复扫描同一段
                continue;
            }

            int current = num;
            int length = 1;
            while (set.contains(current + 1)) {
                current++;
                length++;
            }
            if (length > res) {
                res = length;
            }
        }
        return res;
    }
}
```

### 易错点

遍历去重后的set；若遍历原数组且起点大量重复，会反复扩展同一段。题目数值范围内num±1不会溢出。

### 复杂度

平均时间O(n)，额外空间O(n)。

## 04. 283. 移动零（双指针）

[力扣题目](https://leetcode.cn/problems/move-zeroes/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0283-move-zeroes/)

沿用总笔记中本题的主解。

### 一句话总结

> 先稳定收集非零元素，再把剩余位置补零。

### 拿到这道题的第一思路

1. 把0看成要移除的元素，就能直接沿用数组章节的快慢指针覆盖法。
2. fast只负责读，slow指向下一个写入位置；遇到非零数就写入，保证原相对顺序。
3. 收集结束后，[0,slow)已经正确，必须继续把[slow,n)补0。

### 关键变量与始终保持的规则

fast是读位置；slow既是非零数个数，也是下一次写入的位置。方法返回void，答案在nums中。

### 实例走过程

```text
nums=[0,1,0,3,12]
收集1→[1,1,0,3,12]，slow=1
收集3→[1,3,0,3,12]，slow=2
收集12→[1,3,12,3,12]，slow=3
从下标3补零→[1,3,12,0,0]
```

### Java代码

```java
class Solution {
    public void moveZeroes(int[] nums) {
        // 结果直接写回nums：先收集非零元素，再在剩余位置补零
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        // 有效前缀之外必须全部补零
        for (int i = slow; i < nums.length; i++) {
            nums[i] = 0;
        }
    }
}
```

### 易错点

只覆盖非零数而不补零会残留旧值；不能排序，排序会破坏非零数的相对顺序。

### 复杂度

时间O(n)，额外空间O(1)。

## 05. 11. 盛最多水的容器（双指针）

[力扣题目](https://leetcode.cn/problems/container-with-most-water/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0011-container-with-most-water/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 先算当前两端面积，再移动较短的那一侧。

### 拿到这道题的第一思路

1. 面积=两端较小高度×间距，暴力枚举两端是O(n²)。
2. 从最宽的两端开始。若保留短板只移动高板，宽度减少、有效高度又不能增加，面积不可能更大。
3. 因此移动短板，尝试找到更高的板；每次先更新面积，再缩边界。两端相等时移动任一侧都可以。

### 关键变量与始终保持的规则

left、right是两块板的下标；res保存已经检查过的最大面积。

### 实例走过程

```text
height=[1,8,6,2,5,4,8,3,7]
[0,8]：min(1,7)*8=8，移动left
[1,8]：min(8,7)*7=49，移动right
[1,7]：min(8,3)*6=18，继续移动right
后续面积都不超过49，返回49。
```

### Java代码

```java
class Solution {
    public int maxArea(int[] height) {
        int res = 0; // 保存最大容积
        int left = 0;
        int right = height.length - 1;

        while (left < right) {
            int shorterHeight = Math.min(height[left], height[right]);
            int width = right - left;
            int area = shorterHeight * width;
            if (area > res) {
                res = area;
            }

            // 面积受短板限制，移动短板才可能找到更大容积
            if (height[left] <= height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return res;
    }
}
```

### 易错点

宽度是right-left；题目是两块板形成的容器，不能把中间柱子的高度从面积里扣掉。

### 复杂度

时间O(n)，额外空间O(1)。

## 06. 15. 三数之和（双指针）

[力扣题目](https://leetcode.cn/problems/3sum/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0015-3sum/)

沿用总笔记中本题的主解。

### 一句话总结

> 排序固定一个数，再用相向指针找另外两个数，并按值去重。

### 拿到这道题的第一思路

1. 沿用哈希表章节原解法：三重循环先固定一个数，剩余两数之和可以通过有序性缩小范围。
2. 排序后，sum<0就增大left，sum>0就减小right；固定值已经大于0时可以停止。
3. i层先去重；命中三元组后，左右指针分别跨过相同值，再向内走。

### 关键变量与始终保持的规则

i固定第一个数；left、right搜索后面的两个数，始终i<left<right；res存不同数值三元组。

### 实例走过程

```text
nums=[-1,0,1,2,-1,-4]，排序[-4,-1,-1,0,1,2]
i=0固定-4，找不到
i=1固定-1：left=2,right=5，和0→[-1,-1,2]
向内后left=3,right=4，和0→[-1,0,1]
i=2的-1与前一个相同，跳过，最终两组。
```

### Java代码

```java
import java.util.*;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>(); // 每个内部列表保存一个三元组
        Arrays.sort(nums);
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) {
                break;
            }
            // 同一层固定值只处理一次，仍允许一组中有相同数值。
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;
            while (left < right) {
                long sum = (long) nums[i] + nums[left] + nums[right];
                if (sum < 0) {
                    left++;
                } else if (sum > 0) {
                    right--;
                } else {
                    List<Integer> triple = new ArrayList<>();
                    triple.add(nums[i]);
                    triple.add(nums[left]);
                    triple.add(nums[right]);
                    res.add(triple);
                    // 先保存，再跨过相同的左右值。
                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }
                    left++;
                    right--;
                }
            }
        }
        return res;
    }
}
```

### 易错点

去重按数值，不能禁止同组三个数中出现重复值；例如[-1,-1,2]合法。Arrays.sort会修改输入。

### 复杂度

时间O(n²)，排序辅助空间O(log n)，另计答案空间。

## 07. 42. 接雨水（双指针）

[力扣题目](https://leetcode.cn/problems/trapping-rain-water/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0042-trapping-rain-water/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 每列水量由左右最高板中较矮的一块决定，先结算边界较低的一侧。

### 拿到这道题的第一思路

1. 先按列想：当前位置能接min(左侧最高,右侧最高)-当前高度，负数算0。
2. 可先做左右最大值数组理解，再省空间：leftMax、rightMax记录两侧已经见过的最高板。
3. 更新两侧最大值后，较小的一侧已经有足够高的对岸保证，当前位置水量可确定；结算后移动对应指针。

### 关键变量与始终保持的规则

left、right围住尚未结算的列；leftMax、rightMax包含当前端点；res是已结算水量之和。

### 实例走过程

```text
height=[0,1,0,2,1,0,1,3,2,1,2,1]
下标2：左右最高至少1和3，接1
下标4、5、6：左最高2，右最高3，分别接1、2、1
下标9：两边最高至少3和2，接1
累计1+1+2+1+1=6。调试器按实际左右结算顺序显示。
```

### Java代码

```java
class Solution {
    public int trap(int[] height) {
        int res = 0; // 累加每一列的接水量
        int left = 0;
        int right = height.length - 1;
        int leftMax = 0;
        int rightMax = 0;

        while (left <= right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            if (leftMax <= rightMax) { // 右侧足够高，可以确定左侧这一列的水量
                int water = leftMax - height[left];
                res += water;
                left++;
            } else {
                int water = rightMax - height[right];
                res += water;
                right--;
            }
        }
        return res;
    }
}
```

### 易错点

容器题只算两端面积，本题必须逐列累加水量；比较两边最大值之前先更新它们。

### 复杂度

时间O(n)，额外空间O(1)。

### 方法对比

左右最大值数组更适合初次手算：两趟预处理后逐列计算，O(n)时间、O(n)空间；主解保留相同的按列思路，把辅助数组压缩为两个最大值。

## 08. 3. 无重复字符的最长子串（滑动窗口）

[力扣题目](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0003-longest-substring-without-repeating-characters/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 右端加入字符，若重复就收缩左端，直到窗口重新无重复。

### 拿到这道题的第一思路

1. 要求连续子串，先沿用数组章节滑动窗口：right扩张、left修复窗口。
2. 用Set保存窗口内字符。加入c前，如果它已经在窗口中，就不断移走最左字符，直到旧c也离开。
3. 加入c后窗口无重复，此时用right-left+1更新最长长度。

### 关键变量与始终保持的规则

窗口是[left,right]；set与当前窗口包含相同字符，且没有重复；res是最长合法长度。

### 实例走过程

```text
s="abcabcbb"
right=0..2：窗口a→ab→abc，res=3
right=3遇a：删旧a，left=1，加入新a，窗口bca
继续遇b/c也先删除各自旧位置
末尾b会连续收缩，最长仍为3。
```

### Java代码

```java
import java.util.*;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        int res = 0; // 保存最长无重复子串的长度
        Set<Character> set = new HashSet<>();
        int left = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            while (set.contains(c)) { // 一直缩到旧的同字符离开窗口
                char removed = s.charAt(left);
                set.remove(removed);
                left++;
            }
            set.add(c);

            int length = right - left + 1; // 此时窗口已经没有重复字符
            if (length > res) {
                res = length;
            }
        }
        return res;
    }
}
```

### 易错点

缩窗必须用while而非if；例如abba第二个b出现时，要移走a和旧b。空串返回0。

### 复杂度

平均时间O(n)，额外空间O(min(n,字符集大小))。

## 09. 438. 找到字符串中所有字母异位词（滑动窗口）

[力扣题目](https://leetcode.cn/problems/find-all-anagrams-in-a-string/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0438-find-all-anagrams-in-a-string/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 维护长度等于p的窗口，比较26个字母的频次。

### 拿到这道题的第一思路

1. 异位词只看字母数量，不看顺序；把49题的分组判定放到连续窗口里。
2. p长度固定，所以窗口也固定为p.length()；右端每加入一个字符，超过长度就删掉最左字符。
3. 窗口达到目标长度后，若26个计数都相等，就记录左端下标。

### 关键变量与始终保持的规则

need记录p的频次；window记录当前窗口频次；left是当前左端；窗口长度最多为p.length()。

### 实例走过程

```text
s="cbaebabacd", p="abc"
right=2：窗口cba，频次相同，记录0
加入e时移走c，窗口bae，不匹配
持续右移，right=8：窗口bac，记录6
返回[0,6]。
```

### Java代码

```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>(); // 保存每个匹配窗口的起始下标
        int[] need = new int[26];
        int[] window = new int[26];
        for (int i = 0; i < p.length(); i++) {
            need[p.charAt(i) - 'a']++;
        }
        int left = 0;
        for (int right = 0; right < s.length(); right++) {
            window[s.charAt(right) - 'a']++;
            if (right - left + 1 > p.length()) { // 固定窗口只移走一个最左字符
                window[s.charAt(left) - 'a']--;
                left++;
            }
            boolean sameCounts = Arrays.equals(need, window);
            if (right - left + 1 == p.length() && sameCounts) {
                res.add(left); // 当前窗口的左端就是一个答案下标
            }
        }
        return res;
    }
}
```

### 易错点

只判断字符是否存在不够，还要比较次数；返回的是下标列表，重叠窗口也要检查。

### 复杂度

字符集固定26：时间O(26n+m)，可视为O(n+m)；辅助空间O(26)，另计答案。

### 一句话总结

### 拿到这道题的第一思路

1. 连续区间先想到前缀和：区间和=右侧前缀和-左侧前缀和。
2. 本题含负数，窗口扩大时和不一定增大，不能照搬正数数组的缩窗条件。
3. 扫描右端，查询之前sum-k出现次数，加到答案，再记录当前sum；次数而非是否存在决定有多少个区间。

### 关键变量与始终保持的规则

sum是当前前缀和；count[prefix]是此前该前缀和出现次数；res统计已找到的非空子数组。

### 实例走过程

```text
nums=[1,1,1], k=2
初始count={0:1}，表示空前缀
读第1个1：sum=1，找-1为0，记录1→1
读第2个1：sum=2，找0为1，res=1，记录2→1
读第3个1：sum=3，找1为1，res=2
返回2，对应下标[0,1]和[1,2]。
```

### Java代码

```java
import java.util.*;

class Solution {
    public int subarraySum(int[] nums, int k) {
        int res = 0; // 保存和为k的非空子数组个数
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1); // 空前缀出现一次，使从下标0开始的区间也能被统计
        int sum = 0;

        for (int num : nums) {
            sum += num;
            int neededPrefix = sum - k;
            int matchedCount = count.getOrDefault(neededPrefix, 0);
            res += matchedCount; // 每一个匹配的旧前缀，都对应一个合法区间

            // 先统计答案，再记录当前前缀，避免k=0时把空区间计入
            int oldCount = count.getOrDefault(sum, 0);
            count.put(sum, oldCount + 1);
        }
        return res;
    }
}
```

### 易错点

必须count.put(0,1)，否则漏掉从下标0开始的区间；先查询再记录，k=0时才不会多算空区间。

### 复杂度

平均时间O(n)，额外空间O(n)。

## 11. 239. 滑动窗口最大值（子串）

[力扣题目](https://leetcode.cn/problems/sliding-window-maximum/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0239-sliding-window-maximum/)

沿用总笔记中本题的下标单调队列解法。

### 一句话总结

> 队首删过期下标，队尾删不可能更优的候选，队首就是最大值。

### 拿到这道题的第一思路

1. 沿用栈与队列笔记的下标单调队列解法。每个窗口重新扫描要O(nk)，相邻窗口的大部分元素其实不变。
2. 新数更大或相等，而且过期更晚，队尾较小或相等的旧候选以后都不会更优，可以删除。
3. 队首先检查是否过期，队尾再淘汰弱候选，加入right；窗口满k后再输出队首对应数值。

### 关键变量与始终保持的规则

deque存下标，下标递增、对应值严格递减；left=right-k+1；write是答案写入位置。

### 实例走过程

```text
nums=[1,3,-1,-3,5,3,6,7], k=3
right=2：队列[1:3,2:-1]，输出3
right=3：队列[1:3,2:-1,3:-3]，输出3
right=4：下标1过期；5淘汰队尾-3、-1，输出5
之后输出5、6、7，结果[3,3,5,5,6,7]。
```

### Java代码

```java
import java.util.*;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int[] res = new int[nums.length - k + 1]; // 每个完整窗口对应一个答案
        int write = 0;
        Deque<Integer> deque = new ArrayDeque<>();

        for (int right = 0; right < nums.length; right++) {
            int left = right - k + 1;

            // 队首按下标判断是否已经离开窗口
            while (!deque.isEmpty() && deque.peekFirst() < left) {
                deque.pollFirst();
            }
            // 队尾按数值淘汰旧候选：新数更大或相等，且过期更晚
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[right]) {
                deque.pollLast();
            }
            deque.offerLast(right);

            if (left >= 0) { // 窗口凑满k个元素后，才向结果数组写入
                int maxIndex = deque.peekFirst();
                res[write] = nums[maxIndex];
                write++;
            }
        }
        return res;
    }
}
```

### 易错点

删队首比较下标，删队尾比较数值；队列必须存下标，才能精确判断过期。窗口未满不能写答案。

### 复杂度

时间O(n)，队列空间O(k)，另计O(n-k+1)结果空间。



## 12. 76. 最小覆盖子串（子串）

[力扣题目](https://leetcode.cn/problems/minimum-window-substring/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0076-minimum-window-substring/)

沿用总笔记中本题的主解。

### 一句话总结

> 右端还清目标字符欠账后，连续缩左端，寻找最短有效窗口。

### 拿到这道题的第一思路

1. 沿用数组章节的欠账窗口主解：不是要求窗口无重复，而是要求覆盖t的所有字符及次数。
2. need[c]>0表示仍欠c，等于0表示恰好够，负数表示多余；missing是尚缺字符的总个数。
3. 右端加入直到missing=0；每次缩左端之前记录答案，移走必需字符后窗口失效，再继续扩张。

### 关键变量与始终保持的规则

[left,right]是当前窗口；bestStart、bestLength保存最短有效窗口；missing按字符总数计，含重复次数。

### 实例走过程

```text
s="ADOBECODEBANC", t="ABC"
right=5读C：ADOBEC首次覆盖，记录长度6
移走A后失效；right=10读A后再次收缩
right=12读C后连续移走多余字符，得到BANC，长度4
再移走B会失效，返回BANC。
```

### Java代码

```java
class Solution {
    public String minWindow(String s, String t) {
        String res = ""; // 没有找到覆盖窗口时，答案就是空字符串
        if (t.length() == 0 || s.length() < t.length()) {
            return res;
        }

        int[] need = new int[128];
        for (int i = 0; i < t.length(); i++) {
            need[t.charAt(i)]++;
        }
        int missing = t.length();
        int left = 0;
        int bestStart = 0;
        int bestLength = Integer.MAX_VALUE;

        for (int right = 0; right < s.length(); right++) {
            char added = s.charAt(right);
            if (need[added] > 0) { // 加入前仍欠这个字符，才补掉一个缺口
                missing--;
            }
            need[added]--;

            while (missing == 0) {
                int length = right - left + 1;
                if (length < bestLength) {
                    bestStart = left;
                    bestLength = length;
                }

                char removed = s.charAt(left);
                need[removed]++;
                if (need[removed] > 0) { // 移走后重新欠字符，窗口变为无效
                    missing++;
                }
                left++;
            }
        }

        if (bestLength != Integer.MAX_VALUE) {
            int end = bestStart + bestLength;
            res = s.substring(bestStart, end); // substring右端不包含end
        }
        return res;
    }
}
```

### 易错点

更新最短答案要在有效窗口内、移走左字符之前；比较的是总次数，t="AABC"需要两个A。

### 复杂度

时间O(|s|+|t|)，题目英文字母范围下额外空间O(128)。

## 13. 53. 最大子数组和（普通数组）

[力扣题目](https://leetcode.cn/problems/maximum-subarray/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0053-maximum-subarray/)

沿用总笔记中本题的主解。

### 一句话总结

> 负的累计和只会拖累后面的段，更新答案后再丢掉它。

### 拿到这道题的第一思路

1. 直接沿用贪心章节主解。连续子数组不能跳着选，当前累计和若为负，加到未来段前面只会更差。
2. 每读一个数，先累加，再用sum更新res；然后sum<0时归零，从后一个数重新起段。
3. res从nums[0]初始化，保证全负数组也能返回最大负数，而不是空数组的0。

### 关键变量与始终保持的规则

sum是当前保留段的累计和；res是已经遇到的最大非空子数组和。sum置0只用于后续，不把空段记入答案。

### 实例走过程

```text
nums=[-2,1,-3,4,-1,2,1]
-2：先更新res=-2，再把sum清零
1：res=1；接-3后sum=-2，清零
从4重新开始：4→3→5→6
返回6，对应[4,-1,2,1]。
```

### Java代码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int res = nums[0]; // 必须选非空子数组，全负数组也能得到正确答案
        int sum = 0;

        for (int num : nums) {
            sum += num;
            if (sum > res) {
                res = sum;
            }
            if (sum < 0) { // 先记录答案，再丢掉会拖累后面元素的负前缀
                sum = 0;
            }
        }
        return res;
    }
}
```

### 易错点

必须先更新res再把负sum归零；全负数组例如[-3,-2]应返回-2。

### 复杂度

时间O(n)，额外空间O(1)。

### 方法对比

原笔记也给出DP：dp[i]表示以i结尾的最大和，dp[i]=max(nums[i],dp[i-1]+nums[i])；初始化dp[0]=nums[0]，从左向右，最后取全局最大。例4→max(-1,4-1)=3→5→6。与主解的区别是DP允许状态为负，贪心把负前缀直接丢弃。

## 14. 56. 合并区间（普通数组）

[力扣题目](https://leetcode.cn/problems/merge-intervals/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0056-merge-intervals/)

沿用总笔记中本题的主解。

### 一句话总结

> 按左端排序后，只需判断当前区间与结果最后一段是否重叠。

### 拿到这道题的第一思路

1. 沿用贪心章节原主解。区间没排序时，重叠关系不好判断，先按左端升序排列。
2. 若current[0]大于最后一段右端，说明中间有空隙，新增一段。
3. 否则重叠，只延长最后一段的右端。res先预留n行，count记录有效段数；循环结束裁剪到count行，再统一返回res。

### 关键变量与始终保持的规则

res先分配n行，count表示其中已经写好的区间个数；只有[0,count)有效。current是当前区间，重叠时更新res[count-1]的右端，最后把res裁剪为count行。

### 实例走过程

```text
intervals=[[1,3],[2,6],[8,10],[15,18]]
[1,3]加入结果；[2,6]与它重叠→[1,6]
8>6，新段[8,10]；15>10，新段[15,18]
返回[[1,6],[8,10],[15,18]]。
```

### Java代码

```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        int[][] res = new int[intervals.length][2]; // 最多产生n段，先分配足够的结果位置
        int count = 0; // res中已经写好的区间个数
        intervals = intervals.clone();
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        for (int[] current : intervals) {
            if (count == 0 || current[0] > res[count - 1][1]) {
                res[count][0] = current[0]; // 没有重叠，写入一段新的区间
                res[count][1] = current[1];
                count++;
            } else {
                int lastEnd = res[count - 1][1];
                if (current[1] > lastEnd) { // 有重叠，只需要延长最后一段的右端
                    res[count - 1][1] = current[1];
                }
            }
        }

        res = Arrays.copyOf(res, count); // 只保留已经写入的count段，去掉未使用的位置
        return res;
    }
}
```

### 易错点

端点相等也算重叠，只有current[0]>res[count-1][1]才新开段。返回前要裁剪结果，避免带上未使用的[0,0]行；外层克隆后排序，不改变原输入的区间顺序或端点。

### 复杂度

时间O(n log n)；克隆、排序与结果需要O(n)空间。

## 15. 189. 轮转数组（普通数组）

[力扣题目](https://leetcode.cn/problems/rotate-array/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0189-rotate-array/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 整体反转，再分别反转前k个与剩下部分。

### 拿到这道题的第一思路

1. 右移k位，本质是把最后k个元素搬到最前面，同时保持两段内部顺序。
2. 沿用字符串章节的反转技巧：原数组是AB，整体反转得到reverse(B)reverse(A)。
3. 分别反转这两段后得到BA；k先对n取模，避免无效的整圈移动。

### 关键变量与始终保持的规则

k是归一化后的右移量；reverse处理闭区间[left,right]，交换后两端向内收缩。

### 实例走过程

```text
nums=[1,2,3,4,5,6,7], k=3
整体反转：[7,6,5,4,3,2,1]
反转[0,2]：[5,6,7,4,3,2,1]
反转[3,6]：[5,6,7,1,2,3,4]
```

### Java代码

```java
class Solution {
    public void rotate(int[] nums, int k) {
        // 结果直接写回nums，三次反转完成右移
        k %= nums.length;
        // 整体反转后分别恢复两段内部顺序，AB变成BA
        reverse(nums, 0, nums.length - 1); // 先反转整个数组
        reverse(nums, 0, k - 1); // 恢复前k个元素的顺序
        reverse(nums, k, nums.length - 1); // 恢复剩余元素的顺序
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

### 易错点

这是右移，分割位置是k；k可能大于n；k=0时第一段为空，reverse的while会自然跳过。

### 复杂度

时间O(n)，额外空间O(1)。

## 16. 238. 除了自身以外数组的乘积（普通数组）

[力扣题目](https://leetcode.cn/problems/product-of-array-except-self/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0238-product-of-array-except-self/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 答案等于左边所有数的乘积，再乘右边所有数的乘积。

### 拿到这道题的第一思路

1. 不能用除法，而且0会让总乘积失去信息；改用数组章节“累计信息”的思路，只把加法前缀改成乘法。
2. 第一趟令res[i]等于i左侧乘积，不包含nums[i]。
3. 第二趟从右向左，用rightProduct保存右侧乘积；先乘入答案，再把nums[i]纳入rightProduct。

### 关键变量与始终保持的规则

leftProduct始终不含当前数；第二趟rightProduct也不含当前数；res数组先存左乘积，再变成左右乘积。

### 实例走过程

```text
nums=[1,2,3,4]
第一趟res=[1,1,2,6]
从右向左：i=3乘1得6，rightProduct变4
i=2乘4得8，rightProduct变12
i=1乘12得12；i=0乘24得24
返回[24,12,8,6]。
```

### Java代码

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int[] res = new int[nums.length]; // res[i]最终保存除nums[i]外的全部元素乘积
        int leftProduct = 1;
        for (int i = 0; i < nums.length; i++) {
            res[i] = leftProduct; // 先写入左侧乘积，此时不包含nums[i]
            leftProduct *= nums[i];
        }

        int rightProduct = 1;
        for (int i = nums.length - 1; i >= 0; i--) {
            res[i] = res[i] * rightProduct; // 左侧乘积再乘右侧乘积
            rightProduct *= nums[i];
        }
        return res;
    }
}
```

### 易错点

累计乘积的更新必须放在使用之后，否则会把自身乘入答案；空的一侧乘积取1。0无需特判。

### 复杂度

时间O(n)，除返回数组外额外空间O(1)。

### 拿到这道题的第一思路

1. HashSet容易做，但要求O(1)额外空间。长度n的数组，最小缺失正数一定在[1,n+1]。

3. 归位后从左向右检查，nums[i]!=i+1时返回i+1；全对就返回n+1。

### 关键变量与始终保持的规则

i是当前归位位置；target=nums[i]-1是该值应去的位置；只处理[1,n]内且尚未就位的值。 res先设为n+1，扫描到第一个错位位置时更新res并结束检查，最后统一返回。

### 实例走过程

```text
nums=[3,4,-1,1]
i=0：3换到下标2→[-1,4,3,1]
i=1：4换到下标3→[-1,1,3,4]
当前1继续换到下标0→[1,-1,3,4]
检查下标1应为2却是-1，返回2。
```

### Java代码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        int res = n + 1; // 1到n都存在时，答案就是n+1

        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int target = nums[i] - 1; // 值x应该放到下标x-1；重复值已就位时停止
                int temp = nums[target];
                nums[target] = nums[i];
                nums[i] = temp;
            }
        }

        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                res = i + 1;
                break; // 第一个错位的位置，就是最小缺失正数
            }
        }
        return res;
    }
}
```

### 易错点

交换后新来的数还需继续处理，所以用while；先检查范围再访问nums[nums[i]-1]；重复值必须停止交换，防止死循环。

### 复杂度

时间O(n)，每次有效交换至少把一个值放到正确位置；额外空间O(1)。

## 18. 73. 矩阵置零（矩阵）

[力扣题目](https://leetcode.cn/problems/set-matrix-zeroes/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0073-set-matrix-zeroes/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 借第一行和第一列做标记，最后再处理它们自身。

### 拿到这道题的第一思路

1. 边发现0边整行整列清零，会让新写的0继续传播，误清整个矩阵。必须先标记，再修改。
2. 先用两个布尔值记下原第一行、第一列是否含0；内部遇0时把对应行头、列头置0。
3. 按行头列头处理内部区域，最后依据两个布尔值处理第一行和第一列。

### 关键变量与始终保持的规则

firstRow、firstCol保存原边界状态；matrix[i][0]、matrix[0][j]是内部区域的置零标记。

### 实例走过程

```text
matrix=[[1,1,1],[1,0,1],[1,1,1]]
原首行首列均无0
内部[1,1]为0：标记[1,0]和[0,1]
内部按标记置零→[[1,0,1],[0,0,0],[1,0,1]]
首行首列原先无0，不整行整列清空。
```

### Java代码

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        // 结果直接写回matrix，先标记原有的0，再统一清零
        int m = matrix.length;
        int n = matrix[0].length;
        boolean firstRow = false;
        boolean firstCol = false;
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) {
                firstRow = true;
            }
        }
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) {
                firstCol = true;
            }
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) { // 标记阶段只写第一行、第一列
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        if (firstRow) {
            for (int j = 0; j < n; j++) {
                matrix[0][j] = 0;
            }
        }
        if (firstCol) {
            for (int i = 0; i < m; i++) {
                matrix[i][0] = 0;
            }
        }
    }
}
```

### 易错点

保存首行首列原状态必须在写入标记之前；内部遍历都从1开始；不要让matrix[0][0]同时承担两个未经区分的标记。

### 复杂度

时间O(mn)，额外空间O(1)。

### 方法对比

初次理解可用row[m]和col[n]两个标记数组，O(m+n)额外空间；主解只是把标记借放到矩阵边界，并用两个布尔值保留边界原状态。

## 19. 54. 螺旋矩阵（矩阵）

[力扣题目](https://leetcode.cn/problems/spiral-matrix/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0054-spiral-matrix/)

沿用总笔记中本题的主解。

### 一句话总结

> 按上、右、下、左读一圈，每读完一条边就收缩对应边界。

### 拿到这道题的第一思路

1. 沿用数组章节的四边界主解，先固定尚未访问区域[top,bottom]×[left,right]。
2. 读上边后top++，读右边后right--；接着读下边前检查是否还有行，读左边前检查是否还有列。
3. 每个角点在前一条边读过后就被边界收缩排除，剩余单行或单列不会重复访问。

### 关键变量与始终保持的规则

top、bottom、left、right都是闭区间边界；res依次保存已经访问的元素。

### 实例走过程

```text
matrix=[[1,2,3],[4,5,6],[7,8,9]]
上边1,2,3，top=1；右边6,9，right=1
下边8,7，bottom=1；左边4，left=1
剩中心5，返回[1,2,3,6,9,8,7,4,5]。
```

### Java代码

```java
import java.util.*;

class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> res = new ArrayList<>(); // 按螺旋访问顺序依次加入元素
        if (matrix.length == 0 || matrix[0].length == 0) {
            return res;
        }
        int top = 0;
        int bottom = matrix.length - 1;
        int left = 0;
        int right = matrix[0].length - 1;
        while (top <= bottom && left <= right) {
            for (int col = left; col <= right; col++) {
                res.add(matrix[top][col]);
            }
            top++;
            for (int row = top; row <= bottom; row++) {
                res.add(matrix[row][right]);
            }
            right--;
            if (top <= bottom) { // 仍有未读行，才走下边
                for (int col = right; col >= left; col--) {
                    res.add(matrix[bottom][col]);
                }
                bottom--;
            }
            if (left <= right) { // 仍有未读列，才走左边
                for (int row = bottom; row >= top; row--) {
                    res.add(matrix[row][left]);
                }
                left++;
            }
        }
        return res;
    }
}
```

### 易错点

读下边和左边之前需要重新检查边界，尤其是1×n、m×1矩阵；矩阵不一定是正方形。

### 复杂度

时间O(mn)，额外空间O(1)，另计O(mn)结果列表。

## 20. 48. 旋转图像（矩阵）

[力扣题目](https://leetcode.cn/problems/rotate-image/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0048-rotate-image/)

学习扩展：总笔记未检出本题完整题解，按已有章节的方法组织新解法。

### 一句话总结

> 先沿主对角线转置，再左右反转每一行。

### 拿到这道题的第一思路

1. 先写清目标坐标：顺时针90°是(i,j)→(j,n-1-i)。
2. 分两步更容易原地做：转置(i,j)→(j,i)，再逐行左右反转(j,i)→(j,n-1-i)。
3. 转置只处理主对角线上方，避免同一对元素交换两遍；每行再用相向指针交换。

### 关键变量与始终保持的规则

i、j是转置位置且j>i；row是待反转行；left、right围住本行尚未反转部分。

### 实例走过程

```text
matrix=[[1,2,3],[4,5,6],[7,8,9]]
转置→[[1,4,7],[2,5,8],[3,6,9]]
逐行反转→[[7,4,1],[8,5,2],[9,6,3]]
即顺时针90°，原矩阵中完成。
```

### Java代码

```java
class Solution {
    public void rotate(int[][] matrix) {
        // 结果直接写回matrix：先转置，再左右反转每一行
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) { // 每对对称位置只交换一次
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }
        // 转置完成后，逐行交换左右两端
        for (int row = 0; row < n; row++) {
            int left = 0;
            int right = n - 1;
            while (left < right) {
                int temp = matrix[row][left];
                matrix[row][left] = matrix[row][right];
                matrix[row][right] = temp;
                left++;
                right--;
            }
        }
    }
}
```

### 易错点

转置时j从i+1开始；逐行左右反转对应顺时针，转置后上下翻转会成为逆时针。题目保证n×n方阵。

### 复杂度

时间O(n²)，额外空间O(1)。
