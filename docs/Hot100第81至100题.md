## 81. 70. 爬楼梯（动态规划）

[力扣题目](https://leetcode.cn/problems/climbing-stairs/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0070-climbing-stairs/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnxrshenAcK1oHWW7oJCuOpg)

### 一句话总结

按最后一步爬1阶还是2阶，把方案分成两类。

### 拿到这道题的第一思路

拿到这道题的第一思路：先站在第 n 阶往回看。最后一步只能从 n-1 或 n-2 来；把这两处已有的方案数相加。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[i] 表示恰好到达第 i 阶的不同走法数。
2. 确定递推公式：dp[i]=dp[i-1]+dp[i-2]。最后一步不同，两类走法不会重复。
3. dp数组如何初始化：dp[0]=1 表示不走也是一种起始方案；dp[1]=1。力扣本题 n>=1。
4. 确定遍历顺序：i 从2到 n；两项都取更小台阶的结果。
5. 举例推导dp数组：第3阶：2+1=3；第4阶：3+2=5；例如1+1+2与2+1+1是不同走法。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text
n=4
dp=[1,1,0,0,0]
第2阶：1+1=2
第3阶：2+1=3
第4阶：3+2=5
例如1+1+2与2+1+1是不同走法。
```

### Java代码

```java
class Solution {
    public int climbStairs(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}

```

### 易错点

这是有顺序的走法数。进阶版若允许1到m阶，内层枚举最后一步 step=1..m；仍然先枚举目标阶数，不能把它当无序硬币组合。

### 复杂度

O(n) 时间，O(n) 辅助空间。

## 82. 118. 杨辉三角（动态规划）

[力扣题目](https://leetcode.cn/problems/pascals-triangle/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0118-pascals-triangle/) · [代码随想录](https://programmercarl.com/hot100/0118.pascals-triangle.html)

### 一句话总结

从上到下构造每一行，两端放 1，中间加上一行相邻的两个数。

### 拿到这道题的第一思路

第 81 题用前两个状态求一个新状态。这一题也看已经算好的值，只是两个来源都在上一行。

### 关键变量与始终保持的规则

result 保存已完成的行，row 保存当前正在填的第 i 行。第 i 行下标是 0 到 i，中间的第 j 项取上一行的第 j-1 项和第 j 项之和。

### 实例走过程

numRows = 5。前两行是 [1]、[1,1]。第三行中间是 1+1=2，得到 [1,2,1]。第四行是 [1,3,3,1]，第五行的三个中间值是 1+3、3+3、3+1，得到 [1,4,6,4,1]。

### Java代码

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < numRows; i++) {
            List<Integer> row = new ArrayList<>();
            for (int j = 0; j <= i; j++) {
                if (j == 0 || j == i) {
                    row.add(1);
                } else {
                    row.add(result.get(i - 1).get(j - 1) + result.get(i - 1).get(j));
                }
            }
            result.add(row);
        }
        return result;
    }
}
```

### 易错点

两端直接填 1。只有处理中间位置才读上一行，每轮都新建一个 row。

### 复杂度

时间 O(numRows²)。结果占 O(numRows²)，除结果外额外空间 O(1)。

## 83. 198. 打家劫舍（动态规划）

[力扣题目](https://leetcode.cn/problems/house-robber/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0198-house-robber/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcn3kPYpSIbloxkBeEddyrIqe)

### 一句话总结

到每间房时，在“不偷它”与“偷它并跳过前一间”之间选更大值。

### 拿到这道题的第一思路

拿到这道题的第一思路：单独看金额最大的一间可能挡住两边更好的组合。按前缀记录最优结果；当前房是否偷，只影响能否连接前一间。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[i] 表示只考虑前 i 间房，能够取得的最大金额。nums 的当前下标是 i-1。
2. 确定递推公式：dp[i]=max(dp[i-1],dp[i-2]+nums[i-1])。
3. dp数组如何初始化：dp[0]=0，dp[1]=nums[0]；空数组防御性返回0。
4. 确定遍历顺序：i 从2到 n，先完成更短前缀，再处理当前房。
5. 举例推导dp数组：i=3：max(7,2+9)=11；i=4：max(11,7+3)=11；i=5：max(11,11+1)=12，偷2、9、1。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text
nums=[2,7,9,3,1]
dp[0]=0，dp[1]=2
i=2：max(2,0+7)=7
i=3：max(7,2+9)=11
i=4：max(11,7+3)=11
i=5：max(11,11+1)=12，偷2、9、1。
```

### Java代码

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
        int[] dp = new int[n + 1];
        dp[1] = nums[0];
        for (int i = 2; i <= n; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i - 1]);
        }
        return dp[n];
    }
}

```

### 易错点

dp[i] 并不表示一定偷第 i 间，而是前 i 间的最好结果；若写成“必须偷”就需要不同递推。

### 复杂度

O(n) 时间，O(n) 辅助空间。

## 84. 279. 完全平方数（动态规划）

[力扣题目](https://leetcode.cn/problems/perfect-squares/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0279-perfect-squares/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnp3S75CVoVCZBEPNa15Ekfb)

### 一句话总结

把平方数当作可重复使用的硬币，求最少数量。

### 拿到这道题的第一思路

拿到这道题的第一思路：与322一样是在凑一个总量，只是可选值变成1、4、9……。不能只选最大的平方数，12取9会比取三个4更差。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[i] 表示总和恰为 i 时最少需要几个完全平方数。
2. 确定递推公式：对每个 j*j<=i，dp[i]=min(dp[i],dp[i-j*j]+1)。
3. dp数组如何初始化：dp[0]=0；每个正数状态先设为 i，表示全用1。
4. 确定遍历顺序：外层总和 i 递增，内层枚举平方根 j。
5. 举例推导dp数组：最后取4来自dp[8]+1=3；最后取9来自dp[3]+1=4；取最小3，即4+4+4。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text
n=12
dp[4]=1，dp[8]=2，dp[9]=1
i=12：最后取1来自dp[11]+1=4
最后取4来自dp[8]+1=3
最后取9来自dp[3]+1=4
取最小3，即4+4+4。
```

### Java代码

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = i;
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}

```

### 易错点

枚举的是正平方数，不能包含0，否则状态依赖自己且没有推进。

### 复杂度

O(n√n) 时间，O(n) 辅助空间。

## 85. 322. 零钱兑换（动态规划）

[力扣题目](https://leetcode.cn/problems/coin-change/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0322-coin-change/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnWteUEknV273PQZ705BOxsg)

### 一句话总结

每个金额尝试最后放一枚硬币，取所需枚数最少的来源。

### 拿到这道题的第一思路

拿到这道题的第一思路：一直拿最大硬币可能错，例如[1,3,4]凑6。记录每个小金额的最少枚数，再尝试最后加哪枚硬币。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[i] 表示凑成金额 i 的最少硬币数；amount+1 表示当前不可达。
2. 确定递推公式：若 coin<=i，dp[i]=min(dp[i],dp[i-coin]+1)。
3. dp数组如何初始化：dp[0]=0，其余为 amount+1；硬币面额为正，任何可行最优解最多 amount 枚。
4. 确定遍历顺序：外层金额从1到 amount，内层硬币；来源金额更小且允许重复用币。
5. 举例推导dp数组：dp[6..10]=[2,2,3,3,2]；金额11：从10加1需3枚，从9加2需4枚，从6加5需3枚；返回3，对应5+5+1。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text
coins=[1,2,5]，amount=11
dp[1..5]=[1,1,2,2,1]
dp[6..10]=[2,2,3,3,2]
金额11：从10加1需3枚，从9加2需4枚，从6加5需3枚
返回3，对应5+5+1。
```

### Java代码

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        for (int i = 1; i <= amount; i++) dp[i] = amount + 1;
        for (int i = 1; i <= amount; i++) {
            for (int coin : coins) {
                if (coin <= i) dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}

```

### 易错点

计数问题用加法，这题求最少用 min。不可达不能初始化为0；最终仍大于 amount 就返回-1。

### 复杂度

O(K*amount) 时间，O(amount) 辅助空间。

## 86. 139. 单词拆分（动态规划）

[力扣题目](https://leetcode.cn/problems/word-break/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0139-word-break/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcndGOuknI7gCwbMbf5HR1mhe)

### 一句话总结

检查每个前缀，能否从一个已可拆分的前缀再接一个单词。

### 拿到这道题的第一思路

拿到这道题的第一思路：先找第一个单词也可以搜索，但不同分割会反复到达同一位置。只记录字符串前 i 个字符能否拆分，最后一个单词来自字典。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[i] 表示 s 的前 i 个字符 s[0,i) 可以由字典单词拼出。
2. 确定递推公式：若 dp[i-len] 为 true，且 word 匹配 s 中从 i-len 开始的一段，则 dp[i]=true。
3. dp数组如何初始化：dp[0]=true，空前缀可以作为首个单词之前的起点。
4. 确定遍历顺序：外层前缀长度 i=1..s.length；内层枚举最后一个 word，找到可行来源即可 break。
5. 举例推导dp数组：i=4：前缀"leet"匹配，dp[0]可行，因此dp[4]=true；i=8：最后单词"code"匹配，dp[4]可行，因此dp[8]=true；返回true；字典单词允许重复使用。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text
s="leetcode"，wordDict=["leet","code"]
dp[0]=true
i=4：前缀"leet"匹配，dp[0]可行，因此dp[4]=true
i=8：最后单词"code"匹配，dp[4]可行，因此dp[8]=true
返回true；字典单词允许重复使用。
```

### Java代码

```java
import java.util.List;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;
        for (int i = 1; i <= s.length(); i++) {
            for (String word : wordDict) {
                int len = word.length();
                if (i >= len && dp[i - len] && s.startsWith(word, i - len)) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}

```

### 易错点

字典中有某个后缀还不够，它前面的前缀也必须可拆。用 startsWith(word,start) 对照原串，避免反复创建子串。

### 复杂度

O(N*K*L) 时间上界，O(N) 辅助空间；N为字符串长度，K为单词数，L为最长单词长度。

## 87. 300. 最长递增子序列（动态规划）

[力扣题目](https://leetcode.cn/problems/longest-increasing-subsequence/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0300-longest-increasing-subsequence/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnGif8TJrCrAf5EdGBlULLdh)

### 一句话总结

固定子序列的最后一个位置，再找前面比它小的结尾接上。

### 拿到这道题的第一思路

拿到这道题的第一思路：可以跳过元素，但必须保持原顺序。若答案以 nums[i] 结束，它的前一个选中值必须在前面并且更小；逐个试这些前驱。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[i] 表示以 nums[i] 结尾的最长严格递增子序列长度，必须选 nums[i]。
2. 确定递推公式：枚举 j<i，若 nums[j]<nums[i]，则 dp[i]=max(dp[i],dp[j]+1)。
3. dp数组如何初始化：每个 dp[i] 初始为1，单个元素本身就是合法子序列；result记录所有结尾的最大值。
4. 确定遍历顺序：i 从左到右，j 扫描 i 之前所有位置；不能只比较相邻位置。
5. 举例推导dp数组：处理7时能接到2、5、3后面，最好长度3；处理18时接7，得到长度4；例如[2,3,7,18]，返回4。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text
nums=[10,9,2,5,3,7,101,18]
各结尾dp=[1,1,1,2,2,3,4,4]
处理7时能接到2、5、3后面，最好长度3
处理18时接7，得到长度4
例如[2,3,7,18]，返回4。
```

### Java代码

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] dp = new int[nums.length];
        int result = 0;
        for (int i = 0; i < nums.length; i++) {
            dp[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
            }
            result = Math.max(result, dp[i]);
        }
        return result;
    }
}

```

### 易错点

严格递增使用<，不能使用<=。答案是整个dp的最大值，不一定是 dp[n-1]，例如[1,2,3,0]。

### 复杂度

O(n²) 时间，O(n) 辅助空间。

## 88. 152. 乘积最大子数组（动态规划）

[力扣题目](https://leetcode.cn/problems/maximum-product-subarray/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0152-maximum-product-subarray/) · [代码随想录](https://programmercarl.com/hot100/0152.maximum-product-subarray.html)

### 一句话总结

同一位置同时记最大和最小结尾乘积，遇到负数时，过去最小的可能变成最大的。

### 拿到这道题的第一思路

像第 87 题一样先固定结尾。子数组要连续，因此每一步只能从当前数重新开始，或把它接到上一个位置结尾的子数组后面。

### 关键变量与始终保持的规则

maxEnding 和 minEnding 分别表示以当前位置结尾的最大、最小乘积。每次在当前数、旧最大值乘当前数、旧最小值乘当前数中取最大和最小。result 记录所有结尾里的最大值。

### 实例走过程

nums = [-2,3,-4]。开始最大和最小结尾乘积都是 -2。读到 3 后，最大为 3，最小为 -6。读到 -4 时，旧最小值 -6 乘 -4 得到 24，成为新的最大值。

### Java代码

```java
class Solution {
    public int maxProduct(int[] nums) {
        int maxEnding = nums[0];
        int minEnding = nums[0];
        int result = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int previousMax = maxEnding;
            maxEnding = Math.max(nums[i], Math.max(previousMax * nums[i], minEnding * nums[i]));
            minEnding = Math.min(nums[i], Math.min(previousMax * nums[i], minEnding * nums[i]));
            result = Math.max(result, maxEnding);
        }
        return result;
    }
}
```

### 易错点

更新最小值还要用旧的最大值，所以先用 previousMax 保存它。遇到 0 时两个结尾乘积都会变成 0，下一项仍可重新开始。

### 复杂度

时间 O(n)，辅助空间 O(1)。

## 89. 416. 分割等和子集（动态规划）

[力扣题目](https://leetcode.cn/problems/partition-equal-subset-sum/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0416-partition-equal-subset-sum/) · [算法学习总笔记原解](https://acn581cm6pdd.feishu.cn/wiki/DDeAw4NaKigky8kz1RUcYEOIndf#doxcnCcu3zLEdqDQAf9nuncBAoh)

### 一句话总结

每个数只能用一次，检查能否恰好凑出总和的一半。

### 拿到这道题的第一思路

拿到这道题的第一思路：两组相等就各占总和一半。总和为奇数直接失败；接下来把每个数看成只能选一次的物品。

### 关键变量与始终保持的规则

1. 确定dp数组以及下标的含义：dp[j] 表示已处理的数能否组成恰好为 j 的子集。
2. 确定递推公式：不选当前 num 时保留旧 dp[j]；选它时看旧 dp[j-num]，所以 dp[j] |= dp[j-num]。
3. dp数组如何初始化：dp[0]=true，空子集能凑0，其余为 false。target=sum/2。
4. 确定遍历顺序：外层枚举数，内层 j 从 target 倒序到 num，保证来源仍属于上一轮。
5. 举例推导dp数组：处理5后{0,1,5,6}；处理11后出现11，说明一组可取[11]；另一组[1,5,5]同样为11。完整逐步过程见紧随其后的“实例走过程”。

### 实例走过程

```text

初始可达{0}
处理1后{0,1}
处理5后{0,1,5,6}
处理11后出现11，说明一组可取[11]
另一组[1,5,5]同样为11。
```

### Java代码

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) sum += num;
        if (sum % 2 != 0) return false;
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num]; // 倒序：当前数最多选一次
            }
        }
        return dp[target];
    }
}

```

### 易错点

容量正序会让同一个数在一轮内重复使用；这里要求恰好等于 target，不能只返回最接近的和。

### 复杂度

O(n*target) 时间，O(target) 辅助空间。

## 90. 32. 最长有效括号（动态规划）

[力扣题目](https://leetcode.cn/problems/longest-valid-parentheses/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0032-longest-valid-parentheses/) · [代码随想录](https://programmercarl.com/hot100/0032.longest-valid-parentheses.html)

### 一句话总结

用栈找出有效后缀左边的边界，当前右括号下标减去这个边界就是长度。

### 拿到这道题的第一思路

第 20 题用栈配对括号。本题还要算连续长度，因此栈里存下标，底部保留最近一个无法配对的右括号下标。

### 关键变量与始终保持的规则

初始用 -1 表示串左边的边界。左括号下标入栈，右括号先弹栈。弹完为空时，当前右括号成为新边界。否则新栈顶在当前有效后缀的左边，用 i - stack.peek() 算长度。

### 实例走过程

s = ")()())"。下标 0 的右括号把边界改成 0。下标 2 配对后得到 2-0=2，下标 4 配对后得到 4-0=4。最后一个右括号无法配对，更新边界但最长长度仍是 4。

### Java代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);
        int result = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    result = Math.max(result, i - stack.peek());
                }
            }
        }
        return result;
    }
}
```

### 易错点

初始边界 -1 不能省。栈空要先记录新边界，后面的有效段才不会跨过多余的右括号。

### 复杂度

时间 O(n)，辅助空间 O(n)。

class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];

沿用上一题的上方、左方两个来源。不同路径求方案数，所以相加。这一题求最小代价，所以先选更便宜的来源。

### 关键变量与始终保持的规则

把累计最小路径和写回 grid。处理过的格子存的是从起点到它的最小路径和。首行只能从左边来，首列只能从上面来。

### 实例走过程

grid = [[1,3,1],[1,5,1],[4,2,1]]。第一行累计为 [1,4,5]，第一列累计为 [1,2,6]。中间格取 min(4,2)+5=7，右边一格取 min(5,7)+1=6，右下角取 min(6,8)+1=7。

### Java代码

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        for (int j = 1; j < n; j++) {
            grid[0][j] += grid[0][j - 1];
        }
        for (int i = 1; i < m; i++) {
            grid[i][0] += grid[i - 1][0];
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                grid[i][j] += Math.min(grid[i - 1][j], grid[i][j - 1]);
            }
        }
        return grid[m - 1][n - 1];
    }
}
```

## 93. 5. 最长回文子串（多维动态规划）

[力扣题目](https://leetcode.cn/problems/longest-palindromic-substring/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0005-longest-palindromic-substring/) · [代码随想录](https://programmercarl.com/hot100/0005.longest-palindromic-substring.html)

### 一句话总结

枚举回文的中心，左右相等就一起向外扩，记录最长的一段。

### 拿到这道题的第一思路

第 61 题会从两端向内验证一个区间。这题从中心向外扩张，验证成功的短回文可以直接继续试更长的区间。

### 关键变量与始终保持的规则

expand 返回两个指针失配或越界前得到的回文长度 right-left-1。每个 i 都尝试 (i,i) 和 (i,i+1)，分别处理奇数和偶数长度。取得更长回文时，再更新 start 和 bestLength。

### 实例走过程

s = "cbbd"。下标 1、2 的两个 b 相等，从这条缝向两侧扩张得到 bb。再比较 c 和 d 时停止，长度是 2，起点为 1，返回 "bb"。

### Java代码

```java
class Solution {
    public String longestPalindrome(String s) {
        int start = 0;
        int bestLength = 0;
        for (int i = 0; i < s.length(); i++) {
            int length = Math.max(expand(s, i, i), expand(s, i, i + 1));
            if (length > bestLength) {
                start = i - (length - 1) / 2;
                bestLength = length;
            }
        }
        return s.substring(start, start + bestLength);
    }

    private int expand(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

### 易错点

扩张退出时，两边指针都已在有效区间之外。奇数回文的中心是 i，偶数回文把 i 当成中间两个字符的左边那个。两种情况的起点都能用 i - (length - 1) / 2 算出。

### 复杂度

最坏时间 O(n²)，辅助空间 O(1)，返回的子串空间另计。

[力扣题目](https://leetcode.cn/problems/sort-colors/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0075-sort-colors/) · [代码随想录](https://programmercarl.com/hot100/0075.sort-colors.html)

### 一句话总结

扫描时把 0 推到左边，把 2 推到右边，1 留在中间。

### 拿到这道题的第一思路

颜色只有三种。把数组分成已归位的 0、已扫过的 1、未判断区间、已归位的 2 四段，一次扫描就能处理。

### 关键变量与始终保持的规则

left 是下一个 0 的位置，right 是下一个 2 的位置，i 是正检查的位置。i 左边已经处理过，[i,right] 还没有检查。

### 实例走过程

nums = [2,0,2,1,1,0]。先将开头的 2 和末尾的 0 交换，得到 [0,0,2,1,1,2]。i 暂留在下标 0 检查换来的 0。下标 2 的 2 再与右边的 1 交换，得到 [0,0,1,1,2,2]。

### Java代码

```java
class Solution {
    public void sortColors(int[] nums) {
        int left = 0;
        int right = nums.length - 1;
        int i = 0;

        while (i <= right) {
            if (nums[i] == 0) {
                swap(nums, i, left);
                left++;
                i++;
            } else if (nums[i] == 2) {
                swap(nums, i, right);
                right--;
            } else {
                i++;
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### 易错点

遇到 2 交换后只移动 right。换到 i 的元素原本在未处理区间，还要再检查一次。遇到 0 或 1 时才推进 i。

### 复杂度

## 99. 31. 下一个排列（技巧）

[力扣题目](https://leetcode.cn/problems/next-permutation/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0031-next-permutation/) · [代码随想录](https://programmercarl.com/hot100/0031.next-permutation.html)

### 一句话总结

尽量晚地把一个数抬高一点，再把它后面的数排成最小顺序。

### 拿到这道题的第一思路

从右侧开始看。已经从大到小的后缀是这组数字能排出的最大顺序。需要改动它左边的第一个拐点，才有更大的排列。

### 关键变量与始终保持的规则

pivot 是最右侧满足 nums[pivot] < nums[pivot+1] 的下标。在右边从末尾找第一个严格大于它的数，交换后再反转整个非递增后缀。

### 实例走过程

nums = [1,3,5,4,2]。右侧 [5,4,2] 已经非递增，拐点是 3。从右往左，第一个比 3 大的是 4。交换成 [1,4,5,3,2]，再反转 [5,3,2]，得到 [1,4,2,3,5]。

### Java代码

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int pivot = nums.length - 2;
        while (pivot >= 0 && nums[pivot] >= nums[pivot + 1]) {
            pivot--;
        }

        if (pivot >= 0) {
            int next = nums.length - 1;
            while (nums[next] <= nums[pivot]) {
                next--;
            }
            swap(nums, pivot, next);
        }

        for (int left = pivot + 1, right = nums.length - 1; left < right; left++, right--) {
            swap(nums, left, right);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### 易错点

拐点和替换值都要用严格比较。找不到拐点时，整个数组已是最大排列，直接反转成最小排列。

### 复杂度

时间 O(n)，辅助空间 O(1)。

## 100. 287. 寻找重复数（技巧）

[力扣题目](https://leetcode.cn/problems/find-the-duplicate-number/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0287-find-the-duplicate-number/) · [代码随想录](https://programmercarl.com/hot100/0287.find-the-duplicate-number.html)

### 一句话总结

把 nums[i] 看成从下标 i 跳向的下一站，用快慢指针找到环入口。

### 拿到这道题的第一思路

复用第 26 题「环形链表 II」的思路。数组值都能当作下标，从 0 不停跳一定会进环。环入口同时被入环前的下标和环中的下标指向，这两个下标存着同一个值。

### 关键变量与始终保持的规则

第一阶段 slow 每次跳一步，fast 每次跳两步。相遇后把 slow 放回 0，两个指针都改成一步。起点到入口的距离，和相遇点顺着环走到入口的距离相差整圈。再次相遇时就是入口。

### 实例走过程

nums = [1,3,4,2,2]。从 0 按值走到 1、3、2、4，再回到 2。两个指针第一次在 4 相遇。slow 回到 0 后同步走，分别经过 (1,2)、(3,4)、(2,2)，返回 2。

### Java代码

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = 0;
        int fast = 0;
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        slow = 0;
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;
    }
}
```

### 易错点

fast 的两步写成 nums[nums[fast]]。第一阶段先移动再判断，否则两个初值都是 0，会直接结束。

### 复杂度

时间 O(n)，辅助空间 O(1)。
