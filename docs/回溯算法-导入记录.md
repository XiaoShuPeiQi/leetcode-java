# 回溯算法：导入与 Debug 记录

来源：[飞书回溯算法笔记](https://acn581cm6pdd.feishu.cn/docx/VSYBdzUkuoIxf3xuSfVcsgKkn3g)，快照 revision 90，日期 2026-10-08。完整讲解保存在 [回溯算法原文](回溯算法.md)。

15 份原始 Solution 仅增加 static 修饰与一层缩进，其方法、变量、注释和算法逻辑逐一核对一致。Java 17 编译 17 份源码成功，15 个 main 均运行通过；[完整运行记录](../imports/回溯算法.validation.txt) 保留每题的实际输入、expected、actual 和退出码。

下方 Java 片段是各 main 中的固定输入与 expected，在运行前按原文示例和题意确定，不从算法输出反推。原文只展示部分分支而未逐项列出答案时，本地补齐同一输入的完整预期结果。

在递归方法的第一条语句、选择、递归调用和撤销处打断点，点击 main 上方 Debug。F11 进入，F10 执行当前行，Shift+F11 返回，F5 继续。局部变量只在对应作用域内可见；切换调用堆栈可查看各层参数。VS Code 图形界面未实际操作验证。

全部题目统一使用“变量”面板自动显示当前作用域内的所有变量，无需把下面各题的变量名逐个添加到“监视”。项目已开启代码行内变量值、集合逻辑结构和 toString 内容显示；数组、列表、棋盘及对象字段可展开查看。下方“Debug 变量”是学习对照清单，变量在声明执行后、相应方法或循环作用域内才可见。

## LC0332

**332. 重新安排行程**：[Java 文件](../src/main/java/leetcode/backtracking/LC0332ReconstructItinerary.java)，飞书原文小节 3.13。
