## 21. 240. 搜索二维矩阵 II（矩阵）

[力扣题目](https://leetcode.cn/problems/search-a-2d-matrix-ii/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0240-search-a-2d-matrix-ii/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 从右上角出发，每次排除一整行或一整列。

### 拿到这道题的第一思路

**数据结构。** 二维数组存有序矩阵，行列位置指向剩余区域的右上角。

**怎么想。** 这里是剩余行的最大值、剩余列的最小值。太小就排除这一行，太大就排除这一列。

**文字推演。** 目标 5，从右上角的 15 依次左移到 11、7、4。4 偏小，向下一行到 5，找到目标。

### 关键变量与始终保持的规则

目标若存在，始终在当前行及其下方、当前列及其左方。

### 实例走过程

```text
matrix=[[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target=5
目标 5，从右上角的 15 依次左移到 11、7、4。4 偏小，向下一行到 5，找到目标。
结果 true
```

### Java代码

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int row = 0;
        int col = matrix[0].length - 1;
        while (row < matrix.length && col >= 0) {
            int value = matrix[row][col];
            if (value == target) {
                return true;
            }
            if (value > target) {
                col--; // 当前列剩下的数都更大
            } else {
                row++; // 当前行剩下的数都更小
            }
        }
        return false;
    }
}
```

### 易错点

从右上角或左下角出发，才能根据一次比较确定排除方向。

### 复杂度

时间 O(m+n)，额外空间 O(1)。

## 22. 160. 相交链表（链表）

[力扣题目](https://leetcode.cn/problems/intersection-of-two-linked-lists/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0160-intersection-of-two-linked-lists/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 先对齐两条链的剩余长度，再同步找同一个节点。

### 拿到这道题的第一思路

**数据结构。** 两条单链表靠 next 连接，两个引用分别沿各自的链走。

**怎么想。** 相交后会共享整段后缀。让较长的链先走长度差，两边到链尾的距离就相同，可以同步比较。

**文字推演。** A 的独有段是 4、1，B 的独有段是 5、6、1。B 先走一格，再同步前进两步，第一次指向同一个节点 8。

### 关键变量与始终保持的规则

比较的是节点对象身份。两条链都走到空也会相等，此时返回空。

### 实例走过程

```text
A=[4,1,8,4,5]，B=[5,6,1,8,4,5]，从节点 8 起共享同一批节点
A 的独有段是 4、1，B 的独有段是 5、6、1。B 先走一格，再同步前进两步，第一次指向同一个节点 8。
结果 8
```

### Java代码

```java
class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        int lenA = getLength(headA);
        int lenB = getLength(headB);
        ListNode curA = headA;
        ListNode curB = headB;
        while (lenA > lenB) {
            curA = curA.next;
            lenA--;
        }
        while (lenB > lenA) {
            curB = curB.next;
            lenB--;
        }
        while (curA != curB) {
            curA = curA.next;
            curB = curB.next;
        }
        return curA;
    }

    private int getLength(ListNode head) {
        int length = 0;
        while (head != null) {
            length++;
            head = head.next;
        }
        return length;
    }
}
```

### 易错点

两个值为 1 的节点可能是不同对象，不能用节点值判相交。

### 复杂度

时间 O(m+n)，额外空间 O(1)。

## 23. 206. 反转链表（链表）

[力扣题目](https://leetcode.cn/problems/reverse-linked-list/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0206-reverse-linked-list/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 逐个把当前节点的 next 转向已经翻好的前段。

### 拿到这道题的第一思路

**数据结构。** 单链表。前驱引用指向已翻转部分，当前引用指向待处理部分。

**怎么想。** 每次先保存后继，再把当前节点接到反转段前面。这样既完成一条反向连接，也找得回剩下的链。

**文字推演。** 1、2、3 依次接到反转段前面。先得到 1，再得到 2、1，最后得到 3、2、1。

### 关键变量与始终保持的规则

每一轮开始时，prev 是已翻转段的头，cur 是未处理段的头。

### 实例走过程

```text
head=[1,2,3]
1、2、3 依次接到反转段前面。先得到 1，再得到 2、1，最后得到 3、2、1。
结果 [3, 2, 1]
```

### Java代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next; // 改线前保存原后继
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
```

### 易错点

先保存原 next 再改线。结束时返回 prev。

### 复杂度

时间 O(n)，额外空间 O(1)。

## 24. 234. 回文链表（链表）

[力扣题目](https://leetcode.cn/problems/palindrome-linked-list/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0234-palindrome-linked-list/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 翻转后半段，把首尾对照变成两条链同时向前比较。

### 拿到这道题的第一思路

**数据结构。** 单链表加快慢指针。前后两半用节点引用表示，比较完恢复后半段。

**怎么想。** 快指针走两格、慢指针走一格。找到前半段尾后，反转后半段，让原来的最后一个数先出来和第一个数比。

**文字推演。** 1、2、2、1 分成两半，后半段 2、1 翻成 1、2。逐项都相等，得到 true，再把后半段接回原样。

### 关键变量与始终保持的规则

只比较后半段的长度。奇数长度时，中间节点留在前半段。

### 实例走过程

```text
head=[1,2,2,1]
1、2、2、1 分成两半，后半段 2、1 翻成 1、2。逐项都相等，得到 true，再把后半段接回原样。
结果 true
```

### Java代码

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        // slow 停在前半段末尾，奇数长度时停在中点
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode second = reverse(slow.next);
        ListNode left = head;
        ListNode right = second;
        boolean res = true;
        while (right != null) {
            if (left.val != right.val) {
                res = false;
                break;
            }
            left = left.next;
            right = right.next;
        }
        slow.next = reverse(second); // 比较完恢复输入链表
        return res;
    }

    private ListNode reverse(ListNode cur) {
        ListNode prev = null;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
```

### 易错点

遇到不同也要先记录结果，统一恢复链表后再返回。

### 复杂度

时间 O(n)，额外空间 O(1)。

## 25. 141. 环形链表（链表）

[力扣题目](https://leetcode.cn/problems/linked-list-cycle/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0141-linked-list-cycle/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 让快指针追慢指针，能追上就说明有环。

### 拿到这道题的第一思路

**数据结构。** 单链表，两个引用从头出发。

**怎么想。** 无环时快指针会先走到尾。有环时两者进环后，每轮快指针多走一格，在环上终会追到同一个节点。

**文字推演。** 链是 3、2、0、−4，尾接回 2。快慢指针在环内追赶，最终都到节点 −4，返回 true。

### 关键变量与始终保持的规则

走两步之前先检查快指针和它的下一节点都存在。

### 实例走过程

```text
head=[3,2,0,-4], pos=1（尾部-4.next指回节点2）
链是 3、2、0、−4，尾接回 2。快慢指针在环内追赶，最终都到节点 −4，返回 true。
结果 true
```

### Java代码

```java
class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                return true;
            }
        }
        return false;
    }
}
```

### 易错点

先移动，再比较身份。出发时两个引用相等不算相遇。

### 复杂度

时间 O(n)，额外空间 O(1)。

## 26. 142. 环形链表 II（链表）

[力扣题目](https://leetcode.cn/problems/linked-list-cycle-ii/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0142-linked-list-cycle-ii/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 快慢指针相遇后，让链头和相遇点各出发一个指针，同速走到入口。

### 拿到这道题的第一思路

**数据结构。** 单链表。第一阶段用快慢指针，第二阶段用两个等速引用。

**怎么想。** 相遇时，快指针路程是慢指针两倍，多走的路是整圈。于是相遇点沿环到入口的距离，与链头到入口的距离相差整圈。

**文字推演。** 3、2、0、−4 的尾连回 2。首次在 −4 相遇。此时从头 3 和 −4 各走一步，两边都到 2。

### 关键变量与始终保持的规则

第二阶段两指针每次各走一步，第一次同址就是入口。

### 实例走过程

```text
head=[3,2,0,-4], pos=1（尾部连回节点2）
3、2、0、−4 的尾连回 2。首次在 −4 相遇。此时从头 3 和 −4 各走一步，两边都到 2。
结果 2
```

### Java代码

```java
class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                ListNode index1 = head;
                ListNode index2 = slow;
                while (index1 != index2) {
                    index1 = index1.next;
                    index2 = index2.next;
                }
                return index1;
            }
        }
        return null;
    }
}
```

### 易错点

首次相遇点可能在环内任意位置，入口要等第二阶段确认。

### 复杂度

时间 O(n)，额外空间 O(1)。

## 27. 21. 合并两个有序链表（链表）

[力扣题目](https://leetcode.cn/problems/merge-two-sorted-lists/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0021-merge-two-sorted-lists/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 每次从两条有序链的头里挑较小的，接到结果尾。

### 拿到这道题的第一思路

**数据结构。** 两条单链表。虚拟头方便统一接线，尾引用负责追加节点。

**怎么想。** 每条链的最小剩余值都在头上，比较这两个头就够了。一条用完后，另一条剩余部分直接接上。

**文字推演。** 合并 1、2、4 和 1、3、4。先接两个 1，再接 2、3，最后接两个 4，得到 1、1、2、3、4、4。

### 关键变量与始终保持的规则

结果段一直有序，tail 指向刚接入的最后一个节点。

### 实例走过程

```text
list1=[1,2,4], list2=[1,3,4]
合并 1、2、4 和 1、3、4。先接两个 1，再接 2、3，最后接两个 4，得到 1、1、2、3、4、4。
结果 [1, 1, 2, 3, 4, 4]
```

### Java代码

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                tail.next = list1;
                list1 = list1.next;
            } else {
                tail.next = list2;
                list2 = list2.next;
            }
            tail = tail.next;
        }
        // 剩下的一段已经有序，可以直接接到结果末尾
        tail.next = list1 != null ? list1 : list2;
        return dummy.next;
    }
}
```

### 易错点

接上哪个节点，就推进哪条链的头。

### 复杂度

时间 O(m+n)，额外空间 O(1)。

## 28. 2. 两数相加（链表）

[力扣题目](https://leetcode.cn/problems/add-two-numbers/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0002-add-two-numbers/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 从个位开始逐位相加，把进位留给下一轮。

### 拿到这道题的第一思路

**数据结构。** 两条单链表按低位到高位存数字。结果用新链表保存，一个整数记进位。

**怎么想。** 每轮加两个当前位和旧进位。和的个位写入结果，十位带到下一位。某条链先结束时，该位按 0 算。

**文字推演。** 2、4、3 加 5、6、4。先得 7，再算 4+6 得 0 并进 1，最后 3+4+1 得 8，结果 7、0、8。

### 关键变量与始终保持的规则

只要还有数字或进位，就继续产生下一位。

### 实例走过程

```text
l1=[2,4,3], l2=[5,6,4]
2、4、3 加 5、6、4。先得 7，再算 4+6 得 0 并进 1，最后 3+4+1 得 8，结果 7、0、8。
结果 [7, 0, 8]
```

### Java代码

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        int carry = 0;
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            if (l1 != null) {
                sum += l1.val;
                l1 = l1.next;
            }
            if (l2 != null) {
                sum += l2.val;
                l2 = l2.next;
            }
            tail.next = new ListNode(sum % 10); // 当前位只保留个位
            tail = tail.next;
            carry = sum / 10; // 十位交给下一轮
        }
        return dummy.next;
    }
}
```

### 易错点

两个输入用完后仍可能剩一次进位。

### 复杂度

时间 O(max(m,n))，额外空间 O(1)，另有结果链表。

## 29. 19. 删除链表的倒数第 N 个结点（链表）

[力扣题目](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0019-remove-nth-node-from-end-of-list/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 用固定间距让慢指针恰好停在待删节点前面。

### 拿到这道题的第一思路

**数据结构。** 单链表加虚拟头和快慢指针。

**怎么想。** 从虚拟头让快指针先走 n+1 步，再一起走。快指针到空时，慢指针到待删节点的前一格，能直接改 next。

**文字推演。** 1、2、3、4、5 删除倒数第 2 个。快指针先到 3，再与慢指针一起走到空。慢指针停在 3，跨过 4 连接 5。

### 关键变量与始终保持的规则

同步前进时两者间距始终为 n+1 条边。

### 实例走过程

```text
head=[1,2,3,4,5], n=2
1、2、3、4、5 删除倒数第 2 个。快指针先到 3，再与慢指针一起走到空。慢指针停在 3，跨过 4 连接 5。
结果 [1, 2, 3, 5]
```

### Java代码

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode fast = dummy;
        ListNode slow = dummy;
        for (int i = 0; i <= n; i++) {
            fast = fast.next; // 先拉开n+1条边
        }
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

### 易错点

要找到的是待删节点的前驱。虚拟头也能统一处理删头。

### 复杂度

时间 O(n)，额外空间 O(1)。

## 30. 24. 两两交换链表中的节点（链表）

[力扣题目](https://leetcode.cn/problems/swap-nodes-in-pairs/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0024-swap-nodes-in-pairs/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 把相邻两个节点当一组，交换它们并接回前后。

### 拿到这道题的第一思路

**数据结构。** 单链表加虚拟头。pre 指向已经处理部分的尾节点。

**怎么想。** 先记一组的两个节点。前段改接第二个，第一个改接后缀，第二个再接第一个。

**文字推演。** 1、2、3、4、5 先把 1 和 2 换成 2、1，再把 3 和 4 换成 4、3。单独的 5 留在末尾。

### 关键变量与始终保持的规则

每轮完成后，原来的第一个成为组尾，pre 跟到那里。

### 实例走过程

```text
head=[1,2,3,4,5]，pre=dummy
1、2、3、4、5 先把 1 和 2 换成 2、1，再把 3 和 4 换成 4、3。单独的 5 留在末尾。
结果 [2, 1, 4, 3, 5]
```

### Java代码

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        ListNode pre = dummy;
        while (pre.next != null && pre.next.next != null) {
            ListNode first = pre.next;
            ListNode second = first.next;
            pre.next = second;
            first.next = second.next; // 在second改线前保住后缀
            second.next = first;
            pre = first; // 原first变为已交换部分的末尾
        }
        return dummy.next;
    }
}
```

### 易错点

第一个节点先接到后缀，再改第二个节点的 next，避免丢后缀。

### 复杂度

时间 O(n)，额外空间 O(1)。

## 31. 25. K 个一组翻转链表（链表）

[力扣题目](https://leetcode.cn/problems/reverse-nodes-in-k-group/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0025-reverse-nodes-in-k-group/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 先确认够一组，再原地翻转这组并接回前后。

### 拿到这道题的第一思路

**数据结构。** 单链表加虚拟头。引用标记组前驱、组首、组末和组后。

**怎么想。** 先数够 k 个再动手。把组后节点当反转的初始后继，原组首变成新组尾时就能接住后缀。

**文字推演。** 1、2、3、4、5，k=2。依次翻成 2、1 和 4、3，剩 5 不满一组，保留，得到 2、1、4、3、5。

### 关键变量与始终保持的规则

翻转停在组后节点。组前驱最后连新组首，随后移到新组尾。

### 实例走过程

```text
head=[1,2,3,4,5], k=2
1、2、3、4、5，k=2。依次翻成 2、1 和 4、3，剩 5 不满一组，保留，得到 2、1、4、3、5。
结果 [2, 1, 4, 3, 5]
```

### Java代码

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0, head);
        ListNode before = dummy;
        while (true) {
            ListNode end = before;
            for (int i = 0; i < k; i++) {
                end = end.next;
                if (end == null) {
                    return dummy.next; // 不足一整组，保留剩余节点
                }
            }

            ListNode after = end.next;
            ListNode start = before.next;
            ListNode cur = start;
            ListNode prev = after; // 原组首翻转后成为组尾，先连好后缀
            while (cur != after) {
                ListNode next = cur.next;
                cur.next = prev;
                prev = cur;
                cur = next;
            }
            before.next = end;
            before = start;
        }
    }
}
```

### 易错点

先查长度再改线，否则尾部不满一组时难以保持原样。

### 复杂度

时间 O(n)，额外空间 O(1)。

### 一句话总结

> 先造出所有副本节点，再把两种指针翻译到副本。

### 拿到这道题的第一思路

**数据结构。** Map 存「原节点对象 → 新节点对象」。每个节点有 next 和 random。

**怎么想。** 第一遍只复制节点，第二遍用原指针指到的节点查表，再把副本连到查出的新节点。这样指向后方和指向自己都能处理。

**文字推演。** 原链为 1、2，两个 random 都指向原节点 2。先造两个新节点，第二遍让两个新 random 都指向新的 2。

### 关键变量与始终保持的规则

副本的每条非空指针都指向副本节点。

### 实例走过程

```text
head=[[1,1],[2,1]]
原链为 1、2，两个 random 都指向原节点 2。先造两个新节点，第二遍让两个新 random 都指向新的 2。
结果 [[1, 1], [2, 1]]
```

### Java代码

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public Node copyRandomList(Node head) {
        Map<Node, Node> copies = new HashMap<>();
        for (Node cur = head; cur != null; cur = cur.next) {
            copies.put(cur, new Node(cur.val));
        }
        for (Node cur = head; cur != null; cur = cur.next) {
            Node copy = copies.get(cur);
            // 两条引用都翻译到复制链表，空引用查表仍为空
            copy.next = copies.get(cur.next);
            copy.random = copies.get(cur.random);
        }
        return copies.get(head);
    }
}
```

### 易错点

Map 用节点引用作键。同值节点也必须分别复制。

### 复杂度

时间 O(n)，额外空间 O(n)。

## 33. 148. 排序链表（链表）

[力扣题目](https://leetcode.cn/problems/sort-list/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0148-sort-list/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 先把链表分成两半，各自排好，再合并两条有序链。

### 拿到这道题的第一思路

**数据结构。** 单链表用快慢指针找中点，递归栈暂存待合并的两半。

**怎么想。** 链表按位置随机取值不方便，但拆链和接链都很直接。拆到只有一个节点时天然有序，合并时每轮选两个链头中较小的。

**文字推演。** 4、2、1、3 拆成 4、2 与 1、3。各自排成 2、4 与 1、3，合并得 1、2、3、4。

### 关键变量与始终保持的规则

切开中点的 next 后，左右递归都处理更短的链。

### 实例走过程

```text
head=[4,2,1,3]
4、2、1、3 拆成 4、2 与 1、3。各自排成 2、4 与 1、3，合并得 1、2、3、4。
结果 [1, 2, 3, 4]
```

### Java代码

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode slow = head;
        ListNode fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode right = slow.next;
        slow.next = null; // 分成两条独立的链，递归才会缩小规模
        ListNode sortedLeft = sortList(head);
        ListNode sortedRight = sortList(right);
        return merge(sortedLeft, sortedRight);
    }

    private ListNode merge(ListNode a, ListNode b) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (a != null && b != null) {
            if (a.val <= b.val) {
                tail.next = a;
                a = a.next;
            } else {
                tail.next = b;
                b = b.next;
            }
            tail = tail.next;
        }
        tail.next = a != null ? a : b;
        return dummy.next;
    }
}
```

### 易错点

这版自顶向下归并会用递归栈。需要满足进阶的常数辅助空间时，可改自底向上归并。

### 复杂度

时间 O(n log n)，额外空间 O(log n)。

## 34. 23. 合并 K 个升序链表（链表）

[力扣题目](https://leetcode.cn/problems/merge-k-sorted-lists/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0023-merge-k-sorted-lists/)

学习扩展。按本题条件选择主解。

### 一句话总结

> 小顶堆只保存每条链当前最有资格接入的节点。

### 拿到这道题的第一思路

**数据结构。** 优先队列是小顶堆，存各条非空链的当前头节点。结果仍是单链表。

**怎么想。** 最小的剩余值一定在某条链的头上。弹出最小头接到结果，再把它的后继放进堆。

**文字推演。** 合并 1、4、5，1、3、4，2、6。先从堆里依次取 1、1、2，每次只补它所在链的后继，最终得到 1、1、2、3、4、4、5、6。

### 关键变量与始终保持的规则

堆中每条尚未耗尽的链最多贡献一个候选。

### 实例走过程

```text
lists=[[1,4,5],[1,3,4],[2,6]]
合并 1、4、5，1、3、4，2、6。先从堆里依次取 1、1、2，每次只补它所在链的后继，最终得到 1、1、2、3、4、4、5、6。
结果 [1, 1, 2, 3, 4, 4, 5, 6]
```

### Java代码

```java
import java.util.PriorityQueue;

class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> heap =
                new PriorityQueue<>((a, b) -> Integer.compare(a.val, b.val));
        for (ListNode head : lists) {
            if (head != null) {
                heap.offer(head);
            }
        }
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (!heap.isEmpty()) {
            ListNode node = heap.poll();
            tail.next = node;
            tail = node;
            if (node.next != null) {
                heap.offer(node.next); // 只补上这一条链的下一个候选
            }
        }
        return dummy.next;
    }
}
```

### 易错点

同值节点都要保留。空链的头不加入堆。

### 复杂度

总节点数 N、链数 k。时间 O(k+N log(k+1))，额外空间 O(k)。

## 35. 146. LRU 缓存（链表）

[力扣题目](https://leetcode.cn/problems/lru-cache/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0146-lru-cache/)

学习扩展。按本题条件选择主解。

### 一句话总结

> Map 负责快速找节点，双向链表负责维护最近使用顺序。

### 拿到这道题的第一思路

**数据结构。** Map 存「键 → 双向链表节点」。链表头侧是最近使用，尾侧是最久未用，两端有哨兵。

**怎么想。** 读到键或更新旧键，就把它移到头侧。插入后超容量，淘汰尾侧的真实节点，同时从 Map 删除对应键。

**文字推演。** 容量 2，放 1、2 后访问 1，顺序变成 1、2。再放 3，淘汰 2，所以 get(2) 得 −1。

### 关键变量与始终保持的规则

Map 和链表保存同一批真实节点。换顺序只改连接，查找仍通过 Map。

### 实例走过程

```text
capacity=2, put(1,1), put(2,2), get(1), put(3,3), get(2), put(4,4), get(1), get(3), get(4)
容量 2，放 1、2 后访问 1，顺序变成 1、2。再放 3，淘汰 2，所以 get(2) 得 −1。
结果 [1, -1, -1, 3, 4]
```

### Java代码

```java
import java.util.HashMap;
import java.util.Map;

class LRUCache {
    private static class Node {
        int key;
        int val;
        Node prev;
        Node next;

        Node(int key, int val) {
            this.key = key;
            this.val = val;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> cache = new HashMap<>();
    private final Node head = new Node(0, 0);
    private final Node tail = new Node(0, 0);

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = cache.get(key);
        if (node == null) {
            return -1;
        }
        remove(node);
        addFirst(node);
        return node.val;
    }

    public void put(int key, int value) {
        Node node = cache.get(key);
        if (node != null) {
            node.val = value;
            remove(node);
            addFirst(node);
            return;
        }
        node = new Node(key, value);
        cache.put(key, node);
        addFirst(node);
        if (cache.size() > capacity) {
            Node oldest = tail.prev;
            remove(oldest);
            cache.remove(oldest.key); // 两种结构都删掉淘汰项
        }
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void addFirst(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }
}
```

### 易错点

成功的 get 也改变使用顺序。更新已有键只改值和顺序。

### 复杂度

get 和 put 平均 O(1)，额外空间 O(capacity)。

> 每棵子树都按左、根、右的顺序访问。

### 拿到这道题的第一思路

**数据结构。** 二叉树存左右引用，递归栈记住正在处理的子树，结果列表记录访问顺序。

**怎么想。** 先把左子树完整处理，再记录当前根，最后处理右子树。空树直接结束。

**文字推演。** 根为 4，先走左子树得到 1、2、3，记 4，再走右子树得 5、6、7。

### 关键变量与始终保持的规则

递归函数负责把这一棵子树的中序结果追加到同一个列表。

### 实例走过程

```text
root = [4, 2, 6, 1, 3, 5, 7]
根为 4，先走左子树得到 1、2、3，记 4，再走右子树得 5、6、7。
结果 [1, 2, 3, 4, 5, 6, 7]
```

### Java代码

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        traversal(root, result);
        return result;
    }

    // ① 把当前子树的中序结果追加到 result，无需返回值。
    private void traversal(TreeNode node, List<Integer> result) {
        // ② 空节点没有内容，直接返回。
        if (node == null) {
            return;
        }
        // ③ 中序要等左边完成，才记录自己，再处理右边。
        traversal(node.left, result);
        result.add(node.val);
        traversal(node.right, result);
    }
}
```

### 易错点

记录根值要放在两次递归之间。

### 复杂度

时间 O(n)，额外空间 O(h)，另有结果列表。h 为树高。

### 一句话总结

> 当前子树的深度等于较深孩子的深度加一层。

### 拿到这道题的第一思路

**数据结构。** 二叉树加递归栈。每层接收左右子树分别有多深。

**怎么想。** 空树为 0 层，先求两边深度，取较大值再加当前根这一层。

**文字推演。** 树的根为 4，左右孩子为 2、6，下面还有叶子。叶子回传 1，2 和 6 回传 2，根回传 3。

### 关键变量与始终保持的规则

每次返回的是从当前根向下的层数。

### 实例走过程

```text
root = [4, 2, 6, 1, 3, 5, 7]
树的根为 4，左右孩子为 2、6，下面还有叶子。叶子回传 1，2 和 6 回传 2，根回传 3。
结果 3
```

### Java代码

```java
class Solution {
    // ① 返回当前子树的高度，不是当前节点距离根的深度。
    public int maxDepth(TreeNode root) {
        // ② 空树有 0 层；这样叶子才能由 max(0, 0) + 1 得到 1。
        if (root == null) {
            return 0;
        }
        // ③ 父高度依赖孩子：先拿左右高度，再取较大值加自己一层。
        int leftHeight = maxDepth(root.left);
        int rightHeight = maxDepth(root.right);
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

### 易错点

单边树也要取最大值。空树与叶子的答案分别是 0 和 1。

### 复杂度

时间 O(n)，额外空间 O(h)。


```java
class Solution {
    // ① 返回当前子树翻转后的根；操作直接修改原节点。
    public TreeNode invertTree(TreeNode root) {
        // ② 空树翻转后仍为空。
        if (root == null) {
            return null;
        }
        // ③ 交换两侧，再递归翻转交换后的孩子；当前根仍是 root。
        TreeNode temporary = root.left;
        root.left = root.right;
        root.right = temporary;
        invertTree(root.left);
        invertTree(root.right);
        return root;

}
```

## 39. 101. 对称二叉树（二叉树）

[力扣题目](https://leetcode.cn/problems/symmetric-tree/) · [交互式调试器](https://xiaoshupeiqi.github.io/leetcode-java/problems/hot100-0101-symmetric-tree/)

沿用总笔记及仓库中本题的主解。

### 一句话总结

> 把左右子树成对比较，外侧对外侧，内侧对内侧。

### 拿到这道题的第一思路

**数据结构。** 二叉树加递归栈。每次递归带着一对镜像位置的节点。

**怎么想。** 两边都空就匹配，只空一边就不匹配。值相等后，左树的左孩子要配右树的右孩子，另一对也同理。

**文字推演。** 层序 1、2、2、3、4、4、3。先比两个 2，再交叉检查两个 3 与两个 4，全部相同。

### 关键变量与始终保持的规则

每次递归判断的是一对完整子树能否镜像重合。

### 实例走过程

```text
root = [1, 2, 2, 3, 4, 4, 3]
层序 1、2、2、3、4、4、3。先比两个 2，再交叉检查两个 3 与两个 4，全部相同。
结果 true
```

### Java代码

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) {
            return true;
        }
        return mirror(root.left, root.right);
    }

    // ① 两个参数是待比较的子树根；返回它们是否镜像。
    private boolean mirror(TreeNode left, TreeNode right) {
        // ② 两边都空才匹配；只有一边空说明结构不对称。
        if (left == null || right == null) {
            return left == right;
        }
        // ③ 值相同后，再同时检查外侧和内侧的镜像关系。
        if (left.val != right.val) {
            return false;
        }
        // 外侧对外侧、内侧对内侧；两组都匹配才是镜像。
        return mirror(left.left, right.right)
                && mirror(left.right, right.left);
    }
}
```

### 易错点

比较时还要核对空节点的位置。同层值相同未必镜像。

### 复杂度

时间 O(n)，额外空间 O(h)。

### 拿到这道题的第一思路

**数据结构。** 二叉树加递归栈。每层向上返回一侧高度，另记全树最大直径。

**怎么想。** 经过当前节点的最长路径用左右高度相加。向父节点延伸时只能取较长的一侧，再加当前层。

**文字推演。** 层序 1、2、3、4、5。节点 2 的左右高度各为 1，候选直径 2。根的左右高度为 2 和 1，直径更新为 3。

### 关键变量与始终保持的规则

直径按边数计，空子树高度为 0，叶子向上回传 1。

### 实例走过程

```text
root=[1,2,3,4,5]
层序 1、2、3、4、5。节点 2 的左右高度各为 1，候选直径 2。根的左右高度为 2 和 1，直径更新为 3。
结果 3
```

### Java代码

```java
class Solution {
    private int diameter;

    public int diameterOfBinaryTree(TreeNode root) {
        diameter = 0;
        height(root);
        return diameter;
    }

    // 返回当前子树的高度，同时检查经过当前节点的路径。
    private int height(TreeNode node) {
        if (node == null) {
            return 0;
        }
        int left = height(node.left);
        int right = height(node.right);
        diameter = Math.max(diameter, left + right);
        return Math.max(left, right) + 1;
    }
}
```

### 易错点

最长路径可能绕过树根，所以每个节点都要更新候选。

### 复杂度

时间 O(n)，额外空间 O(h)。
